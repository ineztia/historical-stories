## 3. Proposed Changes

### 3.1 通用处理策略（适用于全部 11 篇）

1. **备注结构重塑**
   - 一级标题仅保留四种：
     - `### 史源：索引`
     - `### 考古：相关发现`
     - `### 推断：……`（可用 `### 推断：说明` 或带主题副标题）
     - `### 评论：……`（通常用 `### 评论：延伸思考`，内容多时分设 `#### 评论：……`）
   - 删除旧标题：`史源索引`、`推断说明`、`延伸思考`、`学术争议`、`叙事说明`、`联系与比较视角`、`多维阐释视角`、`群像篇说明`、`考古二重证据` 等，将其内容归入上述四前缀下。

2. **「考古：相关发现」专项**
   - 首句明确点明与本文主题的证据关系：直接相关 / 宏观背景 / 阙如。
   - 可援引遗址：河南偃师二里头遗址、登封王城岗遗址、新密新砦遗址、夏县东下冯遗址、安徽蚌埠禹会村遗址、豫东/鲁西岳石文化、豫北下七垣文化（先商）等。
   - 凡涉及二里头与夏都/夏文化对应关系，必须使用「学界主流观点」「尚存在争议」「目前无法确证」等限定语，禁止直接等同。
   - 无直接对应证据时，须写「本篇所述……直接对应的考古证据目前尚不存在」或类似阙如说明。

3. **正文局外视角清理**
   - 将正文中「影响深远」「留给后世」「奠定了……基础」「具有重要意义」「标志着……开端」等评论/比较/后世评价句移入备注 `### 评论：延伸思考`。
   - 不改变叙事主线，仅做局部后移或改写为叙事语言。

4. **Proof 文档**
   - 路径：`temp/02_xia/<id>.proof.md`
   - 按 `.agents/writing.md` §8 最新模板覆盖写入，包含阶段 1–4、独立验证记录、通读记录、修订摘要。
   - 所有结果仅允许 ✅ 或 ➖（不适用），不得出现 ❌ 未处理项。

## 5. Verification Steps

1. **单篇自检**：每篇修订后确认备注包含 `### 史源：索引`、`### 考古：相关发现`、`### 推断：`、`### 评论：` 四个一级前缀。
2. **旧标题清零**：Grep 确认 11 篇中不再出现 `史源索引`、`推断说明`、`学术争议`、`叙事说明`、`联系与比较视角`、`多维阐释视角`、`群像篇说明`、`考古二重证据` 等旧标题。
3. **考古专项完整性**：Grep 确认 11 篇均包含 `### 考古：相关发现`。
4. **正文语体抽检**：抽查正文是否仍残留「影响深远」「奠定基础」「具有重要意义」等评论句。
5. **Proof 校验**：确认 `temp/02_xia/xia_11.proof.md` 至 `xia_20.proof.md`、`xia_19x.proof.md` 均存在，且所有校对项为 ✅ 或 ➖。
6. **终盘 Grep**：在 `logs/contents/02_xia/` 对 Batch 5 文件执行四前缀检查，输出每篇命中情况汇总。
7. **生成摘要**：列明 11 篇处理结果、补写考古专项数量、重写 proof 数量、残留问题（如有）。
