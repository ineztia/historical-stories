# 叙事骨架与图谱管理

> 本模块采用**三段对等结构**，先公共、后两线对偶：
> - **§1 公共部分**（§1.1–§1.6）：两线共用的术语、抓手、原则、篇型骨架、编号规则
> - **§2 正史叙事骨架**：分**元规则**（§2.1.1–§2.1.3）与**执行流程**（§2.2.1–§2.2.2）
> - **§3 文学并行图谱**：分**元规则**（§3.1.1–§3.1.5）与**执行流程**（§3.2.1–§3.2.2）
>
> **方法论统一**：§2 与 §3 在结构上对偶——均按"元规则 → 执行流程"两段展开。
> **公共部分前置**：§1 集中定义两线共用的概念、抓手、篇型骨架，分支内不再重复定义。

## §1 公共部分

### 1.1 核心术语

- **政权/势力**：事实性掌权主体，含王朝、割据、民族/宗教政权、流民起义、摄政家族、军阀等
- **掌权阶段**：势力内事实权力中心的连续在位期；非君主持续主导政局跨越重大事件者同样计入
- **叙事段/期**：文学线对「掌权阶段」的对偶概念——原著中按情节转折切分的连续叙事单元
- **人物弧线**：文学线术语——主要人物从出场到收场的起讫与转折点

### 1.2 学史方法抓手

每篇显性对应至少一种：

| 抓手 | 含义 | 通用示例 |
|------|------|----------|
| **考证** | 史料/原著分歧、出土文献补正、版本异文 | 苏秦年代争议、清华简补《竹书纪年》、《水浒传》繁本/简本差异 |
| **关联** | 同期母题对照、纵向母题承接、原著与正史原型对照 | 三家分晋 ↔ 田氏代齐「卿代公」母题；草船借箭之文学虚构 ↔ 史实孙权借箭原型 |
| **对比** | 不同势力处理同一事件、前后制度演变、同母题不同处理 | 李悝—吴起—商鞅—申不害变法路径；《三国演义》「空城计」与《三国志》裴注之异同 |

允许兼具多抓手；无合适抓手者复核是否为凑篇。

### 1.3 覆盖与承接原则

政治意义明确的掌权者**须全部纳入时间轴**，但不要求每位独占一篇：

1. **点名承接**（默认）：在专篇背景/正文中按在位顺序点名，交代继承、起讫、核心事迹——哪怕一句话即视为覆盖
2. **合篇**（仅单一政权时期）：多位掌权者共用一篇群像
3. **一句话承接**：史料极稀薄者允许一句话带过
4. **⊘ 存疑标注**：传说性或存在性存疑者须在相邻故事备注说明

**跨段名人**：按主要活动期归入对应阶段；如需承接，在备注交代衔接。

### 1.4 名人典故三级吸纳

对非掌权者的知名人物（将相、谋臣、武将、学者）与典故/成语事件：

**L1 节点融入**（默认，适用绝大多数）：
- 在分势力分期专篇/掌权阶段篇/里程碑事件篇**正文内作为叙事节点显性点名并充分展开**
- 禁仅一句带过，须交代来龙去脉、核心情节、史源/原著线索
- **纯典故成语一律不允许独立成篇**

**L2 附篇索引**（可选）：
- 在专篇/通论备注末尾附「名人典故索引」条目（软约束）

**L3 独立成篇**（严格门槛，须**同时**满足三条）：
1. 跨多任掌权者或多势力（正史）/ 跨多段或多线索（文学）
2. 独立文化符号（武圣、文宗、诸子代表等，强后世接受史）
3. 现有专篇无法自然容纳

通过者归入：
- 战役/政治类 → 里程碑事件篇
- 思想/文学/文化类 → 通论补充篇

**兜底**：掌权阶段内高辨识度人物须系统点名（黄帝期仓颉/嫘祖、少康期女艾/伯靡），优先 L1 融入。

### 1.5 六种篇型骨架（两线共用骨架）

> 骨架是公共定义；正史定义见 §2.1.3，文学对偶变体见 §3.1.5。

| 骨架篇型 | 公共职能 |
|---------|----------|
| **掌权阶段篇 / 叙事阶段篇** | 以一位/合多位掌权者（正史）或一个/多个叙事段（文学）为主体 |
| **分期导论篇 / 段期导论篇** | 定义该分期/段期的时代坐标与全局形势 |
| **分势力分期专篇 / 分线索分人物专篇** | 每分期内每势力（正史）或每线索/人物（文学）一篇 |
| **里程碑事件篇** | 跨势力/跨分期的家喻户晓或结构性转折事件（名称两线一致） |
| **通论补充篇** | 覆盖该时代独有或代表性成就（子类见下，名称两线一致） |
| **时代收束篇** | 结构性遗产与对后世影响（名称两线一致） |

**通论补充篇三子类**（两线共用）：

- **全时代横截类**：跨势力共享的制度/经济/科技议题（战国铁器牛耕、三国九品中正制）
- **分势力专项类**：有明确主属势力的成就（战国·楚之楚辞与屈原、齐之稷下学宫）
- **跨势力专题类**：多势力并列必须比较者（战国百家争鸣、变法综论）

**严禁**三子类混装成「大杂烩」稀释势力文化轮廓。

### 1.6 优先级与编号规则

**优先级定义**（故事列表「优先级」列填此值）：

- **高**：家喻户晓 / 不可绕过的核心事件 / 必读
- **中**：著名但非必读 / 文学性强 / 可选读
- **低**：低识别度 / 不建议独立成篇（进入延伸候选）

**编号规则**：`{era}_{number}`，正史与文学使用各自前缀（详见 [file-spec.md §1](file-spec.md)）。

## §2 正史叙事骨架

### 2.1 元规则

#### 2.1.1 骨架选型

| 时代类型 | 典型朝代 | 骨架形态 |
|---------|---------|----------|
| 单一政权·无分期 | 夏、商、西周、秦、隋、元 | 按掌权阶段顺序推进，无分期导论 |
| 单一政权·有分期 | 西汉、东汉、唐、宋、明、清 | 分期导论 + 按期推进的掌权阶段 |
| 多势力并立 | 春秋、战国、三国、南北朝、五代十国、宋辽金夏等 | 三层骨架（§2.1.2） |

#### 2.1.2 多势力并立·三层骨架

骨架含 3 个层级（不含时代收束——收束见公共篇型 §1.5）：

1. **历史分期（一级）**：按全局形势的结构性变化切 2–4 期，**不得**以单一势力王位更迭为据。示例：三国分群雄奠基（184–220）、三分鼎立（220–263）、归一之程（263–280）
2. **分势力展开（二级）**：每分期内每势力按该期掌权者顺序点名承接；史料稀薄者允许跨期合并或仅在分期导论中点名
3. **里程碑事件（横切）**：跨势力、跨分期的**家喻户晓或结构性转折**事件（家喻户晓的：三家分晋、赤壁之战；结构性转折的：长平之战、安史之乱、靖康之变等）；其他势力多视角呼应，各层不重复详述

**红线**：多势力并立时代**禁止**「一势力讲完再讲下一势力」的整块切片。

**分势力展开顺序**：默认「中原/正统优先」；若主导力量为非正统势力（五代十国部分阶段、辽金夏对宋主导期），以实际主导力量为先。

#### 2.1.3 篇型体系（正史定义）

公共骨架 §1.5 在正史语境下的具体落地：

| 篇型 | 正史适用场景 | 核心职能 |
|------|------------|----------|
| **掌权阶段篇** | 单一政权 | 以一位/合多位掌权者为主体，详述其治世 |
| **分期导论篇** | 多势力并立 | 定义该分期时代坐标与全局形势 |
| **分势力分期专篇** | 多势力并立 | 每分期内每势力一篇，按该期掌权者顺序点名承接 |
| **里程碑事件篇** | 通用 | 跨势力/跨分期的家喻户晓或结构性转折事件 |
| **通论补充篇** | 通用 | 覆盖该时代独有或代表性成就（子类见 §1.5） |
| **时代收束篇** | 通用（每时代 1 篇） | 结构性遗产与对后世影响 |

### 2.2 执行流程

#### 2.2.1 广度检索 → 通史目标校准 → 规划叙事单元

**广度检索**：按史料优先级做权威互证（二十四史、《史记》、《资治通鉴》及可靠通史著作优先；出土文献同等权重）。

**通史目标校准**：聚焦知名人物与事件与必要脉络承接；避免冷僻专题。每篇须能回答「为何通史读者要读这一篇」。

**规划叙事单元**：

- **单一政权**：以掌权阶段为主骨架，末尾附通论补充题材
- **多势力并立**：由六种篇型组合（见 §2.1.4）——
  - 分期导论篇
  - 分势力分期专篇
  - 里程碑事件篇
  - 通论补充篇（合计 3–12 篇）：贯穿性主题前置/穿插，收束性主题后置
  - 时代收束篇（1 篇）

**篇数参考区间**（非刚性；上限非封顶，超出者归入「延伸拓展候选」；低于下限须复核是否遗漏认知必备）：

- 远古（三皇五帝、夏）：15–30 篇
- 中等（商、西周）：20–40 篇
- 多势力丰厚：春秋、十六国南北朝、五代十国 30–50 篇；战国、三国 40–60 篇
- 单一大朝代（汉、唐、宋、明、清）：40–60 篇

#### 2.2.2 输出故事列表 + 延伸拓展候选

**故事列表**：

- 多势力并立：按「分期 → 导论 → 各势力专篇 → 里程碑 → 通论 → 收束」组织
- 单一政权：按「掌权阶段 → 通论」
- 同步在谱系表「对应故事」列填编号（允许多位掌权者共指同一专篇）
- 每条 5 字段：# / 主题 / 优先级 / 抓手 / 状态

**延伸拓展候选清单**：在 `eras/*.md` 末尾输出

- **记入条件**（任一即记）：因篇数上限未独立成篇者；满足 L3 前两条件但可并入既有篇者；已 L1 融入但仍具独立价值者；认知抓手较弱、取舍两可的专题
- 已独立成篇者不再列入
- **字段**：候选主题 / 建议归类 / 推荐抓手 / 推荐归宿 / 未入选原因
- **升级机制**：用户确认升入正式列表时分配新编号并迁移，同步更新谱系「对应故事」列；候选清单不占正式编号、不计入进度

**输出后暂停待用户确认**。

## §3 文学并行图谱

### 3.1 元规则

#### 3.1.1 核心原则

**正史是正史，传奇是传奇，各走各的叙事线，互不干扰又互相映照。**

对与某朝代相关的非正史叙事材料，按体量与影响力分两级处理：

1. **篇幅小、影响力有限者**（零散野史、笔记、民间传说）：融入正史故事的备注或正文参考部分，不另开辟图谱
2. **篇幅巨大且具有独立文化地位者**（封神演义、水浒传、三国演义、西游记等经典文学巨著）：**另开辟并行叙事图谱**，用独立的叙事线讲述故事

#### 3.1.2 判定标准

须**同时满足**以下三条方可创建并行图谱：

- 原著为长篇巨著（数十回以上），具有完整的叙事结构
- 原著在大众文化中的影响力远超正史，是普通读者接触该时代的主要入口
- 原著内容与正史存在大量出入，强行融入正史会破坏正史的史实底线

**判定结果须向用户说明并确认**。

#### 3.1.3 与正史图谱的关系

| 维度 | 正史图谱 | 并行图谱 |
|------|---------|---------|
| 性质 | 历史叙事 | 文学叙事 |
| 来源类型 | 权威史料（对应写作标准 §2.1 来源卡片） | 经典文学原著（对应写作标准 §2.1 来源卡片） |
| 谱系骨架 | 掌权者传承 | 原著自身的叙事结构（章回/事件/人物弧线） |
| 真实性 | 史实为底线 | 忠实于原著情节，标注「此为文学虚构」即可 |

**红线**：

- 并行图谱**不得**替代正史图谱
- 正史图谱**不得**因并行图谱的存在而删减内容
- 两条线平行存在，读者可择一阅读或对照阅读

#### 3.1.4 命名与文件规则

核心：与正史命名同构（三件套共享前缀），`x` 标识并行。进度单独列于 `progress.md`，不计正史。详细规范见 [file-spec.md §7](file-spec.md)。

#### 3.1.5 篇型体系（文学对偶变体）

公共骨架 §1.5 在文学语境下的具体落地——所有篇型名按文学线语境重定义：

| 篇型 | 文学线适用场景 |
|------|---------------|
| 掌权阶段篇 | 改用「叙事阶段篇」——以谱系中的段/期为主体 |
| 分期导论篇 | 改用「段期导论篇」——定义该段叙事坐标与全局形势 |
| 分势力分期专篇 | 改用「分线索/分人物专篇」——按主线/支线/人物弧线切 |
| 里程碑事件篇 | 通用——跨段/跨线索的关键转折事件 |
| 通论补充篇 | 通用——文学母题、艺术手法、版本异文等专论 |
| 时代收束篇 | 通用——原著整体的艺术成就与后世影响 |

**严禁**将「原著没有的内容」混入正文。

### 3.2 执行流程

#### 3.2.1 原著研读 → 作品概览 → 谱系形态判定 → 叙事段期划分

**原著研读**：通读原著（至少叙事主线 + 关键支线），输出三层认知：

1. **结构骨架**——主线 / 支线 / 汇流点 / 分叉点
2. **叙事大节**——按原著自身的情节大节切分（如：取经路上的八十一难、水浒传的聚义前/聚义后、三国演义的群雄逐鹿/三足鼎立/一统归晋）
3. **核心人物弧线**——主要人物从出场到收场的起讫与转折点

**作品概览**：融进文件头部引言一句话（作者 / 版本 / 关联正史），不单独成节。

**谱系形态判定**：按原著主线/支线关系分三类：

- **单一主线型**——以一条主线贯穿（如《西游记》以取经为单线）
- **多线汇流型**——多条独立主线在关键节点交汇（《三国演义》魏蜀吴三线交织于赤壁、汉中、夷陵等会战点）
- **群像辐射型**——多组人物各自走完弧线后在终点聚合（《水浒传》百零八人聚义后受招安、征方腊）

**叙事段/期划分**：按"原著研读"第 2 项「叙事大节」切「段」或「期」：

- 段数不硬性限制，但单段内部叙事密度须足以独立成篇
- 段的边界以原著情节转折为据（不必与正史时代分期对齐）
- 史料/原著原文中某段叙述稀薄者，仍如实登记，不跳过

**主题命名规范**：统一「事件标签——内涵说明」格式：

- 事件标签：4–8 字为限（取原著回目核心事件）
- 内涵说明：8–16 字为限（点主旨或叙事转折）
- 示例：女娲宫题诗——纣王亵渎与天命降罚

#### 3.2.2 输出作品-叙事谱系 + 故事列表 + 延伸拓展候选

**作品-叙事谱系（A）**：文学线谱系输出至 `eras/<era>.md`（与 AGENTS.md 路由对齐），5 字段表模板见 [file-spec.md §7.2](file-spec.md)。

**故事列表（B）**：按段分组，每条 5 字段（# / 主题 / 优先级 / 抓手 / 状态）

- 多线索型：按「段期 → 导论 → 各线索/人物专篇 → 里程碑 → 通论 → 收束」组织
- 单一主线型：按「叙事阶段 → 通论」组织
- 同步在谱系表「对应故事」列填编号（回填本节谱系第 5 字段）

**延伸拓展候选清单（C）**：字段沿用公共定义（§1.6 + 正史 §2.2.2 字段说明）；记入条件同 §2.2.2，含"已 L1 融入但仍具独立价值者"。

**回目校准**：以原著回目顺序为骨架切分叙事单元。允许的切分粒度：

- **单回篇**——一回能独立讲完一个完整叙事单元者
- **跨回篇**——多回合并叙大事者（如《水浒传》「三打祝家庄」跨多回）
- **人物弧线篇**——以主要人物弧线为切分依据者（如宋江之「怒杀阎婆惜」至「受招安」）

禁按现代主题另起骨架，禁在正文中改写或重排原著情节。

**篇数参考**：以回目数为参考上限（不强制 = 回目数），按叙事密度酌定：

- 高密度单线（如《西游记》百回）→ 30–50 篇
- 多线汇流（如《三国演义》百二十回）→ 40–60 篇
- 群像辐射（如《水浒传》百回/百二十回）→ 40–70 篇
