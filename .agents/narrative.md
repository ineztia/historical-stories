# 说史架构与图谱管理

本文件指导时代架构、篇目规划与素材归属；篇内组织、语体和校对见 [writing.md](writing.md)。

## 1. 叙事架构

### 1.1 正史架构形态

**核心术语**：

- **政权/势力**：事实性掌权主体，含王朝、割据、民族/宗教政权、流民起义、摄政家族、军阀等。
- **掌权阶段**：势力内事实权力中心的连续在位期；非君主但持续主导政局超过一个执政周期者同样计入。

**架构选择**：

- **名义单一政权**（夏、商、西周、秦、隋、元、西汉、东汉、唐、宋、明、清）：掌权阶段为主架构，可按需分卷；唐含武周，宋兼顾并立的辽、西夏、金。
- **多势力并立**（春秋、战国、三国、南北朝、五代十国等）：分卷、分势力展开、跨势力里程碑事件三层组织。

**分卷**：以全局形势的结构性变化为据；单一政权也可聚合相邻且承接紧密的掌权阶段。每卷配一篇分卷导论，史料稀薄或跨度短的时代可不分卷。

**多势力并立的三层结构**：

1. 按全局结构性变化切 2–4 卷，不以单一势力王位更迭为据。如三国分群雄奠基（184–220）、三分鼎立（220–263）、归一之程（263–280）。
2. 每卷内分势力、按该卷掌权者顺序点名承接；史料稀薄的势力允许跨卷合并或仅在导论点名。
3. 跨势力、跨卷的家喻户晓或结构性转折事件设里程碑篇，各层不重复详述。

禁止一势力讲完再讲下一势力的整块叙述。分势力展开默认中原/正统优先，非正统势力主导期以实际主导力量为先。

#### 掌权者覆盖与承接

政治意义明确的掌权者须全部纳入时间轴。**篇目可合并，年谱不合并**：

- **图谱年谱**：凡名号可考、有记载的掌权者各占一行，包括摄政、共治等事实权力中心；不因重要性、史料厚薄或有无故事而省略。
- **故事篇目**：不要求每人独占一篇，可按史料密度合并，但须保持掌权阶段承接清楚。

**图谱规则**：

1. 图谱表格是完整传承年谱的呈现载体，不得用表外名录或备注替代表内位置，也不得以起讫代称、「N 任」等概括多人。
2. 多势力时代仍以人为行单元，统治者列按 `势力｜君主` 书写，同期各势力按时间交错排列；「势力×时段」仅为篇目组织单元。
3. 同一人两度在位可合为一行并列年份；在位不足一年者仍独占一行。
4. 仅当某段世系确无可考名号时可设「失载」行，备注说明依据，不推补人名。
5. 无对应故事者也须占行，标「无对应故事」或「并入 #X」，备注说明原因。

**故事承接方式**：

| 方式 | 用法 |
|------|------|
| 点名承接（默认） | 在背景或正文中按在位顺序交代姓名、继承、起讫与核心事迹 |
| 合并承接（多势力时代） | 低价值或史料稀薄者并入势力展开篇，逐名点到；图谱各人仍独立成行，对应故事加「（承接）」 |
| 群像篇（单一政权时期） | 多位掌权者共用一篇 |
| 一句话承接 | 史料极稀薄者简述，不强行扩写 |
| ⊘ 存疑 | 存在性或传说性存疑者，在相邻故事的史源说明中简述 |

跨期名人按主要活动期归属，其他阶段只作必要承接或指向已写篇目。

### 1.2 并行叙事线架构形态

**类型判定**：单一主线型（《西游记》）、多线汇流型（《三国演义》）、群像辐射型（《水浒传》）。

**回目与卷边界**：

- 以原著回目顺序切分，可用单回篇、跨回篇或人物弧线篇；不按现代主题重排原著情节。
- 卷边界以原著情节转折为据，不必与正史分卷对齐。
- 原著叙述稀薄者仍如实登记。可略过不影响连贯性的低价值回目，后续理解所必需的桥段按 [writing.md §5](writing.md) 补入。
- 主题统一用「事件标签 · 内涵说明」命名。
- 底本图谱采用五字段：分卷名、起始·终止章回、核心事件、核心人物、对应故事，见 [file-spec.md §1.4](file-spec.md)。

| 维度 | 正史 | 文学线 |
|------|------|--------|
| 性质 | 历史叙事 | 文学叙事 |
| 来源 | 权威史料 | 经典文学原著 |
| 组织主线 | 掌权者传承 | 原著自身结构 |
| 真实性 | 史实为底线 | 忠实原著，标明文学虚构 |

两线平行，文学线不得替代正史图谱，正史不得因有文学线而删减必要内容。文学线不混入原著没有的事件。

## 2. 篇目规划

### 2.1 全局疏密

分配篇数前，扫描整个时代或全书的叙事密度；确认后的篇数作为预算。

| 判断依据 | 正史素材 | 文学素材 |
|----------|----------|----------|
| 来源厚度 | 权威史料的记载厚薄 | 原著笔墨、场景与对白密度 |
| 结构分量 | 通史关键节点或平淡延续 | 主线转折、高潮或过渡 |
| 读者认知 | 知名人物、事件的集中程度 | 名场面的集中程度 |

密处充分分配篇位，薄处合并或简略承接；通论占少量篇位，不挤压主体叙事。

**篇数参考区间**（超出归候选，低于则复核遗漏）：

| 类型 | 正史 | 文学 |
|------|------|------|
| 远古/小型 | 三皇五帝、夏：15–30 篇；秦、隋：5–10 篇 | ≤50 回、篇、则：8–15 篇 |
| 中等 | 商、西周：20–40 篇 | 51–100 回、篇、则：15–25 篇 |
| 丰厚/多势力 | 春秋、十六国南北朝、五代十国：30–50 篇；战国、三国：40–60 篇 | >100 回、篇、则：25–35 篇 |
| 大朝代 | 西汉+东汉、唐、宋、明、清：40–60 篇 | — |

非章回体按篇、则、卷或等效字数归档：≤50 回约 3–5 万字，51–100 回约 6–12 万字，>100 回约 13 万字以上。

### 2.2 篇目类型

**结构性必备篇**：每个分卷一篇导论，交代时代坐标、全局形势与主导趋势；每时代一篇终章，讲结构性遗产及后世影响。史料稀薄或跨度极短、不分卷的时代可只保留终章。

主体叙事的焦点可为掌权阶段、势力展开、重大事件、人物传记、对抗博弈、制度兴亡、社会实态、思想文化或综合通论，可兼具多个焦点。

**正史默认按掌权阶段推进**，其余焦点按需要穿插或独立成篇。阶段内的具体组织见 writing.md §8，不以故事性为由改变传承架构或遗漏重要承接。

文学线相应以叙事阶段、线索与人物展开为主体，通论和终章可聚焦文学母题、艺术手法、版本异文及后世影响。

**优先级**：

- 高：家喻户晓、不可绕过的核心事件，必读。
- 中：著名但非必读，具有可读性，可选读。
- 低：低识别度，不建议独立成篇，进入备选题库。

编号规则见 [AGENTS.md §5](../AGENTS.md)。

### 2.3 名人典故吸纳（正史专项）

规划及单篇预研均须检查该掌权阶段的知名故事，视野包括掌权者、臣属、同期其他人物及有来源的民间传说、神鬼志怪。优先选取能呈现人物、时代生活或思想文化的材料；不要求每篇凑齐类别，也不只检索君王本纪。

**L1 节点融入（默认）**：在既有专篇正文中自然展开人物处境、关键行动与结果，不以名字或成语释义代替故事。材料须与本篇人物、事件或时代主题有实质联系；仅仅同年发生，不必全部纳入。**纯典故成语不允许独立成篇**。

**L2 附篇索引（可选）**：无法展开但有查阅价值的材料，可在史源中简列典故、出处与所涉内容，不另设长篇附录，不代替应展开的 L1 节点。

**L3 独立成篇**须同时满足：

1. 跨多任掌权者或多势力；
2. 是具有强后世接受史的独立文化符号；
3. 现有篇目无法自然容纳。

通过者按实际内容选择重大事件、思想文化或综合通论等焦点。掌权阶段内高辨识度人物须系统点名，如黄帝期仓颉、嫘祖，少康期女艾、伯靡。

年代不明的典故可作人物补叙，不硬系于某年；材料性质与可信度按 [writing.md §3.4、§4.3](writing.md) 处理，不能为丰富故事补造细节。

### 2.4 备选题库

未入选正式列表的备查主题，不占编号、不计进度、不使用 ✅/⏳。采用「候选主题、推荐归宿、未入选原因」三字段。

因篇幅超预算、适合先融入既有篇、仍有独立成篇价值或取舍两可者记入，并说明原因。后续升级时分配新编号，同步故事列表与图谱对应故事列。

## 3. 执行流程

两线均按「检索研读 → 规划叙事单元 → 输出确认」执行。

### 3.1 正史线

1. **广度检索**：以二十四史、《史记》、《资治通鉴》、可靠通史与出土文献为主，梳理掌权阶段、重要事件与必要承接，同时按 §2.3 搜集可融入的故事。避免无关冷僻专题，每篇须能回答为何通史读者要读。
2. **规划单元**：按 §2.1 分配篇位。单一政权为「分卷导论（如有）＋掌权阶段主线＋其他焦点篇目＋时代终章」；多势力时代为「分卷导论＋分势力展开＋重大事件＋其他焦点＋时代终章」。
3. **输出**：传承图谱及故事列表（#、主题、优先级、状态四字段）、备选题库写入 `workspace/eras/{编号}_{时代代码}.md`，同步图谱对应故事列；暂停等待用户确认。

### 3.2 文学线

1. **原著研读**：至少覆盖主线与关键支线，梳理叙事结构、叙事大节、主要人物从出场到收场的起讫与转折。
2. **分卷规划**：按 §2.1 分配篇位、§1.2 组织。单线型按叙事阶段推进，多线型兼顾分卷导论、各线人物展开、重大事件与收束。
3. **输出**：底本图谱、四字段故事列表与备选题库写入 `workspace/eras/{编号}_{作品名}.md`，暂停等待用户确认。

时代文件引言须简述作者、版本及与正史的关系；跨时代归属与链接按 AGENTS.md §5 执行。

#### 3.2.1 文学线与补充材料的边界

- 文学线由用户指定作品后开启，不因发现零散传说而另建图谱。
- 野史、笔记、民间传说与志怪可按 §2.3 融入正史正文，明确来源性质，不作史实依据。
- 正史篇涉及个别有影响的文学故事时，可作与主题相关的简短补叙；开头说明「在《某作品》中」，结束后回到历史叙述。不得用文学情节解释真实政治因果，也不得混淆人物原型与文学形象。
- 对经典文学作品的连续、系统复述归入独立文学线，忠实原著。正史与文学的必要差异、交叉引用统一简记于史源，不另开解释板块。
