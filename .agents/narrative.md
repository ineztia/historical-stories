# 说史架构与图谱管理

> 本文件指导如何将一个时代的历史材料结构化为故事序列——从宏观架构设计到具体篇目规划再到执行产出。

---

## 1 叙事架构

### 1.1 正史架构形态

**核心术语**：

- **政权/势力**：事实性掌权主体，含王朝、割据、民族/宗教政权、流民起义、摄政家族、军阀等
- **掌权阶段**：势力内事实权力中心的连续在位期；非君主但持续主导政局超过一个执政周期者同样计入

**架构选择**：按时代结构分两类——

- **名义单一政权**（夏、商、西周、秦、隋、元、西汉、东汉、唐、宋、明、清）：掌权阶段为主架构，可按需分卷；其中唐含武周，宋并立辽、西夏、金
- **多势力并立**（春秋、战国、三国、南北朝、五代十国等）：分卷 + 分势力展开 + 跨势力里程碑事件三层

**分卷**：将全时代划为若干卷的目录组织手段；每卷配一篇分卷导论（结构性必备篇）。划分标准以全局形势的结构性变化为据（多势力并立的默认），亦可按相邻且承接紧密的掌权阶段聚合（单一政权的常用方式）；史料稀薄或跨度短的时代可不分卷。

**多势力并立·三层结构**：

1. **分卷**：按全局形势的结构性变化切 2–4 卷，**不得**以单一势力王位更迭为据。示例：三国分群雄奠基（184–220）、三分鼎立（220–263）、归一之程（263–280）
2. **分势力展开**：每卷内按该卷掌权者顺序点名承接；史料稀薄的势力允许跨卷合并或仅在导论中点名
3. **里程碑事件**：跨势力/跨卷的家喻户晓或结构性转折事件（赤壁之战、长平之战、安史之乱、靖康之变等），各层不重复详述

**红线**：多势力并立时代**禁止**「一势力讲完再讲下一势力」的整块叙述；分势力展开顺序默认「中原/正统优先」，非正统势力主导期以实际主导力量为先。

#### 掌权者覆盖与承接

政治意义明确的掌权者**须全部纳入时间轴**，不要求每位独占一篇；原则上不跳跃时间轴——仅可略过同时满足「正史无明确记载」且「无重大历史影响」的阶段，并在备注说明略过原因。承接方式按史料密度选其一：

1. **点名承接**（默认）：在专篇背景/正文中按在位顺序点名，交代继承、起讫、核心事迹
2. **群像篇**（仅单一政权时期）：多位掌权者共用一篇群像
3. **一句话承接**：史料极稀薄者允许一句话带过
4. **⊘ 存疑**：传说性/存在性存疑者须在相邻故事备注说明

**跨期名人**：按主要活动期归入对应阶段；如需承接，在备注交代衔接。

### 1.2 并行叙事线架构形态

#### 叙事类型判定

按主线/支线关系分三类：单一主线型（如《西游记》）/ 多线汇流型（如《三国演义》）/ 群像辐射型（如《水浒传》）

#### 回目校准与卷边界

- 以原著回目顺序为基准切分叙事单元；允许的切分粒度为单回篇 / 跨回篇 / 人物弧线篇
- 禁按现代主题另起架构，禁改写或重排原著情节
- 卷的边界以原著情节转折为据（不必与正史时代分卷对齐）
- 原著叙述稀薄者仍如实登记，不跳过
- **篇际连贯**：故事列表是对原著连续叙事的分篇切割，分篇是预算分配手段而非叙事断裂——允许略过低价值且不影响连贯性的回目；但被略过回目的关键事件若在后续篇中被引用或为理解后续情节所必需，须在相邻篇正文以桥段补入，不得仅在背景概括
- **主题命名**：统一「事件标签 · 内涵说明」格式

#### 底本图谱结构

5 字段表（分卷名 / 起始·终止章回 / 核心事件 / 核心人物 / 对应故事），格式模板见 [file-spec.md §6.1](file-spec.md)。

#### 与正史的定位关系

| 维度 | 正史 | 并行叙事线（文学线） |
|------|------|------|
| 性质 | 历史叙事 | 文学叙事 |
| 来源 | 权威史料 | 经典文学原著 |
| 组织主线 | 掌权者传承 | 原著自身叙事结构 |
| 真实性 | 史实为底线 | 忠实原著，标注「文学虚构」 |

**红线**：并行叙事线不得替代正史传承图谱；正史不得因并行线的存在而删减内容。两线平行存在，读者可择一或对照阅读。
**底线**：**严禁**将「原著没有的内容」混入正文。

## 2 篇目规划

### 2.1 全局疏密

篇数是固定预算，分配前对整个时代/全书做一次叙事密度扫描。

**三项判断依据**：

| # | 依据 | 正史素材 | 文学素材 |
|---|---|------|---------|
| 1 | 来源厚度 | 权威史料对该阶段的记载厚薄 | 原著对该阶段的笔墨分配（回目数、场景细节、对白密度） |
| 2 | 结构分量 | 该阶段在通史中的结构性分量（关键节点 vs 平淡延续） | 该阶段在全书叙事结构中的分量（主线转折/高潮 vs 过渡衔接） |
| 3 | 读者认知 | 家喻户晓的人物事件是否集中在此阶段 | 名场面是否集中在此阶段 |

**分配原则**：密处多给篇位充分展开，薄处压缩（正史用群像篇/节点融入；文学合并入邻近篇作节点）；通论从预算中分出少量，不与叙事主线争抢篇位。

**篇数参考区间**（超出归候选、低于复核遗漏）：

| 类型 | 正史 | 文学 |
|------|------|------|
| 远古/小型 | 三皇五帝、夏：15–30 篇；秦、隋：5–10 篇 | ≤50回 / 篇 / 则：8–15篇 |
| 中等 | 商、西周：20–40 篇 | 51–100回 / 篇 / 则：15–25篇 |
| 丰厚/多势力 | 春秋、十六国南北朝、五代十国 30–50 篇；战国、三国 40–60 篇 | >100回 / 篇 / 则：25–35篇 |
| 大朝代 | 西汉+东汉、唐、宋、明、清：40–60 篇 | — |

非章回体作品以「篇 / 则 / 卷」或等效字数规模归入对应档位：≤50回 ≈ 3–5万字，51–100回 ≈ 6–12万字，>100回 ≈ 13万字以上。

### 2.2 篇目类型

#### 结构性必备篇

| 必备篇 | 职能 |
|--------|------|
| **分卷导论** | 独立于任何掌权者的全卷宏观概览：时代坐标、全局形势、结构性背景与主导趋势 |
| **时代终章** | 结构性遗产与对后世影响；每时代 1 篇 |

适用范围：分卷导论适用于所有使用分卷组织的时代（每卷一篇）。
**省略条件**：史料稀薄或跨度极短的时代，可仅保留时代终章，省略分卷导论。

#### 主体叙事篇焦点维度

以下为常见焦点维度（启发性菜单，非穷举）。一篇故事可兼具多个焦点，也允许菜单外的组织方式：

| 焦点维度 | 说明 |
|---------|------|
| 掌权阶段 | 以一位或多位掌权者的在位期为主线 |
| 势力展开 | 某势力在某时段内的连续发展（多势力并立时代） |
| 重大事件 | 跨势力/跨卷的家喻户晓或结构性转折事件 |
| 人物传记 | 以单一人物的生命弧线为主线 |
| 对抗与博弈 | 以双方/多方互动为叙事引擎 |
| 制度兴亡 | 以制度从产生到崩溃为线索 |
| 社会实态 | 以某时段社会面貌为对象 |
| 思想文化 | 以思想运动或文化现象为主题 |
| 综合通论 | 贯穿全时代的横截面主题（文化/科技/制度/经济等） |

**组织原则**：掌权阶段仍是正史叙事的默认主架构（时间轴推进载体），其余焦点按叙事需要穿插或独立成篇。

**文学线焦点对应**（仅部分维度有对应表述）：

- 掌权阶段 → 叙事阶段（以一个/多个分卷为主体）
- 势力展开 → 线索/人物展开（每线索/人物一篇）
- 综合通论 → 聚焦文学母题、艺术手法、版本异文等专论
- 时代终章（必备篇） → 聚焦原著整体的艺术成就与后世影响

#### 优先级

- **高**：家喻户晓 / 不可绕过的核心事件 / 必读
- **中**：著名但非必读 / 可读性强 / 可选读
- **低**：低识别度 / 不建议独立成篇（进入备选题库）

故事 id 与编号规则见 [AGENTS.md §5](../AGENTS.md) 与 [file-spec.md §3](file-spec.md)。

### 2.3 名人典故吸纳（正史专项）

**L1 节点融入**（默认）：在专篇正文内作为叙事节点显性点名并充分展开——禁仅一句带过；**纯典故成语一律不允许独立成篇**。
**L2 附篇索引**（可选）：在专篇/通论备注末尾附「名人典故索引」条目。
**L3 独立成篇**（须同时满足三条）：跨多任掌权者或多势力；独立文化符号（强后世接受史）；现有篇目无法自然容纳。通过者按实际内容选择合适焦点维度（战役/政治类 → 重大事件焦点；思想/文学/文化类 → 思想文化或综合通论焦点）。

**不可缺项**：掌权阶段内高辨识度人物须系统点名（黄帝期仓颉、嫘祖，少康期女艾、伯靡）。

### 2.4 备选题库

未入选正式故事列表的备查主题池；后续可升入正式列表（分配新编号，迁移并同步图谱「对应故事」列）。

- 不占正式编号、不计进度、无 ✅/⏳
- 字段：**候选主题 / 推荐归宿 / 未入选原因**（3 字段；升级时同步更新图谱）
- 记入条件（任一即记）：因篇幅或叙事密度超出预期未独立成篇；具备独立成篇部分条件但并入既有篇更合适；已以节点形式融入正文但仍有单独成篇价值；认知价值较弱、取舍两可
- 记入时同步记下未入选原因——便于后续升级或重新评估

## 3 执行流程

正史与文学线均按三步执行——**广度检索 → 规划叙事单元 → 输出**。两线差异仅在第一步的检索对象与第二步的组织方式。

### 3.1 正史线

**第 1 步·广度检索**：以二十四史、《史记》、《资治通鉴》及可靠通史著作、出土文献为主，聚焦知名人物与事件与必要脉络承接；避免冷僻专题；每篇须能回答「为何通史读者要读这一篇」。

**第 2 步·规划叙事单元**：按 §2.1 全局疏密分配篇位后，细化组织——

- 单一政权：（分卷导论 →）掌权阶段主线 + 其他焦点篇目按需穿插 + 时代终章
- 多势力并立：分卷导论 + 分势力展开 + 重大事件 + 其他焦点篇目 + 时代终章

**第 3 步·输出**：故事列表（4 字段：# / 主题 / 优先级 / 状态）+ 备选题库，写入 `logs/eras/<era>.md`，同步在图谱「对应故事」列填编号；输出后暂停待用户确认。

### 3.2 文学线

**第 1 步·原著研读**（至少叙事主线 + 关键支线），输出三层认知：① 叙事结构（主线 / 支线 / 汇流点 / 分叉点）② 叙事大节（按原著情节大节切分）③ 核心人物弧线（主要人物从出场到收场的起讫与转折点）。

**第 2 步·分卷划分**：按 §2.1 分配篇位，按 §1.2 架构规则组织——单一主线型按「叙事阶段 → 其他焦点 → 收束」；多线索型按「分卷导论 → 各线索/人物展开 → 重大事件 → 其他焦点 → 收束」。

**作品概览**（文学线 era 文件引言必填，一句话内）：作者 / 版本 / 与正史的关系。例：`明代许仲琳（一说陆西星）百回本《封神演义》，以武王伐纣为骨干，融合大量神话与民间传说`。

**第 3 步·输出**：底本图谱（5 字段表，见 [file-spec.md §6.1](file-spec.md)）+ 故事列表（4 字段）+ 备选题库，写入 `logs/eras/{编号}_{作品名}.md`；输出后暂停待用户确认。

**跨时代文学归属**：文学线的 `{编号}` 按作品故事起始时代确定，而非按主要叙事时代或结束时代。具体编号规则与作品示例详见 [AGENTS.md §5](../AGENTS.md)。

#### 3.2.1 开辟判定

**材料分级处理**：

- 零散野史/笔记/民间传说 → 融入正史故事备注或正文参考，不另开辟图谱
- 经典文学巨著（封神演义、水浒传、三国演义、西游记等）→ 另开辟并行叙事线

**创建条件**（须同时满足）：① 原著为数十回以上的长篇巨著，具有完整的叙事结构；② 原著在大众文化中的影响力远超正史，是普通读者接触该时代的主要入口；③ 原著内容与正史存在结构性冲突，无法在正史叙事中兼容呈现。

满足条件时 AI 评估并告知用户，由用户决定是否开辟（[AGENTS.md §4.3](../AGENTS.md)）。

**用户拒绝开辟**：进入该时代正史线处理；该文学巨著中有"对普通读者形成历史认知起决定性作用"的具体情节（如封神演义中的妲己 / 三国演义中的草船借箭）时，由 AI 在对应正史故事备注中以"推断：/评论："形式提示读者"该形象在[作品名]中的文学化处理"，但不展开复述。
