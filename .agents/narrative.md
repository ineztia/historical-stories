# 叙事骨架与图谱管理

> **结构**：§1 公共部分（两线共用）→ §2 正史叙事骨架 → §3 文学并行图谱。
> §2 与 §3 在结构上对偶：均按"元规则 → 执行流程"两段展开。
> **子模块自包含**：命名/路径/元数据等总则回查 [AGENTS.md §4](../AGENTS.md)。

---

## §1 公共部分

### 1.1 六种篇型骨架

| 骨架篇型 | 公共职能 |
|---------|----------|
| **掌权阶段篇**（文学线：叙事阶段篇） | 以一位/合多位掌权者（正史）或一个/多个叙事段（文学）为主体 |
| **分期导论篇**（文学线：段期导论篇） | 定义该分期/段期的时代坐标与全局形势 |
| **分势力分期专篇**（文学线：分线索分人物专篇） | 每分期内每势力（正史）或每线索/人物（文学）一篇 |
| **里程碑事件篇** | 跨势力/跨分期的家喻户晓或结构性转折事件 |
| **通论补充篇** | 覆盖该时代独有或代表性成就；三子类：全时代横截类 / 分势力专项类 / 跨势力专题类（严禁三子类混装成「大杂烩」） |
| **时代收束篇** | 结构性遗产与对后世影响；每时代 1 篇 |

**多势力并立专属**：分期导论篇、分势力分期专篇仅适用于多势力并立时代。
**文学线语境差异**（仅同名篇型不列）：通论补充篇聚焦文学母题、艺术手法、版本异文等专论；时代收束篇聚焦原著整体的艺术成就与后世影响。

### 1.2 优先级

- **高**：家喻户晓 / 不可绕过的核心事件 / 必读
- **中**：著名但非必读 / 可读性强 / 可选读
- **低**：低识别度 / 不建议独立成篇（进入候补故事池）

**编号规则**：定义见 [AGENTS.md §4.2](../AGENTS.md)。

### 1.3 候补故事池（公共机制）

**做什么**：未入选正式故事列表的故事备查清单——记录因篇幅、密度、价值等原因未独立成篇、但值得备查的故事；可后续升级为正式篇目。

- **记入条件**（任一即记）：
  - 因篇幅或叙事密度超出预期而未独立成篇者
  - 已具备独立成篇的部分条件、但并入既有篇更合适者
  - 已以节点形式融入正文、但仍有单独成篇价值者
  - 认知价值较弱、取舍两可的专题
- **字段**：候选主题 / 建议归类 / 推荐归宿 / 未入选原因
- 已独立成篇者不再列入
- **升级机制**：用户确认升入正式列表时分配新编号并迁移，同步更新谱系「对应故事」列；候选清单不占正式编号、不计入进度

## §2 正史叙事骨架

### 2.1 元规则

#### 2.1.1 掌权者覆盖与承接

**核心术语**：

- **政权/势力**：事实性掌权主体，含王朝、割据、民族/宗教政权、流民起义、摄政家族、军阀等
- **掌权阶段**：势力内事实权力中心的连续在位期；非君主持续主导政局跨越重大事件者同样计入

**承接原则**：政治意义明确的掌权者**须全部纳入时间轴**，不要求每位独占一篇。承接方式按史料密度选其一：

1. **点名承接**（默认）：在专篇背景/正文中按在位顺序点名，交代继承、起讫、核心事迹
2. **合篇**（仅单一政权时期）：多位掌权者共用一篇群像
3. **一句话承接**：史料极稀薄者允许一句话带过
4. **⊘ 存疑**：传说性/存在性存疑者须在相邻故事备注说明

**跨段名人**：按主要活动期归入对应阶段；如需承接，在备注交代衔接。

#### 2.1.2 多势力并立·三层骨架

按时代类型分三档（前置选型）：

| 时代类型 | 典型朝代 | 骨架形态 |
|---------|---------|---------|
| 单一政权·无分期 | 夏、商、西周、秦、隋、元 | 按掌权阶段顺序推进，无分期导论 |
| 单一政权·有分期 | 西汉、东汉、唐、宋、明、清 | 分期导论 + 按期推进的掌权阶段 |
| 多势力并立 | 春秋、战国、三国、南北朝、五代十国、宋辽金夏等 | 三层骨架（本节） |

**三层结构**：

1. **历史分期（一级）**：按全局形势的结构性变化切 2–4 期，**不得**以单一势力王位更迭为据。示例：三国分群雄奠基（184–220）、三分鼎立（220–263）、归一之程（263–280）
2. **分势力展开（二级）**：每分期内每势力按该期掌权者顺序点名承接；史料稀薄者允许跨期合并或仅在分期导论中点名
3. **里程碑事件（横切）**：跨势力、跨分期的**家喻户晓或结构性转折**事件——家喻户晓的（如三家分晋、赤壁之战）；结构性转折的（如长平之战、安史之乱、靖康之变）。其他势力多视角呼应，各层不重复详述

**红线**：多势力并立时代**禁止**「一势力讲完再讲下一势力」的整块叙述。
**分势力展开顺序**：默认「中原/正统优先」；若主导力量为非正统势力（五代十国部分阶段、辽金夏对宋主导期），以实际主导力量为先。

#### 2.1.3 名人典故三级吸纳

**L1 节点融入**（默认）：在专篇正文内作为叙事节点显性点名并充分展开——禁仅一句带过；**纯典故成语一律不允许独立成篇**。
**L2 附篇索引**（可选）：在专篇/通论备注末尾附「名人典故索引」条目。
**L3 独立成篇**（须同时满足三条）：跨多任掌权者或多势力；独立文化符号（强后世接受史）；现有专篇无法自然容纳。通过者归入：战役/政治类 → 里程碑事件篇；思想/文学/文化类 → 通论补充篇。

**不可缺项**：掌权阶段内高辨识度人物须系统点名（黄帝期仓颉/嫘祖、少康期女艾/伯靡）。

### 2.2 执行流程

#### 2.2.1 广度检索 → 通史校准 → 规划叙事单元

- **广度检索**：按史料优先级做权威互证（二十四史、《史记》、《资治通鉴》及可靠通史著作优先；出土文献同等权重）
- **通史校准**：聚焦知名人物与事件与必要脉络承接；避免冷僻专题；每篇须能回答「为何通史读者要读这一篇」
- **规划叙事单元**：
  - 单一政权：掌权阶段为主骨架 + 末尾通论补充
  - 多势力并立：分期导论 + 分势力分期专篇 + 里程碑事件篇 + 通论补充篇（3–12 篇；贯穿性主题前置/穿插，收束性主题后置）+ 时代收束篇（1 篇）

**篇数参考区间**（参考；超出归候选、低于复核遗漏）：

- 远古（三皇五帝、夏）：15–30 篇
- 中等（商、西周）：20–40 篇
- 多势力丰厚：春秋、十六国南北朝、五代十国 30–50 篇；战国、三国 40–60 篇
- 单一大朝代（汉、唐、宋、明、清）：40–60 篇

#### 2.2.2 输出故事列表 + 延伸拓展候选

**故事列表**（4 字段：# / 主题 / 优先级 / 状态）：

- 多势力并立：「分期 → 导论 → 各势力专篇 → 里程碑 → 通论 → 收束」
- 单一政权：「掌权阶段 → 通论」
- 同步在谱系表「对应故事」列填编号（允许多位掌权者对应同一专篇）

**延伸拓展候选**：按 §1.3 公共规则输出，置于 `logs/eras/*.md` 末尾。
**输出后暂停待用户确认**。

## §3 文学并行图谱

### 3.1 元规则

#### 3.1.1 核心原则

**核心术语**：

- **叙事段/期**：原著中按情节转折切分的连续叙事单元（与正史「掌权阶段」对偶）
- **人物弧线**：主要人物从出场到收场的起讫与转折点

**材料分级处理**：与某朝代相关的非正史材料按体量与影响力分两级：

- **零散野史/笔记/民间传说** → 融入正史故事备注或正文参考，不另开辟图谱
- **经典文学巨著**（封神演义、水浒传、三国演义、西游记等）→ **另开辟并行叙事图谱**

**文件与进度**：与正史命名同构（三件套共享前缀），`x` 标识并行；进度单独列于 `logs/progress.md`，不计正史。

#### 3.1.2 创建并行图谱的判定标准（硬条件，须同时满足）

- 原著为长篇巨著（数十回以上），具有完整的叙事结构
- 原著在大众文化中的影响力远超正史，是普通读者接触该时代的主要入口
- 原著内容与正史存在大量出入，强行融入正史会破坏正史的史实底线

**判定结果须向用户说明并确认。**

#### 3.1.3 与正史图谱的关系

| 维度 | 正史图谱 | 并行图谱 |
|------|---------|---------|
| 性质 | 历史叙事 | 文学叙事 |
| 来源类型 | 权威史料 | 经典文学原著 |
| 谱系骨架 | 掌权者传承 | 原著自身的叙事结构（章回/事件/人物弧线） |
| 真实性 | 史实为底线 | 忠实于原著情节，标注「此为文学虚构」即可 |

**红线**：并行图谱不得替代正史图谱；正史图谱不得因并行图谱的存在而删减内容；两条线平行存在，读者可择一阅读或对照阅读。
**底线**：**严禁**将「原著没有的内容」混入正文。

### 3.2 执行流程

#### 3.2.1 原著研读 → 谱系形态判定 → 段期划分

**第 1 步：原著研读**（至少叙事主线 + 关键支线），输出三层认知：

1. **结构骨架**——主线 / 支线 / 汇流点 / 分叉点
2. **叙事大节**——按原著自身的情节大节切分（如：取经路上的八十一难、水浒传的聚义前/聚义后、三国演义的群雄逐鹿/三足鼎立/一统归晋）
3. **核心人物弧线**——主要人物从出场到收场的起讫与转折点

**第 2 步：判定谱系形态**（按主线/支线关系分三类）：

- **单一主线型**——以一条主线贯穿（如《西游记》取经单线）
- **多线汇流型**——多条独立主线在关键节点交汇（如《三国演义》魏蜀吴三线交织于赤壁、汉中、夷陵等会战点）
- **群像辐射型**——多组人物各自走完弧线后在终点聚合（如《水浒传》百零八人聚义后受招安、征方腊）

**第 3 步：划分段期并命名主题**：

- 段数不硬性限制，单段内部叙事密度须足以独立成篇
- 段的边界以原著情节转折为据（不必与正史时代分期对齐）
- 叙述稀薄者仍如实登记，不跳过
- **主题命名**（段/期/故事名）：统一「事件标签——内涵说明」格式（例：女娲宫题诗——纣王亵渎与天命降罚）

**作品概览**（辅助项）：作者 / 版本 / 关联正史融进时代文件头部引言一句话。

**附加约束与参考**：

- **回目校准**：以原著回目顺序为骨架切分叙事单元；允许的切分粒度为单回篇 / 跨回篇 / 人物弧线篇。禁按现代主题另起框架，禁在正文中改写或重排原著情节
- **疏密预判**：对全书回目做「详 / 略」分流——详写：独立成篇、充分展开（家喻户晓的名场面 / 主线结构性转折）；略写：合并入邻近篇作节点展开。分流依据：① 大众熟悉度、② 主线推进必要性、③ 原著叙事密度
- **篇数参考**（非刚性，按叙事密度酌定）：单线 30–50 / 多线 40–60 / 群像 40–70；超出归候选、低于复核遗漏

#### 3.2.2 输出：作品-叙事谱系 + 故事列表 + 延伸拓展候选

- **作品-叙事谱系（A）**：5 字段表（段/期名 / 起始·终止章回 / 核心事件 / 核心人物 / 对应故事）输出至 `logs/eras/<era>.md`
- **故事列表（B）**（4 字段：# / 主题 / 优先级 / 状态）：多线索型按「段期 → 导论 → 各线索/人物专篇 → 里程碑 → 通论 → 收束」组织；单一主线型按「叙事阶段 → 通论」组织；同步在谱系表「对应故事」列填编号
- **延伸拓展候选（C）**：按 §1.3 公共规则输出

**输出后暂停待用户确认**。
