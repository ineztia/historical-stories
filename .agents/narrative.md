# 叙事骨架与图谱管理

---

## §1 公共部分

### 1.1 篇目组织：两层机制

#### 第一层：结构性必备篇（骨架节点，每时代不可省略）

| 必备篇 | 职能 |
|--------|------|
| **分卷/分期导论** | 独立于任何掌权者的全卷宏观概览：时代坐标、全局形势、结构性背景与主导趋势 |
| **时代收束** | 结构性遗产与对后世影响；每时代 1 篇 |

适用范围：分卷导论适用于所有使用分卷组织的时代（每卷一篇）；史料稀薄或跨度极短的时代可省略分卷导论，仅保留时代收束。

#### 第二层：主体叙事篇（灵活组织，不限定类型）

以下为常见焦点维度（启发性菜单，非穷举分类法）。一篇故事可兼具多个焦点，也允许出现菜单外的组织方式：

| 焦点维度 | 说明 |
|---------|------|
| 掌权阶段 | 以一位或多位掌权者的在位期为主线 |
| 势力展开 | 某势力在某时段内的连续发展（多势力并立时代） |
| 重大事件 | 跨势力/跨卷的家喻户晓或结构性转折事件 |
| 人物传记 | 以单一人物的生命弧线为主线 |
| 对抗与博弈 | 以双方/多方互动为叙事引擎 |
| 制度兴亡 | 以制度从产生到崩溃为线索 |
| 社会实态 | 以某时段社会面貌为对象 |
| 思想文化 | 以思想运动或文化现象为主题 |
| 综合通论 | 贯穿全时代的横截面主题（文化/科技/制度/经济等） |

**组织原则**：掌权阶段仍是正史叙事的默认主骨架（时间轴推进载体），其余焦点按叙事需要穿插或独立成篇。综合通论类主题从篇数预算中分出少量，不与叙事主线争抢篇位。

**文学线焦点对偶**（仅部分维度有对应表述）：
- 掌权阶段 → 叙事阶段（以一个/多个叙事段为主体）
- 势力展开 → 线索/人物展开（每线索/人物一篇）
- 综合通论 → 聚焦文学母题、艺术手法、版本异文等专论
- 时代收束（必备篇） → 聚焦原著整体的艺术成就与后世影响

### 1.2 优先级

- **高**：家喻户晓 / 不可绕过的核心事件 / 必读
- **中**：著名但非必读 / 可读性强 / 可选读
- **低**：低识别度 / 不建议独立成篇（进入候补故事池）

**编号规则**：定义见 [AGENTS.md §4.2](../AGENTS.md)。

### 1.3 候补故事池（公共机制）

**做什么**：未入选正式故事列表的故事备查清单——记录因篇幅、密度、价值等原因未独立成篇、但值得备查的故事；可后续升级为正式篇目。

- **记入条件**（任一即记）：
  - 因篇幅或叙事密度超出预期而未独立成篇者
  - 已具备独立成篇的部分条件、但并入既有篇更合适者
  - 已以节点形式融入正文、但仍有单独成篇价值者
  - 认知价值较弱、取舍两可的专题
- **字段**：候选主题 / 建议归类 / 推荐归宿 / 未入选原因
- 已独立成篇者不再列入
- **升级机制**：用户确认升入正式列表时分配新编号并迁移，同步更新谱系「对应故事」列；候选清单不占正式编号、不计入进度

## §2 正史叙事骨架

### 2.1 元规则

#### 2.1.1 掌权者覆盖与承接

**核心术语**：

- **政权/势力**：事实性掌权主体，含王朝、割据、民族/宗教政权、流民起义、摄政家族、军阀等
- **掌权阶段**：势力内事实权力中心的连续在位期；非君主但持续主导政局超过一个执政周期者同样计入。「一个执政周期」指完成至少一次重大政治事件或政策实施周期

**承接原则**：政治意义明确的掌权者**须全部纳入时间轴**，不要求每位独占一篇。原则上不跳跃时间轴；仅可略过同时满足「正史无明确记载」且「无重大历史影响」的阶段，并在备注说明略过原因。承接方式按史料密度选其一：

1. **点名承接**（默认）：在专篇背景/正文中按在位顺序点名，交代继承、起讫、核心事迹
2. **合篇**（仅单一政权时期）：多位掌权者共用一篇群像
3. **一句话承接**：史料极稀薄者允许一句话带过
4. **⊘ 存疑**：传说性/存在性存疑者须在相邻故事备注说明

**跨段名人**：按主要活动期归入对应阶段；如需承接，在备注交代衔接。

#### 2.1.2 骨架选型与分卷

**分卷**：将全时代划分为若干卷的目录组织手段，适用于所有时代。每卷配一篇分卷导论（结构性必备篇）。

| 时代类型 | 典型朝代 | 骨架形态 |
|---------|---------|---------|
| 单一政权 | 夏、商、西周、秦、隋、元、西汉、东汉、唐、宋、明、清 | 分卷（可选）+ 掌权阶段为主骨架 |
| 多势力并立 | 春秋、战国、三国、南北朝、五代十国、宋辽金夏等 | 三层骨架：分卷（必需）+ 分势力展开 + 里程碑事件 |

**分卷划分标准**：
- 按全局形势的结构性变化切分（多势力并立的默认标准）
- 按若干相邻且承接紧密的掌权阶段聚合成卷（单一政权的常用方式）
- 史料稀薄或跨度短的时代可不分卷，直接按掌权阶段顺序推进

**多势力并立·三层结构**：

1. **分卷（一级）**：按全局形势的结构性变化切 2–4 卷，**不得**以单一势力王位更迭为据。示例：三国分群雄奠基（184–220）、三分鼎立（220–263）、归一之程（263–280）
2. **分势力展开（二级）**：每卷内每势力按该卷掌权者顺序点名承接；史料稀薄者允许跨卷合并或仅在导论中点名
3. **里程碑事件（横切）**：跨势力、跨卷的**家喻户晓或结构性转折**事件——家喻户晓的（如三家分晋、赤壁之战）；结构性转折的（如长平之战、安史之乱、靖康之变）。其他势力多视角呼应，各层不重复详述

**红线**：多势力并立时代**禁止**「一势力讲完再讲下一势力」的整块叙述。
**分势力展开顺序**：默认「中原/正统优先」；若主导力量为非正统势力（五代十国部分阶段、辽金夏对宋主导期），以实际主导力量为先。

#### 2.1.3 名人典故三级吸纳

**L1 节点融入**（默认）：在专篇正文内作为叙事节点显性点名并充分展开——禁仅一句带过；**纯典故成语一律不允许独立成篇**。
**L2 附篇索引**（可选）：在专篇/通论备注末尾附「名人典故索引」条目。
**L3 独立成篇**（须同时满足三条）：跨多任掌权者或多势力；独立文化符号（强后世接受史）；现有篇目无法自然容纳。通过者按实际内容选择合适焦点维度（战役/政治类 → 重大事件焦点；思想/文学/文化类 → 思想文化或综合通论焦点）。

**不可缺项**：掌权阶段内高辨识度人物须系统点名（黄帝期仓颉/嫘祖、少康期女艾/伯靡）。

### 2.2 执行流程

#### 2.2.1 广度检索 → 全局疏密 → 规划叙事单元

**第 1 步：广度检索**：按史料优先级做权威互证（二十四史、《史记》、《资治通鉴》及可靠通史著作优先；出土文献同等权重）；聚焦知名人物与事件与必要脉络承接；避免冷僻专题；每篇须能回答「为何通史读者要读这一篇」

**第 2 步：全局疏密**（规划的核心主导逻辑）：篇数是固定预算，分配前先对整个时代做一次叙事密度扫描。判断密度的依据：① 权威史料对该段的记载厚薄（有多少可叙述的事件、人物、对话、细节）；② 该段在通史叙事中的结构性分量（开国/转折/亡国等关键节点 vs 平淡延续期）；③ 读者认知中的轨述密度（家喻户晓的人物事件是否集中在此段）。三者综合判断，按密度分配篇位——密处多给，薄处用合篇/节点融入压缩；通论补充从预算中分出少量，不与叙事主线争抢篇位

**第 3 步：规划叙事单元**（在密度分配确定后细化组织）：

- 单一政权：分卷导论（若分卷）+ 掌权阶段为主骨架 + 其他焦点篇目按需穿插 + 时代收束（1 篇）
- 多势力并立：分卷导论 + 分势力展开篇 + 重大事件篇 + 其他焦点篇目（综合通论、人物传记、制度兴亡等，贯穿性主题前置/穿插，收束性主题后置）+ 时代收束（1 篇）

**篇数参考区间**（参考；超出归候选、低于复核遗漏）：

- 远古（三皇五帝、夏）：15–30 篇
- 中等（商、西周）：20–40 篇
- 多势力丰厚：春秋、十六国南北朝、五代十国 30–50 篇；战国、三国 40–60 篇
- 单一大朝代（汉、唐、宋、明、清）：40–60 篇

#### 2.2.2 输出故事列表 + 延伸拓展候选

**故事列表**（4 字段：# / 主题 / 优先级 / 状态）：

- 单一政权：「（分卷导论 →）掌权阶段主线 → 其他焦点篇目 → 收束」
- 多势力并立：「分卷导论 → 各势力展开 → 重大事件 → 其他焦点篇目 → 收束」
- 同步在谱系表「对应故事」列填编号（允许多位掌权者对应同一篇目）

**延伸拓展候选**：按 §1.3 公共规则输出，置于 `logs/eras/*.md` 末尾。
**输出后暂停待用户确认**。

## §3 文学并行图谱

### 3.1 元规则

#### 3.1.1 核心原则

**核心术语**：

- **叙事段/期**：原著中按情节转折切分的连续叙事单元（与正史「掌权阶段」对偶）
- **人物弧线**：主要人物从出场到收场的起讫与转折点

**材料分级处理**：与某朝代相关的非正史材料按体量与影响力分两级：

- **零散野史/笔记/民间传说** → 融入正史故事备注或正文参考，不另开辟图谱
- **经典文学巨著**（封神演义、水浒传、三国演义、西游记等）→ **另开辟并行叙事图谱**

**文件与进度**：与正史命名同构（三件套共享前缀），`x` 标识并行；进度单独列于 `logs/progress.md`，不计正史。

#### 3.1.2 创建并行图谱的判定标准（硬条件，须同时满足）

- 原著为长篇巨著（数十回以上），具有完整的叙事结构
- 原著在大众文化中的影响力远超正史，是普通读者接触该时代的主要入口
- 原著内容与正史存在大量出入，强行融入正史会破坏正史的史实底线

**判定结果须向用户说明并确认。**

#### 3.1.3 与正史图谱的关系

| 维度 | 正史图谱 | 并行图谱 |
|------|---------|---------|
| 性质 | 历史叙事 | 文学叙事 |
| 来源类型 | 权威史料 | 经典文学原著 |
| 谱系骨架 | 掌权者传承 | 原著自身的叙事结构（章回/事件/人物弧线） |
| 真实性 | 史实为底线 | 忠实于原著情节，标注「此为文学虚构」即可 |

**红线**：并行图谱不得替代正史图谱；正史图谱不得因并行图谱的存在而删减内容；两条线平行存在，读者可择一阅读或对照阅读。
**底线**：**严禁**将「原著没有的内容」混入正文。

### 3.2 执行流程

#### 3.2.1 原著研读 → 全局疏密 → 段期划分

**第 1 步：原著研读**（至少叙事主线 + 关键支线），输出三层认知：

1. **结构骨架**——主线 / 支线 / 汇流点 / 分叉点
2. **叙事大节**——按原著自身的情节大节切分（如：取经路上的八十一难、水浒传的聚义前/聚义后、三国演义的群雄逐鹿/三足鼎立/一统归晋）
3. **核心人物弧线**——主要人物从出场到收场的起讫与转折点

**第 2 步：全局疏密**（规划的核心主导逻辑）：篇数是固定预算，分配前先对原著整体做一次叙事密度扫描。判断密度的依据：① 原著对该段的笔墨分配（回目数、场景细节、对白密度）；② 该段在全书叙事结构中的分量（主线转折/高潮/收束 vs 过渡衔接段）；③ 读者认知中的名场面集中度（家喻户晓的情节是否集中在此段）。三者综合判断，按密度分配篇位——密处独立成篇充分展开，薄处合并入邻近篇作节点；通论补充从预算中分出少量，不与情节主线争抢篇位

**第 3 步：段期划分与组织**（在密度分配确定后细化）：

- **谱系形态判定**（按主线/支线关系分三类）：单一主线型（如《西游记》）/ 多线汇流型（如《三国演义》）/ 群像辐射型（如《水浒传》）
- **回目校准**：以原著回目顺序为骨架切分叙事单元；允许的切分粒度为单回篇 / 跨回篇 / 人物弧线篇。禁按现代主题另起框架，禁改写或重排原著情节
- **段的边界**以原著情节转折为据（不必与正史时代分卷对齐）；叙述稀薄者仍如实登记，不跳过
- **主题命名**：统一「事件标签——内涵说明」格式

**作品概览**（辅助项）：作者 / 版本 / 关联正史融进时代文件头部引言一句话。

**篇数参考**（非刚性，按叙事密度酌定）：单线 30–50 / 多线 40–60 / 群像 40–70；超出归候选、低于复核遗漏

#### 3.2.2 输出：作品-叙事谱系 + 故事列表 + 延伸拓展候选

- **作品-叙事谱系（A）**：5 字段表（段/期名 / 起始·终止章回 / 核心事件 / 核心人物 / 对应故事）输出至 `logs/eras/<era>.md`
- **故事列表（B）**（4 字段：# / 主题 / 优先级 / 状态）：多线索型按「段期导论 → 各线索/人物展开 → 重大事件 → 其他焦点篇目 → 收束」组织；单一主线型按「叙事阶段 → 其他焦点篇目 → 收束」组织；同步在谱系表「对应故事」列填编号
- **延伸拓展候选（C）**：按 §1.3 公共规则输出

**输出后暂停待用户确认**。
