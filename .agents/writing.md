# 写作与校对统一标准

---

## 总则

本系统的故事分两种叙事线：

- **正史**——以权威史料（二十四史、出土文献、可靠通史著作、现代学术研究）为底，史实为底线
- **文学**——以经典文学原著为底，忠实原著情节，标注「此为文学虚构」

**两线统摄原则**：

1. **三层标签**——所有陈述按来源分为「**史源**」「**推断**」「**评论/比较/后世评价**」
2. **三类禁区**——无据不写、分层不混、边界不越

---

## 1. 故事输出形态

每篇固定三段，职能严格分工。

### 1.1 三段分工

**背景**：承担**纵向脉络**（前代渊源、制度承袭）与**结构性背景**（地理、经济、社会结构）。

**正文**：承担叙事职能，身份锁定为「叙事者」。凡需跳出故事、以局外视角才能说出的话均禁入正文，仅入备注——包含评论、比较、后世评价、章回结构标注、叙事手法分析、创作意图解读等内容。

**备注**：承担来源标注、概念语境锁定、推理过程、阐释维度、延伸思考等一切非叙事内容。

### 1.2 社会实态多维结构（贯穿背景与正文）

历史不仅是政治事件序列，更是社会系统各维度的交织运行。每篇须自然交织以下维度，不必逐项罗列：

- **权力与制度**：统治方式、合法性来源、制度运作
- **经济与生产**：生产方式、贸易、赋役、物资动员
- **宗教与信仰**：祭祀体系、宗教行为（含人殉、人牲等暴力祭祀）、信仰与权力的关系
- **社会分层与暴力**：阶层结构、奴隶制、刑罚、战争的社会后果
- **物质文化与技术**：建筑、器物、工艺所反映的社会组织水平

重大事件须呈现因果闭环：**上游（什么条件使之发生）→ 事件本身 → 下游（什么社会后果）→ 反馈回系统**。

考古/出土证据确证的重大社会现象不得回避。

### 1.3 焦点适配（按篇目焦点调配背景侧重）

- **分卷导论**（结构性必备篇）：背景偏时代坐标与全局形势
- **势力展开类篇目**：背景偏本势力渊源与该期掌权者承接（须点名该期所有掌权者，哪怕一句话）
- **重大事件类篇目**：背景偏事件爆发前各势力态势的多视角聚拢
- **其余焦点**（人物传记、制度兴亡、思想文化、社会实态等）：灵活调配，背景围绕本篇主题的前因与结构性背景展开

## 2. 来源与陈述

### 2.1 出处卡（落笔前预研，记入备注）

**适用说明**：两线均须建卡——正史以此保障史实可溯，文学以此锚定原著出处与版本、确保引文可检索。文学出处卡的职能是**出处锚定**而非史实验证，不构成额外论证负担。

**六字段**（结构共用，填法按线区分）：

| 字段 | 正史 | 文学 |
|------|------|------|
| 1. 来源名·篇目 | 如「《史记·五帝本纪》」 | 如「《封神演义》第一回」 |
| 2. 编纂/成书时代 | 史书编纂时代 | 原著成书时代 |
| 3. 所述事件时代 | 本篇事件的历史时代 | 本篇事件的历史时代 |
| 4. 体裁等级 | 正史/编年/类书/诸子/野史/笔记/志怪/出土文献/现代研究 | 长篇神魔小说/章回体/笔记体等 |
| 5. 关键原文摘句（≤60 字） | 须为原书可检索实句，禁复述改写 | 同左；现代研究引用核心结论或关键数据 |
| 6. 互证/对照状态 | 孤证/双证/多证 | 与正史异同 / 无对照 |

### 2.2 证据处理

- **统一证据池**：所有证据（传世文献、出土文献、考古报告、现代学术研究）进入同一证据池，共同服务于正文与备注
- **可靠性排序**（双维）：按「时代贴近度 × 史料可靠性」综合判断。同时代一手证据的事实陈述权重不低于后世追述性正史；后世正史的综合性叙事框架仍有组织价值，但不得以「正史未载」为由排斥同时代实证
- **体裁可靠性参考**（正史）：二十四史、《资治通鉴》等可靠通史、现代研究 > 野史、笔记、志怪、小说（后者须如实标注体裁等级并在备注说明可靠性边界）
- **学术研究引用**（正史专项）：可引用权威学术期刊（CSSCI/SSCI/A&HCI 及《历史研究》《考古》《文物》《中国史研究》等）、高校学报、专业机构论文与专著；出处卡体裁等级标「现代研究」，须注明作者·年份·篇名·刊名/出版社
- **孤证处理**（正史）：正文以「据某书」「一说」等限定语处理；备注注明孤证
- **争议处理**（正史）：同一事件在两部以上权威史料矛盾时，正文谨慎措辞（「有说法认为……」「部分史料记载……」），备注列主要分歧与来源；古文原文入备注并标注出处，篇幅过长可摘关键句仍须标注

### 2.3 陈述分层（三层标签）

**落位准则**：三层标签的显性前缀与原始素材（原文摘句、推理过程、阐释性内容）一律落位于备注；正文需呈现其结论时，以叙事语言自然融入，不加前缀、不另起独立段落。以此保障正文叙事纯度（§1.1）。

| 层级 | 显性前缀 | 触发条件 | 允许素材 | 备注要求 |
|------|---------|---------|---------|---------|
| **史源** | 「史源：」 | 当篇来源已记载 | 出处卡对应的权威原文 | 前缀与原文摘句落位于备注「史源原文」专项；正文呈现史源结论时以叙事语言自然融入，不加前缀。卡片可索引即可 |
| **推断** | 「推断：」 | 当篇来源未记载且无其他权威来源可参考 | **公认知识**、常识、逻辑推理、野史、传说 | 前缀与推理过程落位于备注；正文呈现推断结论时以叙事语言自然融入，不加前缀。**强制**：必须注明来源出处或推理过程 |
| **评论/比较/后世评价** | （无前缀） | — | 阐释性内容 | **分析性、评判性内容仅入备注**（落位于「延伸思考」「关联叙事方法」等阐释性小节），**禁入正文**；纵向联系等叙事性背景信息可入背景 |

### 2.4 概念语境锁定

对本篇关键名词（族群、地名、人名、制度、核心术语）锁定本篇语境所指，排查：

- **同名异指**：九夷（先秦 vs 汉代）、羿（尧时大羿 vs 夏初后羿）、跨代族群称谓
- **古今地名错位**：东海、会稽、洛阳、长安等
- **同名人物混淆**：跨代同名将相、同名诸侯
- **现代概念硬套古代**：封建、民主、国家、民族、经济等

存在跨时代同名异指者，备注简注辨析并指明本篇取义。

### 2.5 红线

1. **无据不写**——具体陈述必须对应出处卡；无卡即删除，或降为「推断：」
2. **分层不混**——编纂时代/所述事件时代/概念语境层不得混为一源（含同名异指、晚出追述、今古同名地）
3. **边界不越**——史源/推断/评论三层不得互相越位

## 3. 叙事语言

### 3.1 语体与形态

- **以叙事自然段详述**——正文须以流畅现代文讲清来龙去脉、人物动机与历史脉络，使读者不依赖古文也能完整理解
- **禁用分点、报告体、清单体**——正文全程保持叙事语体
- **古文按需括注引用**——确需出示原文时，优先以括注形式嵌入现代叙述（例：成汤誓师时声讨夏朝「罪恶深重、天命该灭」（有夏多罪，天命殛之）），或「白话在前、括注补原文」
- **整段原文的去处**——确属重要文献需完整呈现者，落入备注「史源原文」专项，不占正文空间
- **文白比例参考**：正文直引古文不宜超总字数 10%，单处连续引文不宜超 60 字。此为原则性参考，重在控制「古文堆砌感」
- **全篇形态一致**：正文从头到尾应保持一致的段落结构与叙事密度，以成熟文学作品的章节形态为参照。后半篇段落变短、空行变多、节奏破碎化是典型退化信号

### 3.2 立场

- 强调科普性、历史性、社会性；细致解释关键细节，避免文学化渲染与空泛表述
- 对民族冲突、起义、宗教争议、政权更迭保持中立克制，不做道德审判与煽情
- **文学线**：对原著立场保持中立复现，不替原著辩护亦不批驳

### 3.3 视角与阐释（启发性菜单，按需取用）

> 以下视角中，「纵向联系」属叙事性背景信息，可入背景；其余均属评论/比较/后世评价，仅入备注。数量与侧重由史料丰度与主题决定，无合适可不用；偏离常规时在备注简述理由。

**五类视角**：

1. **纵向联系**（宜入背景）——同一母题/制度的前代渊源或后世影响
2. **横向联系**（宜入备注）——同时期其他政权/区域/民族/文明的异同
3. **辩证视角**（宜入备注）——事件两面性、人物功过、短长期后果
4. **母题归纳**（宜入备注）——反复出现的政治/社会母题（会盟确权、禅让—篡位、封建—郡县转型等）
5. **阐释维度**（宜入备注）——制度机理 / 长时段·多重动因 / 地理—经济—生态 / 跨文明同期 / 概念史 / 史源对读 / 后世接受史 / 考古二重证据

### 3.4 拼音与括注

**标注准则**：生僻字、易误读字（含古音专读、多音歧义、通假异读）首次出现时标拼音；常见读音不标。例：亶 dǎn、殁 mò、彘 zhì、皋陶 yáo、会 kuài 稽、月氏 zhī、亶父之「父」fǔ、削 xuē 藩。同一篇内同一字词仅首次标注。以《现代汉语词典》《辞海》《古代汉语词典》等权威辞书为准。

**括注形式**：生僻概念、制度术语、易疑惑处的释义性括注，与拼音括注同理，首次出现时直接嵌入行文。

### 3.5 推理补全

背景、原因、上下文不可考证时须补必要推理完善情节，按 §2.3「**推断**：」处理。前缀与推理过程落位于备注，正文以叙事语言呈现结论。

## 4. 关联叙事方法

写作故事本体时，**每篇至少使用一种**关联叙事方法，帮助读者延伸阅读历史知识（允许兼具多种）：

| 方法 | 类型 | 含义 | 通用示例 |
|------|------|------|----------|
| **考证** | 验证型延伸 | 史料/原著分歧、出土文献补正、版本异文 | 苏秦年代争议、清华简补《竹书纪年》、《水浒传》繁本/简本差异 |
| **关联** | 网络型延伸 | 同期母题对照、纵向母题承接、原著与正史原型对照 | 三家分晋 ↔ 田氏代齐「卿代公」母题；草船借箭之文学虚构 ↔ 史实孙权借箭原型 |
| **对比** | 立体型延伸 | 不同势力处理同一事件、前后制度演变、同母题不同处理 | 李悝—吴起—商鞅—申不害变法路径；《三国演义》「空城计」与《三国志》裴注之异同 |

**显性对应要求**：在备注中明确标注本篇所用的关联叙事方法（考证/关联/对比的哪种或哪几种），并交代该方法在本篇的具体应用形态。无合适方法者须复核本篇是否值得独立成篇。

## 5. 文学线专项

**写作目标**：让未读过原著的读者获得**完整的阅读体验**，而非仅知道「发生了什么」。正文是**故事复现**而非情节概述——须以叙事段展开场景、行动、对话、转折。写作者在正文中只「讲故事」，不「评故事」——对回目结构的标注、对原著笔法的分析、对伏笔意图的阐释，一律归入备注「延伸思考」。

**叙事消化原则**（统摄本节所有条目）：写作者应**吸收原著素材后以现代叙事语言重新组织输出**，而非展示原文并附注释。忠实体现为情节走向一致，而非逐句引用—逐句解释的注疏体。正文的最终形态是**连续的现代小说叙事**——有段落节奏、有场景纵深、有衔接肌理，读起来像一部完整的故事，而非一份带译注的古文选读。

**名场面展开原则**：大众熟悉度高的经典场面（哪吒闹海、姜太公钓鱼、赤壁之战、武松打虎等）必须从原著充分汲取素材——具体场景描写、人物对白、动作链、原著诗词等不可省略。即使本篇合并了多回内容，重点场面仍须充分展开，不得以「篇幅有限」为由压缩为概括句。

**基本约束**：

- **忠实原著**：不发明原著没有的**情节事件**；允许以现代叙事语言重组场景呈现——对白可转为间接引语或现代化表述，场景可用叙事段重新组织，只要情节走向与因果不变
- **标注出处**：每篇标注对应原著篇目/回目/卷次
- **与正史出入**：列于备注「正史出入」专项（§6.3 备注内容清单），不喧宾夺主
- **回目顺序**：按原著回目顺序推进，不跳跃，不提前混入后续情节
- **关键语言引用**：仅**点睛式**节点须直接引用原文（名句、诗词、判语、回目证诗）；普通对白应消化为叙事转述或现代化对白，不逐句引用
- **延伸思考维度**（备注可选）：叙事技巧分析、主题张力解读、结构设计深层逻辑、人物塑造手法、母题变奏与互文
- **交叉引用**（备注末尾）：
  - 正史故事备注：`↗ 并行叙事：[作品名]中[人物/事件]见 [id]`
  - 并行故事备注：`↙ 正史参照：[事件]史实见 [id]`

## 6. 禁区与篇幅

### 6.1 禁区（红线全清单）

按主题分组，任一情况均不得违反：

| 主题 | 禁止项 |
|------|--------|
| **史料** | 无据不写；分层不混；边界不越（§2.5） |
| **正文形态** | 禁止分点、报告体、清单体；禁止 meta 内容（评论/结构标注/手法分析/意图解读）混入正文 |
| **叙事立场** | 禁止道德审判；禁止情绪化煽情 |
| **扩写** | 禁止无目的润色扩充；禁止虚构情节（**文学线**除外，文学线允许忠实复现原著情节） |
| **文学底线**（文学线） | 禁止改写原著情节；禁止混入正史情节为正文 |

### 6.2 篇幅参考

| 部分 | 参考下限 |
|------|---------|
| 正文 | 4000 字 |
| 备注 | 2000 字 |
| 合计 | 6000 字 |

此为**原则性参考**——判断依据是「内容是否讲透、来源是否充分、阐释是否到位」。输出后若明显感觉单薄，可对照参考下限评估是否需要通过正当路径扩写；内容已充实到位者，不必强行堆字。

**史料匮乏降档**：若某掌权阶段史料极度匮乏（正史无明确记载且考古证据有限），可降至合计 4000 字、正文 2500 字，但须在备注说明原因。

**弹性上调**：

- **文学线**：涉及多章回合并的篇，篇幅可进一步上浮
- **正史线**：长跨度时代（如周、汉、唐）的掌权阶段类篇目，篇幅可上浮

**扩写路径**：通读时若感到内容单薄，通过以下正当路径扩写——补充可核验来源、补足背景细节、解释制度与社会结构、展开场景与人物动机；若内容已充实到位，不必强行堆字。

### 6.3 备注内容清单

以下各项按当篇适用性选取，非全部必填。**推荐组织顺序**：出处卡 → 概念语境锁定 → 关联叙事方法 → 延伸思考 → 史源原文 → 正史出入/交叉引用。

- **出处卡**（对应 §2.1）
- **概念语境锁定**（对应 §2.4）
- **关联叙事方法**（对应 §4，强制必填，至少一种：考证/关联/对比）
- **延伸思考**：对应 §3.3 阐释维度
- **史源原文**（含长篇引文时）
- **正史出入 + 交叉引用**（仅文学线，对应 §5）

## 7. 校对

### 7.1 流程

重新读取已落盘文件，以落盘文件为唯一校对对象（不依赖生成过程中的记忆或中间稿），按 §7.3 Checklist 选用本线适用项逐项校对。任一项不通过须就地修订（不得仅口头声明），修订后回到本步重新校对；全部通过后更新进度。

### 7.2 独立验证（红线）

校对中涉及准确性（史实/情节/原文）的审查，**必须重新查询当篇的权威来源原文**独立校验——正史重新查权威史料原文，文学重新查原著原文。已写文本是验证对象，不得同时充当验证依据。

**禁止凭记忆校对**——任何对原文/史实的引用与判断，须基于当场可查证的权威来源；不得以"我记得是…""印象中…"作为依据。

### 7.3 弹性 Checklist（4 组，与正文解耦）

**使用原则**：先判断当前故事的特性（焦点维度、史料丰度、内容主题、所属叙事线），在心智层面确认每项是否适用，再逐项校对适用项。不适用的项目标注「N/A + 原因」跳过，**不得机械要求全部打勾**。

**执行机制（todo list 模式）**：本 Checklist 作为 todo list 逐项执行——校对时维护临时校对进程文档 `logs/contents/<era_dir>/<id>.proof.md`，按序记录每项校对结果（✅ 通过 / ❌ 不通过→修订记录 / N/A+原因），校对一条过一条，不跳项；全部通过后删除临时文档，转入 §4.5 进度更新。

> 排序原则：硬约束红线前置（最大注意力区），内容核心次之，形式规范再次，元数据篇幅收尾。
