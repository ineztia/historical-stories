# 写作与校对统一标准

---

## 总则

本系统的故事分两种叙事线：

- **正史**——以权威史料（二十四史、出土文献、可靠通史著作、现代学术研究）为底，史实为底线
- **文学**——以经典文学原著为底，忠实原著情节，标注「此为文学虚构」

**核心要求**：来源可溯、叙事纯净、正史/文学分流。正史线以权威史料为底线，文学线以原著情节为底线。

---

## 1. 故事输出形态

每篇固定三段，职能严格分工。

**背景**：承担**纵向脉络**（前代渊源、制度承袭）与**结构性背景**（地理、经济、社会结构）。

**正文**：承担叙事职能，身份锁定为「叙事者」。凡需跳出故事、以局外视角才能说出的话均禁入正文，仅入备注——包含评论、比较、后世评价、章回结构标注、叙事手法分析、创作意图解读等内容。

**备注**：承担来源标注、推理过程、阐释维度、延伸思考等一切非叙事内容，并按内容类型加前缀标注：「史源：」「推断：」「评论：」。

---

## 2. 背景

### 2.1 背景职能

背景承担**纵向脉络**（前代渊源、制度承袭）与**结构性背景**（地理、经济、社会结构）。

### 2.2 背景内容侧重

- **分卷导论**（结构性必备篇）：背景偏时代坐标与全局形势
- **势力展开类篇目**：背景偏本势力渊源与该期掌权者承接（须点名该期所有掌权者，哪怕一句话）
- **重大事件类篇目**：背景偏事件爆发前各势力态势的多视角聚拢
- **其余焦点**（人物传记、制度兴亡、思想文化、社会实态等）：灵活调配，背景围绕本篇主题的前因与结构性背景展开

## 3. 正文

### 3.1 语体与形态

- **以叙事自然段详述**——正文须以流畅现代文讲清来龙去脉、人物动机与历史脉络，使读者不依赖古文也能完整理解
- **禁用分点、报告体、清单体**——正文全程保持叙事语体
- **古文按需括注引用**——确需出示原文时优先以括注形式嵌入现代叙述（例：成汤誓师时声讨夏朝「罪恶深重、天命该灭」（有夏多罪，天命殛之）），或「白话在前、括注补原文」；正史线整段原文迁入备注「史源原文」专项；文学线按 §5 点睛式引用原则处理，不设「史源原文」专项
- **文白比例参考**：正文直引古文不宜超总字数 10%，单处连续引文不宜超 60 字。此为原则性参考，重在控制「古文堆砌感」
- **全篇形态一致**：正文从头到尾应保持一致的段落结构与叙事密度，以成熟文学作品的章节形态为参照；后半篇段落变短、空行变多、节奏破碎化是典型退化信号

### 3.2 社会实态维度

历史不仅是政治事件序列，更是社会系统各维度的交织运行。每篇须自然交织以下维度，不必逐项罗列：

- **权力与制度**：统治方式、合法性来源、制度运作
- **经济与生产**：生产方式、贸易、赋役、物资动员
- **宗教与信仰**：祭祀体系、宗教行为（含人殉、人牲等暴力祭祀）、信仰与权力的关系
- **社会分层与暴力**：阶层结构、奴隶制、刑罚、战争的社会后果
- **物质文化与技术**：建筑、器物、工艺所反映的社会组织水平

重大事件须呈现因果闭环：**上游（什么条件使之发生）→ 事件本身 → 下游（什么社会后果）→ 反馈回系统**。

考古/出土证据确证的重大社会现象不得回避。

### 3.3 立场

- 强调科普性、历史性、社会性；细致解释关键细节，避免文学化渲染与空泛表述
- 对民族冲突、起义、宗教争议、政权更迭保持中立克制，不做道德审判与煽情
- **文学线**：对原著立场保持中立复现，不替原著辩护亦不批驳

### 3.4 标注规则

以下四项标注规则均遵循「同一篇内同一对象仅首次标注」的节制原则，但触发条件不同：拼音、概念释义、同名称谓在对象首次出现时标注；随文注在关键剧情需要即时说明时标注。四子节针对不同场景与对象，互不替代。

#### 3.4.1 拼音标注

生僻字、易误读字（含古音专读、多音歧义、通假异读）首次出现时标拼音；常见读音不标。例：亶 dǎn、殁 mò、彘 zhì、皋陶 yáo、会 kuài 稽、月氏 zhī、亶父之「父」fǔ、削 xuē 藩。同一篇内同一字词仅首次标注。以《现代汉语词典》、《辞海》、《古代汉语词典》等权威辞书为准。

**出土文献/古专名**（商周及更早的人名、族名、方国名）出现时须特别留意——这些专名多无现代普通话通用读音，常见标注有：妇好 fù hǎo、妲己 dá jǐ（有争议）、西伯姬昌（周文王名「昌」，姓「姬」，二者勿混）、王亥 wáng hǎi、卜辞 bǔ cí。无法确定时括注"音未详"或参考《甲骨文合集》、《殷周金文集成》释文与《古文字诂林》。同一篇内同一字词仅首次标注。

#### 3.4.2 概念释义括注

对现代读者可能陌生的历史概念：

- **覆盖对象**：官职、制度、器物、族群、古地名、核心术语等。示例：亚相（副相）、司空（掌工程）、簋（guǐ，盛食礼器）、九夷（东方部落泛称）
- **判断标准**：面向「历史爱好者」而非专业学者——当代通识中已常见的概念不标（如「丞相」「刺史」），生僻或古今义异的概念必标
- **程度**：点明足以理解当下叙事的职能或含义即可，不展开考据；长释义归入背景或备注
- 同一篇内同一概念仅首次括注

#### 3.4.3 同名称谓解析

排查本篇关键名词是否存在跨时代或跨语境的同名异指，仅在确有混淆风险时辨析：

- **同名异指**：九夷（先秦 vs 汉代）、羿（尧时大羿 vs 夏初后羿）、跨代族群称谓
- **古今地名错位**：东海、会稽、洛阳、长安等
- **同名人物混淆**：跨代同名将相、同名诸侯
- **时代消歧**：编纂时代与所述事件时代不得混为一源（含晚出追述、同名异指的跨时代混淆）

#### 3.4.4 随文注

正文中可用括号做轻量即时说明，帮助读者理解关键剧情、消解当下阅读障碍。形式为「（注：……）」，长度以不中断叙事节奏为限。同一篇内同一事项只注一次。

**适用于**：必要背景补白、同名异指消歧、关键因果关系点明、轻量史料说明。

### 3.5 推断结论的呈现

背景、原因、上下文不可考证时须补必要推理完善情节。推断素材可包括公认知识、常识、逻辑推理、野史、传说，但须在备注注明其可靠性边界。

- **正文**：只呈现结论，以叙事语言自然融入，不标「推断：」前缀。
- **备注**：展示推理过程、证据来源、多源矛盾及延伸研讨，以「推断：」前缀标注，强制注明来源出处或推理过程。

**示例**：

- 正文：「伏羲画卦的传说虽带有神话色彩，但其历史内核可能对应新石器时代先民长期观察自然、积累符号思维的漫长过程。」
- 备注：「推断：伏羲画卦的具体年代无直接考古证据，上述对应关系基于贾湖刻符、大汶口陶符等符号思维实物与文献传说的间接推理。」

## 4. 备注

### 4.1 备注职能与前缀

备注承担来源标注、推理过程、阐释维度、延伸思考等一切非叙事内容，并按内容类型加前缀标注：

- 「史源：」——来源与证据说明
- 「推断：」——推理过程与不可考证之处的补全
- 「评论：」——比较、后世评价、手法分析等局外视角内容

### 4.2 史源索引（落笔前预研，记入备注）

**两线分流**：

- **正史线**——建 6 字段史源索引（含「关键原文摘句」），保障史实可溯（史料分散、版本异文多、须独立查证）
- **文学线**——建 5 字段简化索引（去掉「关键原文摘句」），用于出处锚定与正史异同对照；原著单一可查阅，不摘录原文进备注、不设「史源原文」专项

**字段**：

正史线（6 字段）：

| 字段 | 填法 |
|------|------|
| 1. 来源名·篇目 | 如「《史记·五帝本纪》」 |
| 2. 编纂/成书时代 | 史书编纂时代 |
| 3. 所述事件时代 | 本篇事件的历史时代 |
| 4. 体裁等级 | 正史/编年/类书/诸子/野史/笔记/志怪/出土文献/现代研究 |
| 5. 关键原文摘句（≤60 字） | 须为原书可检索实句，禁复述改写；现代研究引用核心结论或关键数据 |
| 6. 互证/对照状态 | 孤证/双证/多证 |

文学线（5 字段）：

| 字段 | 填法 |
|------|------|
| 1. 来源名·篇目 | 如「《封神演义》第一回」 |
| 2. 编纂/成书时代 | 原著成书时代 |
| 3. 所述事件时代 | 本篇事件的历史时代 |
| 4. 体裁等级 | 长篇神魔小说/章回体/笔记体等 |
| 5. 互证/对照状态 | 与正史异同 / 无对照 |

**形态约束**：表格按来源行组织，字段作为表头列横向铺开；禁逐条铺成纵向小表堆叠。同一原著/同一史书的多条来源，其重复字段（编纂时代、体裁等级、所述事件时代、互证状态）可用「同上」或空值合并，但须在表下「史源说明」中统一交代。

### 4.3 证据处理

**核心原则**：来源必须有据，按可靠性层级使用。权威来源（正史/编年/出土文献/学术研究）> 补充来源（野史/笔记/志怪/民间传说）；权威来源间矛盾，依现代研究或逻辑推理判断。本原则主要约束正史线；文学线证据处理见 §5。

以核心原则为第一性原理，按以下三层递进处理：

**第一层·来源分级**：
- 权威来源（二十四史、可靠通史、出土文献、学术研究）> 补充来源（野史、笔记、志怪、民间传说）
- 补充来源须标注体裁等级与可靠性边界

**第二层·可靠性判断**：
- 时代贴近度：同时代一手证据的事实陈述权重不低于后世追述性正史；后世正史的综合性叙事框架仍有组织价值，但不得以「正史未载」为由排斥同时代实证
- 学术研究引用（正史专项）：属权威来源，可引用权威学术期刊（CSSCI/SSCI/A&HCI 及《历史研究》《考古》《文物》《中国史研究》等）、高校学报、专业机构论文与专著；出处卡体裁等级标「现代研究」，须注明作者·年份·篇名·刊名/出版社

**第三层·矛盾与孤证**（正史）：
- 权威间矛盾：同一事件在两部以上权威史料矛盾时，依现代研究或逻辑推理判断，正文谨慎措辞（「有说法认为……」「部分史料记载……」），备注列主要分歧与来源；古文原文入备注并标注出处，篇幅过长可摘关键句仍须标注
- 孤证：正文以「据某书」「一说」等限定语处理；备注注明孤证

### 4.4 阐释方法

本节所列仅供备注延伸思考使用，不进入正文。

**硬规则**：纵向联系（前代渊源/后世影响）属叙事性背景信息，可入背景；其余阐释性内容（横向联系、辩证视角、母题归纳、阐释维度——含制度机理/长时段·多重动因/地理—经济—生态/跨文明同期/概念史/史源对读/后世接受史/考古二重证据）一律仅入备注。数量与侧重由史料丰度与主题决定；偏离常规时在备注简述理由。

### 4.5 内容清单

以下各项按当篇适用性选取，非全部必填。

**正史线推荐组织顺序**：出处卡 → 关联叙事方法 → 延伸思考 → 史源原文。

**文学线推荐组织顺序**：出处卡（简化索引）→ 关联叙事方法 → 延伸思考 → 正史出入/交叉引用。

- **出处卡**（正史线 6 字段 / 文学线 5 字段简化版，对应 §4.2）
- **关联叙事方法**（对应 §6，强制必填，至少一种：考证/关联/对比）
- **延伸思考**：对应 §4.4 阐释维度
- **史源原文**（正史线，含长篇引文时；文学线不设此专项）
- **正史出入 + 交叉引用**（仅文学线，对应 §5）

## 5. 文学线专项

**写作目标**：让未读过原著的读者获得**完整的阅读体验**，而非仅知道「发生了什么」。正文是**故事复现**而非情节概述——须以叙事段展开场景、行动、对话、转折。写作者在正文中只「讲故事」，不「评故事」——对回目结构的标注、对原著笔法的分析、对伏笔意图的阐释，一律归入备注「延伸思考」。

**叙事消化原则**（统摄本节所有条目）：写作者应**吸收原著素材后以现代叙事语言重新组织输出**，而非展示原文并附注释。忠实体现为情节走向一致，而非逐句引用—逐句解释的注疏体。正文的最终形态是**连续的现代小说叙事**——有段落节奏、有场景纵深、有衔接肌理，读起来像一部完整的故事，而非一份带译注的古文选读。

**名场面展开原则**：大众熟悉度高的经典场面（哪吒闹海、姜太公钓鱼、赤壁之战、武松打虎等）必须从原著充分汲取素材——具体场景描写、人物对白、动作链、原著诗词等不可省略。即使本篇合并了多回内容，重点场面仍须充分展开，不得以「篇幅有限」为由压缩为概括句。

**基本约束**：

- **忠实原著**：不发明原著没有的**情节事件**；允许以现代叙事语言重组场景呈现——对白可转为间接引语或现代化表述，场景可用叙事段重新组织，只要情节走向与因果不变
- **标注出处**：每篇标注对应原著篇目/回目/卷次；备注建 §4.2 简化索引（5 字段，不含原文摘句），不设「史源原文」专项
- **与正史出入**：列于备注「正史出入」专项（§4.5 备注内容清单），不喧宾夺主
- **回目顺序**：按原著回目顺序推进，不跳跃，不提前混入后续情节
- **关键语言引用**：仅**点睛式**节点须直接引用原文（名句、诗词、判语、回目证诗）；普通对白应消化为叙事转述或现代化对白，不逐句引用
- **延伸思考维度**（备注可选）：叙事技巧分析、主题张力解读、结构设计深层逻辑、人物塑造手法、母题变奏与互文
- **交叉引用**（备注末尾）：
  - 正史故事备注：`↗ 并行叙事：[作品名]中[人物/事件]见 [id]`
  - 并行故事备注：`↙ 正史参照：[事件]史实见 [id]`

## 6. 关联叙事方法

写作故事本体时，**每篇至少使用一种**关联叙事方法，帮助读者延伸阅读历史知识（允许兼具多种）：

| 方法 | 类型 | 含义 | 通用示例 |
|------|------|------|----------|
| **考证** | 验证型延伸 | 史料/原著分歧、出土文献补正、版本异文 | 苏秦年代争议、清华简补《竹书纪年》、《水浒传》繁本/简本差异 |
| **关联** | 网络型延伸 | 同期母题对照、纵向母题承接、原著与正史原型对照 | 三家分晋 ↔ 田氏代齐「卿代公」母题；草船借箭之文学虚构 ↔ 史实孙权借箭原型 |
| **对比** | 立体型延伸 | 不同势力处理同一事件、前后制度演变、同母题不同处理 | 李悝—吴起—商鞅—申不害变法路径；《三国演义》「空城计」与《三国志》裴注之异同 |

**显性对应要求**：在备注中明确标注本篇所用的关联叙事方法（考证/关联/对比的哪种或哪几种），并交代该方法在本篇的具体应用形态。当本篇同时满足以下情形时，视为无合适方法：无权威史料分歧、无跨势力/跨期对照、无纵向母题承接、无版本异文。此时 AI 应暂停并复问用户——是否将本篇并入相邻高密度篇目、保留为备选题库、或坚持独立成篇。

## 7. 禁区与篇幅

### 7.1 禁区（红线全清单）

按主题分组，任一情况均不得违反：

| 主题 | 禁止项 |
|------|--------|
| **史料** | 见 §4.3（来源可靠性层级） |
| **正文形态** | 禁止分点、报告体、清单体；禁止 meta 内容（评论/结构标注/手法分析/意图解读）混入正文 |
| **叙事立场** | 禁止道德审判；禁止情绪化煽情 |
| **扩写** | 禁止无目的润色扩充；禁止虚构情节（**文学线**除外，文学线允许忠实复现原著情节） |
| **文学底线**（文学线） | 禁止改写原著情节；禁止混入正史情节为正文 |

### 7.2 篇幅参考

| 部分 | 参考下限 |
|------|---------|
| 正文 | 4000 字 |
| 备注 | 2000 字 |
| 合计 | 6000 字 |

上表为**参考区间**，判断核心是「内容是否讲透、来源是否充分、阐释是否到位」。内容已充实到位者，不必强行堆字；若感觉单薄，应通过补充可核验来源、补足背景细节、解释制度与社会结构、展开场景与人物动机等正当路径扩写，禁止为凑字数无目的润色。

**史料匮乏降档**：若某掌权阶段史料极度匮乏（正史无明确记载且考古证据有限），可降至合计 4000 字、正文 2500 字，但须在备注说明原因。

**弹性上调**：

- **文学线**：涉及多章回合并的篇，篇幅可进一步上浮
- **正史线**：长跨度时代（如周、汉、唐）的掌权阶段类篇目，篇幅可上浮

## 8. 校对

### 8.1 流程

重新读取已落盘文件，以落盘文件为唯一校对对象（不依赖生成过程中的记忆或中间稿）。先判断本篇特性（焦点维度、史料丰度、内容主题、所属叙事线），再按 §8.3 Checklist 选用适用项逐项校对。任一项不通过须就地修订（不得仅口头声明），修订后回到本步重新校对；全部通过后更新进度。

### 8.2 独立验证（红线）

校对中涉及准确性（史实/情节/原文）的审查，**必须重新查询当篇的权威来源原文**独立校验——正史重新查权威史料原文，文学重新查原著原文。已写文本是验证对象，不得同时充当验证依据。

### 8.3 弹性 Checklist（4 组，与正文解耦）

**使用原则**：每项是否适用由 §8.1 在执行前判定；只校对判定为适用的项目，不适用的标注「N/A + 原因」跳过，**不得机械要求全部打勾**。

**执行机制（todo list 模式）**：校对时维护临时校对进程文档 `logs/contents/<era_dir>/<id>.proof.md`，按序记录每项校对结果（✅ 通过 / ❌ 不通过→修订记录 / N/A+原因），校对一条过一条，不跳项；全部通过后删除临时文档，转入 [AGENTS.md §4.5](../AGENTS.md) 进度更新。若当篇内容简单或红线项无风险，可用简化记录（仅列不通过项与修订记录）。

> 排序原则：硬约束红线前置（最大注意力区），内容核心次之，形式规范再次，元数据篇幅收尾。
