# 写作与校对统一标准

---

## 总则

本系统的故事分两种叙事线：

- **正史**——以权威史料（二十四史、出土文献、可靠通史著作、现代学术研究）为底，史实为底线
- **文学**——以经典文学原著为底，忠实原著情节，标注「此为文学虚构」

**核心要求**：来源可溯、叙事纯净、正史/文学分流。正史线以权威史料为底线，文学线以原著情节为底线。

---

## 1. 故事输出形态

每篇固定三段，职能严格分工。

**背景**：承担**纵向脉络**（前代渊源、制度承袭）与**结构性背景**（地理、经济、社会结构）。

**正文**：承担叙事职能，身份锁定为「叙事者」。凡需跳出故事、以局外视角才能说出的话均禁入正文，仅入备注——包含评论、比较、后世评价、章回结构标注、叙事手法分析、创作意图解读等内容。

**备注**：承担来源标注、推理过程、延伸思考等一切非叙事内容，并按内容类型加前缀标注：「史源：」「推断：」「评论：」。

---

## 2. 背景

### 2.1 背景职能

背景承担**纵向脉络**（前代渊源、制度承袭）与**结构性背景**（地理、经济、社会结构）。

### 2.2 背景内容侧重

- **分卷导论**（结构性必备篇）：背景偏时代坐标与全局形势
- **势力展开类篇目**：背景偏本势力渊源与该期掌权者承接（须点名该期所有掌权者，哪怕一句话）
- **重大事件类篇目**：背景偏事件爆发前各势力态势的多视角聚拢
- **其余焦点**（人物传记、制度兴亡、思想文化、社会实态等）：灵活调配，背景围绕本篇主题的前因与结构性背景展开

## 3. 正文

### 3.1 叙事语体与质量标准

**语体总纲**

正文以现代汉语自然叙事为主，用当代读者可自然理解的语体讲述。正文只呈现叙事内容，禁止分点、报告体、清单体、百科体、评论体。

**正文质量清单**

1. **叙事驱动**：正文通过场景与细节传递知识；不脱离叙事做百科式介绍。
2. **叙事节奏**：按事件推进自然分段，信息释放有张有弛；保持全篇密度相对均衡，避免前松后紧、中段塌陷或结尾急促。
3. **信息密度**：每段须同时承担叙事推进或知识传递功能；删除空话、重复内容与硬塞式铺陈。
4. **沉浸感**：用具体场景、人物动作、对话与时代细节还原历史情境，避免纯概念陈述。
5. **语言质感**：使用现代汉语自然叙事，准确、生动、有节奏；避免欧化长句、文言腔、口号腔与词藻堆砌，正文以客观陈述为主。
6. **古文轻量引用**：确需出示古文时采用「白话在前、括注补原文」的轻量形式；整段古文、长篇引文及史源原文归入备注或史料索引。

### 3.2 正文内容承载

正文承担叙事职能。所有进入正文的内容都须服务于叙事推进和读者理解，而不是为了展示知识或证明观点。

**核心原则**
- **以人物与事件为线索**：正文通过人物行动和事件进程传递历史知识，不脱离叙事做百科式介绍。
- **知识为叙事服务**：政治、经济、军事、社会、文化、艺术、科学、思想、地理、生态、考古发现等知识均可进入正文，但须回答：它如何帮助读者理解当下的人物选择或事件走向？
- **讲清事件因果**：正文须交代关键事件的来龙去脉——什么条件导致它发生，它又产生了什么后果。跨事件、跨时代的深层关联与阐释性分析归入背景或备注。

### 3.3 标注规则

以下四项标注规则均遵循「同一篇内同一对象仅首次标注」的节制原则，但触发条件不同：拼音、概念释义、同名称谓在对象首次出现时标注；随文注在关键剧情需要即时说明时标注。四小节针对不同场景与对象，互不替代。

#### 3.3.1 拼音标注

生僻字、易误读字（含古音专读、多音歧义、通假异读）首次出现时标拼音；常见读音不标。例：亶 dǎn、殁 mò、彘 zhì、皋陶 yáo、会 kuài 稽、月氏 zhī、亶父之「父」fǔ、削 xuē 藩。同一篇内同一字词仅首次标注。以《现代汉语词典》、《辞海》、《古代汉语词典》等权威辞书为准。

**出土文献/古专名**（商周及更早的人名、族名、方国名）出现时须特别留意——这些专名多无现代普通话通用读音，常见标注有：妇好 fù hǎo、妲己 dá jǐ（有争议）、西伯姬昌（周文王名「昌」，姓「姬」，二者勿混）、王亥 wáng hǎi、卜辞 bǔ cí。无法确定时括注"音未详"或参考《甲骨文合集》、《殷周金文集成》释文与《古文字诂林》。同一篇内同一字词仅首次标注。

#### 3.3.2 概念释义括注

对现代读者可能陌生的历史概念：

- **覆盖对象**：官职、制度、器物、族群、古地名、核心术语等。示例：亚相（副相）、司空（掌工程）、簋（guǐ，盛食礼器）、九夷（东方部落泛称）
- **判断标准**：面向「历史爱好者」而非专业学者——当代通识中已常见的概念不标（如「丞相」「刺史」），生僻或古今义异的概念必标
- **程度**：点明足以理解当下叙事的职能或含义即可，不展开考据；长释义归入背景或备注
- 同一篇内同一概念仅首次括注

#### 3.3.3 同名称谓解析

排查本篇关键名词是否存在跨时代或跨语境的同名异指，仅在确有混淆风险时辨析：

- **同名异指**：九夷（先秦 vs 汉代）、羿（尧时大羿 vs 夏初后羿）、跨代族群称谓
- **古今地名错位**：东海、会稽、洛阳、长安等
- **同名人物混淆**：跨代同名将相、同名诸侯
- **时代消歧**：编纂时代与所述事件时代不得混为一源（含晚出追述、同名异指的跨时代混淆）

#### 3.3.4 随文注

正文中可用括号做轻量即时说明，帮助读者理解关键剧情、消解当下阅读障碍。形式为「（注：……）」，长度以不中断叙事节奏为限。同一篇内同一事项只注一次。

**适用于**：必要背景补白、同名异指消歧、关键因果关系点明、轻量史料说明。

### 3.4 推断结论的呈现

背景、原因、上下文不可考证时须补必要推理完善情节。推断素材可包括公认知识、常识、逻辑推理、野史、传说，但须在备注注明其可靠性边界。

- **正文**：只呈现结论，以叙事语言自然融入，不标「推断：」前缀。
- **备注**：展示推理过程、证据来源、多源矛盾及延伸研讨，以「推断：」前缀标注，强制注明来源出处或推理过程。

**示例**：

- 正文：「伏羲画卦的传说虽带有神话色彩，但其历史内核可能对应新石器时代先民长期观察自然、积累符号思维的漫长过程。」
- 备注：「推断：伏羲画卦的具体年代无直接考古证据，上述对应关系基于贾湖刻符、大汶口陶符等符号思维实物与文献传说的间接推理。」

## 4. 备注

### 4.1 备注职能与前缀

备注承担来源标注、推理过程、延伸思考等一切非叙事内容，并按内容类型加前缀标注：

- 「史源：」——来源与证据说明
- 「推断：」——推理过程与不可考证之处的补全
- 「评论：」——比较、后世评价、手法分析等局外视角内容

### 4.2 史源索引（落笔前预研，记入备注）

**两线分流**：

- **正史线**——建 6 字段史源索引（含「关键原文摘句」），保障史实可溯（史料分散、版本异文多、须独立查证）
- **文学线**——建 5 字段简化索引（去掉「关键原文摘句」），用于出处锚定与正史异同对照；原著单一可查阅，不摘录原文进备注、不设「史源原文」专项

**字段**：

正史线（6 字段）：

| 字段 | 填法 |
|------|------|
| 1. 来源名·篇目 | 如「《史记·五帝本纪》」 |
| 2. 编纂/成书时代 | 史书编纂时代 |
| 3. 所述事件时代 | 本篇事件的历史时代 |
| 4. 体裁等级 | 正史/编年/类书/诸子/野史/笔记/志怪/出土文献/现代研究 |
| 5. 关键原文摘句（≤60 字） | 须为原书可检索实句，禁复述改写；现代研究引用核心结论或关键数据 |
| 6. 互证/对照状态 | 孤证/双证/多证 |

文学线（5 字段）：

| 字段 | 填法 |
|------|------|
| 1. 来源名·篇目 | 如「《封神演义》第一回」 |
| 2. 编纂/成书时代 | 原著成书时代 |
| 3. 所述事件时代 | 本篇事件的历史时代 |
| 4. 体裁等级 | 长篇神魔小说/章回体/笔记体等 |
| 5. 互证、对照状态 | 与正史异同、无对照 |

**形态约束**：表格按来源行组织，字段作为表头列横向铺开；禁逐条铺成纵向小表堆叠。同一原著/同一史书的多条来源，其重复字段（编纂时代、体裁等级、所述事件时代、互证状态）可用「同上」或空值合并，但须在表下「史源说明」中统一交代。

### 4.3 证据处理

**核心原则**
来源必须有据，按可靠性层级使用。权威来源优先，补充来源须标注边界；权威来源间矛盾时，依现代研究或逻辑推理判断。

**来源分级**

| 层级 | 类型 |
|------|------|
| 权威来源 | 正史、编年、出土文献与考古发现、学术研究 |
| 补充来源 | 野史、笔记、志怪、民间传说 |

**使用规则**
- **一手优先**：同时代一手证据的事实陈述权重不低于后世追述。
- **矛盾处理**：权威来源矛盾时，正文谨慎措辞，备注列主要分歧与来源。
- **孤证处理**：正文以限定语处理，备注注明孤证。
- **学术引用**：注明作者、年份、篇名、刊名/出版社；出处卡体裁等级标「现代研究」。

**文学线**
文学线证据处理见 §5。

### 4.4 备注内容组织

备注承载正文无法容纳的内容，按功能分为三类：

**1. 来源与证据**
- **出处卡**：史源索引，见 §4.2。
- **史源原文**：正史线长篇古文引文；文学线不设此专项。

**2. 推理与判断**
- **推断说明**：不可考证之处的推理过程与可靠性边界。

**3. 阐释与延伸**
- **延伸思考**：横向联系、跨时代比较、后世影响、概念演变等阐释性内容。
- **关联叙事方法**：在备注中显性说明本篇所用的考证/关联/对比及其具体应用，见 §6。
- **正史出入、交叉引用**（仅文学线）：说明与正史差异，标注参照篇目。格式示例：
  - 正史故事备注：`↗ 并行叙事：[作品名]中[人物/事件]见 [id]`
  - 并行故事备注：`↙ 正史参照：[事件]史实见 [id]`

**组织原则**
- 按「来源 → 推理 → 阐释」顺序排列。
- 评论、比较、后世评价、手法分析等局外视角内容仅入备注，不得进入正文。
- 只写对理解故事有必要的内容，不做无目的展示。

## 5. 文学线专项

文学线以经典文学原著为底，目标是让未读过原著的读者获得**完整的阅读体验**。

**核心原则**
- **故事复现**：以叙事段展开场景、行动、对话、转折，不是情节概述。
- **忠实原著**：不发明原著没有的情节事件；允许以现代叙事语言重组场景和表述。
- **名场面充分展开**：大众熟悉的经典场面须从原著汲取素材，充分呈现场景、对白、动作链、原著诗词。
- **消化式表达**：吸收原著素材后以现代叙事语言重新组织，不逐句引用—逐句解释。

**与正史的关系**
- 文学线正文只讲故事，不混入正史情节。
- 与正史的出入、原型对照等放入备注「正史出入/交叉引用」专项。

**引用与索引**
- 每篇标注对应原著篇目/回目/卷次。
- 关键节点可点睛式引用原文（名句、诗词、判语、回目证诗）；普通对白消化为叙事转述。
- 备注建 §4.2 简化索引（5 字段），不设「史源原文」专项。

**回目与衔接**
- 按原著回目顺序推进，不跳跃，不提前混入后续情节。
- 被略过回目的关键事件若为本篇理解所必需，以桥段补入正文。

## 6. 关联叙事方法

关联叙事方法是在叙事中帮助读者建立知识连接、触类旁通的手段。使用时须在备注「延伸思考」中显性说明具体应用。

**三种基本方法**

- **考证**：对史料分歧、出土文献补正、版本异文等进行辨析。示例：苏秦年代争议、清华简补《竹书纪年》。
- **关联**：建立同期母题、纵向母题或文学原型之间的对照。示例：三家分晋与田氏代齐的「卿代公」母题。
- **对比**：展示不同势力、前后制度或同母题的不同处理。示例：李悝—吴起—商鞅—申不害变法路径。

**使用原则**
- **服务于叙事**：关联方法须自然融入故事，不为了使用而使用。
- **按主题选择**：史料无分歧、无对照、无母题承接时，不必强行使用。
- **显性说明**：使用关联方法时，须在备注中说明用了哪种方法及具体应用。

## 7. 禁区与篇幅

### 7.1 禁区

以下情况绝对禁止：

- **史料红线**：不得使用无法标注来源或可靠性边界的内容；不得虚构史料。
- **正文红线**：禁止分点、报告体、清单体；禁止局外视角内容（评论、比较、后世评价、手法分析、创作意图解读等需跳出故事才能说出的话）混入正文。
- **立场红线**：禁止道德审判与情绪化煽情；对政治、宗教、文化、习俗等保持中立。
- **扩写红线**：禁止无目的润色扩充；禁止为凑字数硬加内容。
- **文学线红线**：禁止改写原著情节；禁止将正史情节混入文学线正文。

### 7.2 篇幅参考

篇幅以「讲透、来源充分、阐释到位」为核心判断标准，不机械追求字数。

- **正文**：参考下限 4000 字
- **备注**：参考下限 2000 字
- **合计**：参考下限 6000 字

**降档**：史料极度匮乏时，可降至合计 4000 字、正文 2500 字，须在备注说明原因。

**上调**：文学线多章回合并篇，或正史线长跨度掌权阶段篇，可适度上浮。

## 8. 校对

### 8.1 流程

校对必须以落盘文件为唯一对象，按【校对各环节】执行。**任一环节未通过，不得进入下一环节**。

1. **创建校对文档**：在 `logs/contents/<era_dir>/<id>.proof.md` 建立校对记录文件，按 §8.3 的校对内容阶段和项目建立表格。
2. **逐项校对并独立验证**：按 §8.3 各环节顺序逐项审查，在 proof 文档中记录结果。
   - 涉及史实、情节、原文准确性的审查，须重新查询当篇权威来源原文（正史查史料，文学查原著），在 proof 文档「独立验证记录」中记录查证来源；已写文本是验证对象，不得同时作为验证依据。
   - 涉及叙事质量的审查，须以读者视角通读全文，标记阅读体验卡点（节奏、沉浸、密度、语言、张力），在 proof 文档「通读记录」中记录具体位置与问题。
3. **就地修订**：任一 ❌ 须修订原文后，回到该环节起点重新校对。
4. **完成校对**：各环节全部通过后，删除 proof 文档，更新进度。

**重要**：未生成 proof 文件、或 proof 文件未全部通过，均视为校对未完成。AI 不得口头宣称已校对。

### 8.2 校对文档（强制）

校对时必须创建 `logs/contents/<era_dir>/<id>.proof.md`。proof 文件按 §8.3 的校对内容阶段和项目建立表格，逐项记录结果。文件结构与符号约定见 file-spec.md。

proof 文件必须真实存在，不得口头声明。每项结果只能是：
- **✅ 通过**
- **❌ 不通过**（须修订后重新校对）
- **➖ 不适用 + 原因**

### 8.3 校对内容阶段

#### 阶段 1：红线（硬约束，必须先过）

- 史料来源符合 §4.3 可靠性层级；无虚构史料。
- 史源索引齐备；非正史来源已标注可靠性边界；孤证、争议已按规定处理。
- 正文无局外视角内容（评论、比较、后世评价、手法分析、创作意图解读等）。
