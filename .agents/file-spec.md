> 命名与路径规则见 [AGENTS.md §5](../AGENTS.md)；本文件定义文件内部格式（YAML 元数据、状态符号、结构模板、写入规则）。

---

## 1. logs/eras/*.md 结构模板

### 1.1 形态约束（正史/文学通用）

- **头部**：1 段引言（blockquote），含图谱说明与正史参照（文学线须标注「并行叙事线·文学线」并链接正史线文件）
- **章节正文**：按需组织「图谱块、故事列表、备选题库」三大块（图谱块按线取：正史线 → §1.3 传承图谱，文学线 → §1.4 底本图谱）
- **流程标注分流**：故事级状态符号（⏳/✅）属于图谱内容，保留在时代文件故事列表中；其余执行痕迹（已确认、修订日期、用户裁决标记等）一律写入 `logs/progress.md`，**不得混入时代文件正文**

### 1.2 通用骨架模板（正史/文学通用）

> 以下模板为两线通用骨架：`[方括号文字]` 为占位符（输出时替换）。图谱块按线替换——正史线用 §1.3 传承图谱块，文学线用 §1.4 底本图谱块；一级标题后缀随线取「传承图谱/底本图谱」；图谱字段填写规则见对应图谱块（不写入输出文件）。

```markdown
# 时代名称 - {传承图谱/底本图谱}

> [图谱说明 + 正史参照的一句话引言；文学线须标注「并行叙事线·文学线」并链接正史线文件]
> - 类型：正史、文学（并行叙事线·文学线）
> - 正史参照：[正史线文件链接或时代名]（文学线必填，正史线填「本文件」或留空）

[图谱块——正史线：§1.3 传承图谱；文学线：§1.4 底本图谱]

## 故事列表

### 掌权阶段/时期名称（N）
```

### 1.3 正史线图谱块：传承图谱

> 仅正史线使用；文学线不适用。

```markdown
## 传承图谱

[简洁的时代传承描述]

| 掌权阶段 | 统治者/权力中心 | 时间范围·时长（约） | 继承关系 | 备注 | 对应故事 |
|---------|----------------|---------------|---------|------|---------|
| 1 | 黄帝 | 约前 2717–前 2599 年（约 98 年） | — | 开国 | #1、#2 |
| 2 | 颛顼 | 约前 2514–前 2437 年（约 77 年） | 黄帝之孙，昌意之子 | 孙继祖 | #3 |
| ... | ... | ... | ... | ... | ... |
```

字段填写规则（不写入输出文件）：

**继承关系**：
- 记录血缘（「某之子/孙」）或政治（「禅让/篡位/拥立」）关系，优先血缘
- 并存须均标注（「帝喾之子，禅让」）
- 史料分歧以主流为主，分歧在备注说明

**「时间范围·时长」列格式**：
- 可计算：`约前XXX-前XXX年（约N年）`
- 时长不详：`不详（？年）`或 `约某时期（？年）`
- 未即位：`未即位`（不标时长）

**行单元粒度**（按时代类型分层）：
- **单一政权时代**：每位掌权者一行；史料极稀薄者可并入折叠行
- **多势力并立时代**：行单元为「势力×时段」——时段内含家喻户晓/结构性转折掌权者（对应故事优先级「高」）则展开成行，此类掌权者逐人成行（默认行，无需标注）；其余时段一律**折叠为一行**：统治者列写「势力｜起讫代称（N 任）」（如 `郑｜厉公—声公（15 任）`、`周王室｜平王—敬王（14 任）`），备注列以「折叠：N 任」开头，继承关系列可写「从略，正文承接时交代」

**覆盖底线**：图谱表格是时间轴连续性的唯一呈现载体——所有有记载的掌权者须在表内有位置（独立行或折叠行名录内），无对应故事者也须以折叠行占位并在备注列说明原因；跨卷长世系（如东周王室）按分卷拆行，保证各段传承表内可见；禁止以表格外说明替代表格位置。

**「对应故事」列规格**：
- 每个图谱行至少一个标注（不允许空值），允许值：编号（多值用「、」分隔，连续区间可用 `#A–#B` 简写）、`无对应故事`、`并入 #X`（融合进其他故事）；折叠行填该势力展开篇编号并加 `（承接）`，确无承接故事者标 `无对应故事` 或 `并入 #X` 并在备注列说明原因
- **主篇**（掌权者为主体）：无需额外标注
- **群像篇**（单一政权时期多人共一篇群像）：编号后加 `（群像）`
- **附篇承接**（多势力并立时代，势力展开篇按序点名承接某掌权者）：编号后加 `（承接）`
- **互斥**：单一政权用「群像篇」，多势力并立用「附篇承接」，同一图谱不混用
- 同一篇可同时作为某人主篇、他人群像/承接
- 传说性或存在性存疑者填 `⊘`，并在相邻故事文件的备注中说明

**候补故事选题说明**（规则定义见 [narrative.md §2.4](narrative.md)）：
- 不占正式编号，不计进度，无 ✅/⏳
- 升入正式列表时分配新编号并迁入对应位置，同步更新图谱「对应故事」列
- 用户否决者可移出或加「否决」标注

**状态行说明**：
- 故事状态：✅ 已完成 | ⏳ 待输出
- 图谱特殊标注：⊘ 存疑掌权者（仅用于 `eras/*.md` 图谱）

### 1.4 文学线图谱块：底本图谱

> 文学线以**原著分卷**为架构，输出至 `logs/eras/{编号}_{作品名}.md`，**5 字段表，「对应故事」列必须填满编号**（与正史线的掌权者传承表不同）；引言须标注「并行叙事线·文学线」并链接正史线对应时代文件（跨时代作品链接全部所涉时代，如《封神演义》同时链接商、西周）。

```markdown
## 底本图谱

| 分卷名 | 起始·终止章回 | 核心事件 | 核心人物 | 对应故事 |
|---------|--------------|---------|---------|---------|
| [段名] | 第X回 — 第Y回 | [中心事件] | [主要人物] | #1、#2 |
| ... | ... | ... | ... | ... |
```

**「起始·终止章回」列格式**：原著回目范围，精确到回（如「第一回 — 第十五回」）；原著回目以主流版本为准，版本异文在备注说明。

**「对应故事」列规格**：
- 每段至少一个编号（不允许空值），多值用「、」分隔
- 同一段可作为多篇故事的核心或承接
- 原著叙述稀薄者如实登记，不跳过

文学线进度条目在 `logs/progress.md` 独立列出，不计入正史进度（见 [AGENTS.md §5](../AGENTS.md)）。

## 2. progress.md 结构模板

**约束**：

- 必备 3 节：`当前状态`、`各时代进度`、`当前进度`
- `当前状态` 表固定 4 行：当前时代、已完成故事总数、跳过故事数、存疑掌权者数
- `各时代进度` 表的状态列用 `已完成 (m/n)` 或 `进行中 (m/n)` 表示
- **由 AI 维护**：进度表与状态数字在每次故事状态变更（⏳→✅）时由 AI 同步更新；状态数字应以 `eras/*.md` 故事列表的 ✅/⏳ 统计为准（用户裁决后由 AI 改写）

```markdown
# 历史故事进度

## 当前状态

| 项目 | 状态 |
|------|------|
| 当前时代 | 时代名称 |
| 已完成故事总数 | N |
| 跳过故事数 | N |
| 存疑掌权者数 | N |

---

## 各时代进度

| 时代 | 状态 | 进度 |
|------|------|------|
| 时代A | 已完成 (m/m) | m/m |
| 时代B | 进行中 (m/n) | m/n |

---

## 当前进度

- **时代**：时代名称
- **当前故事**：故事名称（状态）
- **下一个故事**：故事名称

### 并行线指针（文学线进行中时启用）

- **并行图谱**：作品名（关联正史：时代名）
- **当前故事**：故事名称（状态）
- **下一个故事**：故事名称

---

*进度概览与执行指针；数据由 `eras/*.md` 与 `contents/<era_dir>/*.md` 汇总*
```

## 3. logs/contents/<era_dir>/<id>.md 元数据约定

每故事文件必须包含 YAML 元数据头：

```markdown
---
id: story_id
era: era_code
section: 掌权阶段名称
title: 故事标题
---

# 故事标题

## 故事大纲

……（大事纪式条目，格式见 §7）……

## 故事背景

……（背景内容）……

## 正文

……（正文内容）……

## 备注

……（史源索引、推断、延伸思考等非叙事内容，前缀见 writing.md §1）……
```

**字段与约束**：

| 字段 | 必填 | 说明 |
|------|------|------|
| `id` | 是 | 故事唯一标识，格式 `{标识符}_{number}`，与文件名及 `logs/eras/*.md` 故事列表「#」列严格对应 |
| `era` | 是 | 时代代码/作品名，见 [AGENTS.md §5](../AGENTS.md)。正史线如 `xia`、`sanhuangwudi`；文学线如 `fengshen` |
| `section` | 是 | 篇目焦点与位置，见下 |
| `title` | 是 | 完整标题，与正文一级标题一致 |

**`section` 取值**：应反映本篇焦点 + 在时代中的位置，格式自由——掌权阶段类（`杼时期`）、势力展开类（`战国早期·魏`）、重大事件类（`长平之战`）、人物传记类（`商鞅列传`）、制度兴亡类（`府兵制兴衰`）、思想文化类（`百家争鸣`）、综合通论类（`战国·全时代·铁器牛耕`）。

**结构性必备标记**（必须出现于每个分卷或整个时代）：

- **分卷导论**（每个分卷一篇）——`[分卷名]·导论`，例：`战国早期·导论`
- **时代终章**（整个时代一篇）——`[时代]·终章`，例：`战国·终章`

**特殊情形**：

- 群像篇跨多阶段：主篇阶段为主值并追小注，如 `太戊时期（含沃丁·雍己）`
- 文学线对应：叙事阶段类、分卷导论、线索·人物展开类
- 记忆手卡（`{标识符}_{number}x`）：补充材料，豁免四段结构（不设大纲小节），不参与状态统计

允许按实际焦点自由命名，但须同时包含「焦点类型」与「时代、阶段位置」两个要素，避免只写人名或只写事件名；语义清晰即可。

**约束**：

- 元数据头必须用 `---` 包围，不得省略
- `id` 必须与 `logs/eras/*.md` 故事编号对应
- 每故事独占一文件，文件名即 `id`

## 4. 状态符号约定

**故事级状态**（仅两种原子态，由执行步骤自动触发转换）：

| 符号 | 含义 | 首次写入时机 | 转换触发 |
|------|------|-------------|---------|
| ⏳ | 未完成 | 故事列表落盘时（[narrative.md §3.1](narrative.md)） | — |
| ✅ | 已完成 | [AGENTS.md §4.5](../AGENTS.md) 校对各环节全部通过后 | ⏳ → ✅ |

> [说明] **时代级完成度**由故事级状态自动推导——一个时代全部故事为 ✅ 即为已完成，无需独立符号。

**图谱字段标注**（非状态，与 ✅/⏳ 正交）：

- **⊘** —— 传说性或存在性存疑的掌权者，须在相邻故事备注说明。仅用于 `eras/*.md` 图谱，不参与状态统计。

## 5. 文件写入规则

- **文件不存在**：创建并写入
- **文件已存在**：读 YAML `id`——与当前一致则覆盖；不一致则报错（文件名与内容错位，须人工处置）
- **必须包含 YAML 元数据头**（§3）
- **写入前确认目录存在**；不存在则先创建

## 6. 临时校对文档

`writing.md §9.3` 要求校对时维护校对记录文档，其规范如下。

### 6.1 路径与命名

```
temp/<era_dir>/<id>.proof.md
```

其中 `<era_dir>` 与 `<id>` 与对应故事文件一致。

### 6.2 内容格式

proof 文件由多阶段校对表格组成，每阶段包含若干校对项。每行记录一项校对结果：

```markdown
# 校对记录：<id>

## 阶段 N：<阶段名>
| 项 | 结果 | 说明 |
|---|---|---|
| <校对项 1> | ✅/❌/➖ | |
| <校对项 2> | ✅/❌/➖ | |
| ... | ... | ... |

## 独立验证记录
| 审查项 | 查证来源 | 结果 |
|---|---|---|
| <审查内容> | <来源> | ✅/❌ |
```

结果符号约定：
- **✅ 通过**
- **❌ 不通过**（须修订后重新校对）
- **➖ 不适用 + 原因**

具体校对各环节与项目由写作规范定义，本文件只规定文件结构与符号约定。

### 6.3 生命周期

- 校对开始时创建；
- 校对各环节全部通过后保留，作为校对记录（与内容文件一并留档）；
- 转入 [AGENTS.md §4.5](../AGENTS.md) 更新进度。

## 7. 故事大纲

`writing.md §8` 要求落笔前梳理故事大纲，其规范如下。

### 7.1 位置

大纲是故事文件的独立组成部分，置于「## 故事大纲」小节，先于「## 故事背景」出现；不另设临时文件。

### 7.2 内容格式

大纲内容规范（大事纪条目组织、分类型标识、时序约束）见 [writing.md §8.1–§8.2](writing.md)，本文件不重复。

### 7.3 确认与写入

- 撰写背景、正文与备注前梳理大纲并经用户确认；
- 确认后大纲随草稿写入故事文件「## 故事大纲」小节，不另设临时文件。
