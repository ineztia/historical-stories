# 文件记录规范

> 本文件作为**文件记录与落盘约定**专项规范，采用独立编号 §1–§7。自包含，不引用其他模块文件。

## 1. 文件路径与写入规范

| 路径 | 用途 |
|------|------|
| `logs/eras/` | 按朝代拆分的故事图谱，每朝代一文件（`00_sanhuang_wudi.md`、`01_xia.md`） |
| `logs/progress.md` | 进度跟踪，记录当前状态和概览 |
| `logs/contents/<era_dir>/` | 按朝代划分的故事目录，与 `eras/` 文件名前缀一致 |
| `logs/contents/<era_dir>/<story_id>.md` | 每故事一独立文件，文件名即 id，存储原文（背景/正文/备注） |

**定位与写入规则**：

- `<era_dir>` 与 `eras/` 文件名前缀一致；进入新时代时不存在须先创建
- `<id>` 格式 `{era_code}_{number}`（如 `xia_22`），与 `eras/*.md` 故事编号对应
- 每故事独占一文件，严禁多故事共用
- 文件不存在：创建并写入
- 文件已存在：读 YAML `id`——与当前一致则覆盖；不一致则报错（文件名与内容错位，须人工处置）
- 必须包含 YAML 元数据头（见 §4）

## 2. eras/*.md 结构模板

### 2.1 形态约束（正史/文学通用）

- **头部**：仅 1 段引言（blockquote），内容限定为「图谱说明 + 正史参照」
- **章节正文**：紧随引言之后，按需组织「时代谱系 / 故事列表 / 延伸拓展候选」三大块
- **底部**：5 行固定脚注（状态 / 类型 / 正史参照 / 进度 / 编号规则）
- **流程标注分流**：执行痕迹（§3.2.x 已确认、修订日期、用户裁决标记等）一律写入 `logs/progress.md`，**不得混入时代文件正文**
- **正史/文学差异**：文学线时代文件需在引言中标注「并行图谱」并链接正史线对应时代文件

### 2.2 模板

```markdown
# 时代名称 - 故事图谱

> [图谱说明 + 正史参照的一句话引言；文学线须标注「并行图谱」并链接正史线文件]

## 时代谱系

[简洁的时代传承描述]

| 掌权阶段 | 统治者/权力中心 | 时间范围·时长（约） | 继承关系 | 备注 | 对应故事 |
|---------|----------------|---------------|---------|------|---------|
| 1 | 黄帝 | 约前 2717-前 2599 年（约98年） | — | 开国 | #1、#2 |
| 2 | 颛顼 | 约前 2514-前 2437 年（约77年） | 黄帝之孙，昌意之子 | 孙继祖 | #3 |
| 3 | 帝喾 | 约前 2436-前 2367 年（约69年） | 颛顼之侄，蟜极之子 | 侄继叔 | #4（合篇） |
| 4 | 尧 | 约前 2357-前 2255 年（约102年） | 帝喾之子 | 子继父 | #4 |
| 5 | 舜 | 约前 2255-前 2205 年（约50年） | 尧之婿 | 禅让 | #5 |
| ... | ... | ... | ... | ... | ... |

**继承关系**：记录血缘（「某之子/孙」）或政治（「禅让/篡位/拥立」）关系，优先血缘；并存须均标注（「帝喾之子，禅让」）；史料分歧以主流为主，分歧在备注说明。

**「时间范围·时长」列格式**：
- 可计算：`约前XXX-前XXX年（约N年）`
- 时长不详：`不详（？年）`或 `约某时期（？年）`
- 未即位：`未即位`（不标时长）

**「对应故事」列规格**：
- 每位掌权者至少一个编号（不允许空值），多值用「、」分隔
- **主篇**（掌权者为主体）：无需额外标注
- **合篇**（单一政权时期多人共一篇群像）：编号后加 `（合篇）`
- **专篇承接**（多势力并立时代，分势力分期专篇按序点名承接某掌权者）：编号后加 `（承接）`
- **互斥**：单一政权用「合篇」，多势力并立用「专篇承接」，同一图谱不混用
- 同一篇可同时作为某人主篇、他人合篇/承接
- 传说性或存在性存疑者填 `⊘`，并在相邻故事备注说明（见 §5）

## 故事列表

**单一政权时期**：按掌权阶段顺序组织

### 掌权阶段/时期名称（N）

| # | 主题 | 优先级 | 抓手 | 状态 |
|---|------|--------|------|------|
| n | 标题 | 高/中/低 | 考证/关联/对比 | ✅/⏳ |

**多势力并立时期**：按三层骨架组织（分期导论 + 分势力分期专篇 + 里程碑事件 + 通论补充 + 时代收束）

### 一、[分期名]（#A–#B）

#### 分期导论

| # | 主题 | 优先级 | 抓手 | 状态 |
|---|------|--------|------|------|
| A | [分期名]导论——时代坐标与全局形势 | 高 | 关联 | ⏳ |

#### 分势力分期专篇

| # | 主题 | 优先级 | 抓手 | 状态 |
|---|------|--------|------|------|
| A+1 | [分期名]的[势力名]——[该期主题] | 高 | 对比 | ⏳ |

### 二、[下一分期]……

### N、里程碑事件篇

### N+1、通论补充题材

### N+2、时代收束篇

## 延伸拓展候选（不占正式编号）

> 汇总符合通史选题标准、但因篇数上限、主题重合或抓手较弱等原因未入正式列表的主题，供用户裁决。

| 候选主题 | 建议归类 | 推荐抓手 | 推荐归宿 | 未入选原因 |
|---------|---------|---------|---------|-----------|
| 示例：张仪合纵连横细目 | 人物 | 对比、关联 | 并入 #N 或独立成篇 | 已由里程碑篇 L1 融入 |
| 示例：稷下学宫学派谱系 | 通论 | 关联 | L2 索引即可 | 与百家争鸣篇重合 |
| ... | ... | ... | ... | ... |

**说明**：
- 不占正式编号，不计进度，无 ✅/⏳
- 升入正式列表时分配新编号并迁入对应骨架，同步更新谱系「对应故事」列
- 用户否决者可移出或加「否决」标注

---

- 状态：✅ 已完成 | ⏳ 待输出（⊘ 专属谱系表标注存疑掌权者，见 §5）
- 类型：正史 / 文学（并行图谱）
- 正史参照：[正史线文件链接或时代名]（文学线必填，正史线填「本文件」或留空）
- 进度：m/n
- 编号规则：`{era}_{number}` 格式
```

**补充说明**（非脚注字段，列于模板之后）：

- **「抓手」**：填写规则见 [narrative.md §1.2 / §3.2.2](narrative.md)；表内仅给单选示例
- **里程碑事件篇排布**：可按期穿插或集中置末，按主题灵活决定
- **正史线类型标注**：正史线时代文件底部「类型」填 `正史`，正史参照留空或填「本文件」

## 3. progress.md 结构模板

**约束**（与 §1 同体例）：

- 必备 3 节：`当前状态` / `各时代进度` / `当前进度`
- `当前状态` 表固定 3 行：当前时代 / 已完成故事总数 / 存疑掌权者数
- `各时代进度` 表的状态列仅用 ✅ / 🔄（无 ⏳——未开始不列入此表）
- 时代状态变化时同步更新 `各时代进度`（✅ ↔ 🔄）
- 自动产物，非手写；详情数据从 `eras/*.md` 与 `contents/<era_dir>/*.md` 汇总

```markdown
# 历史故事进度

## 当前状态

| 项目 | 状态 |
|------|------|
| 当前时代 | 时代名称 |
| 已完成故事总数 | N |
| 存疑掌权者数 | N |

---

## 各时代进度

| 时代 | 状态 | 进度 |
|------|------|------|
| 时代A | ✅ 已完成 | m/m |
| 时代B | 🔄 进行中 | m/n |

## 当前进度

- **时代**：时代名称
- **当前故事**：故事名称（状态）
- **下一个故事**：故事名称

```

## 4. contents/<era_dir>/<id>.md 元数据约定

每故事文件必须包含 YAML 元数据头：

```markdown
---
id: story_id
era: era_code
section: 掌权阶段名称
title: 故事标题
---

# 故事标题

## 故事背景
...
```

**字段与约束**：

| 字段 | 必填 | 说明 |
|------|------|------|
| `id` | 是 | `{era}_{number}`（`xia_14`、`sanhuang_05`）；同时作为文件名 |
| `era` | 是 | 时代代码（`xia`、`shang`、`zhou`、`sanhuang` 等） |
| `section` | 是 | 篇型与位置，见下 |
| `title` | 是 | 完整标题，与正文一级标题一致 |

**`section` 取值（按篇型）**：

- 掌权阶段篇：`杼时期`、`禹时期`
- 分期导论篇：`战国早期·导论`
- 分势力分期专篇：`战国早期·魏`、`三国三分期·吴`
- 里程碑事件篇：`长平之战`、`赤壁之战`
- 通论补充篇：
  - 全时代横截类：`战国·全时代·铁器牛耕`、`三国·全时代·九品中正制`
  - 分势力专项类：`战国·楚专项·楚辞`、`三国·魏专项·建安文学`
  - 跨势力专题类：`战国·跨势力专题·百家争鸣`、`战国·跨势力专题·孟子`
- 时代收束篇：`战国·终章`
- 合篇跨多阶段：主篇阶段为主值并追小注，如 `太戊时期（含沃丁—雍己）`

**约束**：
- 元数据头必须用 `---` 包围，不得省略
- `id` 必须与 `eras/*.md` 故事编号对应
- 每故事独占一文件，文件名即 `id`

## 5. 状态符号约定

| 符号 | 含义 |
|------|------|
| ✅ | 已完成 |
| ⏳ | 待输出 |
| 🔄 | 进行中（仅用于 `progress.md` 时代级统计） |
| ⊘ | 存疑略过（仅用于传说性或存在性存疑的掌权者，须在相邻故事备注说明） |

## 6. 文件命名规范

- 时代文件：`eras/XX_name.md`（XX 从 00 开始）
- 故事目录：`contents/XX_name/`（与 `eras/` 前缀一致，如 `01_xia/`）
- 故事文件：`contents/XX_name/{era}_{number}.md`（如 `01_xia/xia_14.md`）
- 进度文件：`progress.md`

## 7. 并行叙事图谱文件格式

> 命名规则与正史同构（`x` 标识并行）；判定标准与图谱管理见 [narrative.md §3.1](narrative.md)，尤其是 §3.1.4 命名与文件规则。

### 7.1 命名规则

- 时代文件：`eras/<时代编号>_<作品名>.md`（如 `eras/02x_fengshen.md`）
- 故事目录：`contents/<时代编号>_<作品名>/`（如 `contents/02x_fengshen/`）
- 故事文件：`contents/<时代编号>_<作品名>/<作品名>_<number>.md`（如 `contents/02x_fengshen/fengshen_01.md`）
- 进度文件：`progress.md`（独立列出，不计入正史进度）

### 7.2 文学线谱系表模板

文学线谱系以**原著叙事段/期**为骨架，输出至 `eras/<era>.md`，**5 字段表，对应故事列须填满编号**：

| 段/期名 | 起始·终止章回 | 核心事件 | 核心人物 | 对应故事 |
|---------|--------------|---------|---------|---------|
| [段名] | 第X回 — 第Y回 | [中心事件] | [主要人物] | #1、#2 |
| ... | ... | ... | ... | ... |

**「起始·终止章回」列格式**：原著回目范围，精确到回（如「第一回 — 第十五回」）；原著回目以主流版本为准，版本异文在备注说明。

**「对应故事」列规格**：
- 每段至少一个编号（不允许空值），多值用「、」分隔
- 同一段可作为多篇故事的核心或承接
- 原著叙述稀薄者如实登记，不跳过
