# 文件记录规范

> 本文件从 `AGENTS.md` 拆分而来，作为**文件记录与落盘约定**专项规范，采用独立编号 §1–§7。
>
> **跨文件引用**：AGENTS.md 引用本文件时写作「**文件记录规范 §N**」；本文件内部互引直接写「§N」。

## 1. 文件路径与写入规范

| 路径 | 用途 |
|------|------|
| `logs/eras/` | 按朝代拆分的故事图谱，每朝代一文件（`00_sanhuang_wudi.md`、`01_xia.md`） |
| `logs/progress.md` | 进度跟踪，记录当前状态和概览 |
| `logs/contents/<era_dir>/` | 按朝代划分的故事目录，与 `eras/` 文件名前缀一致 |
| `logs/contents/<era_dir>/<story_id>.md` | 每故事一独立文件，文件名即 id，存储原文（背景/正文/备注） |

**定位与写入规则**：

- `<era_dir>` 与 `eras/` 文件名前缀一致；进入新时代时不存在须先创建
- `<id>` 格式 `{era_code}_{number}`（如 `xia_22`），与 `eras/*.md` 故事编号对应
- 每故事独占一文件，严禁多故事共用
- 文件不存在：创建并写入
- 文件已存在：读 YAML `id`——与当前一致则覆盖；不一致则报错（文件名与内容错位，须人工处置）
- 必须包含 YAML 元数据头（见 §4）

## 2. eras/*.md 结构模板

```markdown
# 时代名称 - 故事图谱

## 时代谱系

[简洁的时代传承描述]

| 掌权阶段 | 统治者/权力中心 | 时间范围·时长（约） | 继承关系 | 备注 | 对应故事 |
|---------|----------------|---------------|---------|------|---------|
| 1 | 黄帝 | 约前 2717-前 2599 年（约98年） | — | 开国 | #1、#2 |
| 2 | 颛顼 | 约前 2514-前 2437 年（约77年） | 黄帝之孙，昌意之子 | 孙继祖 | #3 |
| 3 | 帝喾 | 约前 2436-前 2367 年（约69年） | 颛顼之侄，蟜极之子 | 侄继叔 | #4（合篇） |
| 4 | 尧 | 约前 2357-前 2255 年（约102年） | 帝喾之子 | 子继父 | #4 |
| 5 | 舜 | 约前 2255-前 2205 年（约50年） | 尧之婿 | 禅让 | #5 |
| ... | ... | ... | ... | ... | ... |

**继承关系**：记录血缘（「某之子/孙」）或政治（「禅让/篡位/拥立」）关系，优先血缘；并存须均标注（「帝喾之子，禅让」）；史料分歧以主流为主，分歧在备注说明。

**「时间范围·时长」列格式**：
- 可计算：`约前XXX-前XXX年（约N年）`
- 时长不详：`不详（？年）`或 `约某时期（？年）`
- 未即位：`未即位`（不标时长）

**「对应故事」列规格**：
- 每位掌权者至少一个编号（不允许空值），多值用「、」分隔
- **主篇**（掌权者为主体）：无需额外标注
- **合篇**（单一政权时期多人共一篇群像）：编号后加 `（合篇）`
- **专篇承接**（多势力并立时代，分势力分期专篇按序点名承接某掌权者）：编号后加 `（承接）`
- **互斥**：单一政权用「合篇」，多势力并立用「专篇承接」，同一图谱不混用
- 同一篇可同时作为某人主篇、他人合篇/承接
- 传说性或存在性存疑者填 `⊘`，并在相邻故事备注说明（见 §5）

## 故事列表

**单一政权时期**：按掌权阶段顺序组织
```

## 4. contents/<era_dir>/<id>.md 元数据约定

每故事文件必须包含 YAML 元数据头：

```markdown
---
id: story_id
era: era_code
section: 掌权阶段名称
title: 故事标题
---

# 故事标题

## 故事背景
...
```

**字段与约束**：

| 字段 | 必填 | 说明 |
|------|------|------|
| `id` | 是 | `{era}_{number}`（`xia_14`、`sanhuang_05`）；同时作为文件名 |
| `era` | 是 | 时代代码（`xia`、`shang`、`zhou`、`sanhuang` 等） |
| `section` | 是 | 篇型与位置，见下 |
| `title` | 是 | 完整标题，与正文一级标题一致 |

**`section` 取值（按篇型）**：

- 掌权阶段篇：`杼时期`、`禹时期`
- 分期导论篇：`战国早期·导论`
- 分势力分期专篇：`战国早期·魏`、`三国三分期·吴`
- 里程碑事件篇：`长平之战`、`赤壁之战`
- 通论补充篇：
  - 全时代横截类：`战国·全时代·铁器牛耕`、`三国·全时代·九品中正制`
  - 分势力专项类：`战国·楚专项·楚辞`、`三国·魏专项·建安文学`
  - 跨势力专题类：`战国·跨势力专题·百家争鸣`、`战国·跨势力专题·孟子`
- 时代收束篇：`战国·终章`
- 合篇跨多阶段：主篇阶段为主值并追小注，如 `太戊时期（含沃丁—雍己）`

**约束**：
- 元数据头必须用 `---` 包围，不得省略
- `id` 必须与 `eras/*.md` 故事编号对应
- 每故事独占一文件，文件名即 `id`

## 5. 状态符号约定

| 符号 | 含义 |
|------|------|
| ✅ | 已完成 |
| ⏳ | 待输出 |
| 🔄 | 进行中（仅用于 `progress.md` 时代级统计） |
| ⊘ | 存疑略过（仅用于传说性或存在性存疑的掌权者，须在相邻故事备注说明） |

## 6. 文件命名规范

- 时代文件：`eras/XX_name.md`（XX 从 00 开始）
- 故事目录：`contents/XX_name/`（与 `eras/` 前缀一致，如 `01_xia/`）
- 故事文件：`contents/XX_name/{era}_{number}.md`（如 `01_xia/xia_14.md`）
- 进度文件：`progress.md`

## 7. 并行叙事图谱规范

### 7.1 定义与定位

并行叙事图谱是独立于正史图谱的**文学叙事线**，用于讲述与某朝代相关的经典文学巨著（如封神演义、水浒传等）。

| 维度 | 正史图谱 | 并行图谱 |
|------|---------|---------|
| 性质 | 历史叙事 | 文学叙事 |
| 史料规范 | 严格遵循 AGENTS.md §2.3 | 以原著为唯一叙事来源，不要求史源卡片 |
| 谱系骨架 | 掌权者传承 | 原著自身的叙事结构（章回/事件/人物弧线） |
| 真实性 | 史实为底线 | 忠实于原著情节，标注「此为文学虚构」即可 |

### 7.2 命名规则

- 时代编号 = 正史编号 + `x`（如 `02x` 对应 `02_shang`）
- 时代文件：`eras/02x_fengshen.md`
- 故事目录：`contents/02x_fengshen/`
- 故事文件：`contents/02x_fengshen/fengshen_01.md`
- `x` 后缀明确标识「这是并行图谱，不是正史」

### 7.3 写作规范

并行图谱**不适用**正史的全部规范（史源卡片、三层标签、三条红线），但须遵守：

- **忠实原著**：不擅自改写情节，不添加原著没有的内容
- **标注回目**：每篇标注对应原著回目，方便读者回查
- **与正史出入**：备注中简注「正史见 XX」，不喧宾夺主
- **叙事语体**：同样面向历史爱好者，可读性优先
- **篇幅**：每篇合计约 3000 字以上，正文约 2000 字以上（原则性参考）

### 7.4 交叉引用

- 正史故事备注：`↗ 并行叙事：封神演义中姜子牙形象见 fengshen_08`
- 并行故事备注：`↙ 正史参照：牧野之战史实见 shang_20`

### 7.5 进度跟踪

并行图谱在 `progress.md` 中单独列出，不计入正史进度。
