# 历史故事 Agent

系统讲述中国历代史的历史叙事项目，以「讲故事」的方式面向历史爱好者/通史读者从三皇五帝讲到清朝。

## 项目简介

本项目围绕「政权及事实权力中心掌权阶段」建立连续时间轴，以**耳熟能详的重要人物与事件**为叙事主体，辅以权威史料与制度解说，通过**考证、关联、对比**三种学史方法帮助读者触类旁通地掌握通史脉络。

### 文件命名规则

- **规则主文件**：`AGENTS.md`（主提示词）
- **规则子模块**：`.agents/file-recording-spec.md`（文件记录规范，AGENTS.md §4 引用）
- **时代图谱**：`eras/XX_name.md`（XX 为序号，如 `01_xia.md`）
- **故事文件**：`contents/XX_name/{era}_{number}.md`（如 `contents/01_xia/xia_14.md`）
- **进度文件**：`progress.md`

## 使用方式

1. 启动 Agent，先读 `logs/progress.md` 识别当前状态
2. 按 `AGENTS.md` 执行路由加载对应模块（§4 引用 `.agents/file-recording-spec.md`）
3. 按流程进入新时代 → 确认时代谱系 → 确认故事列表 → 逐篇输出
4. 每篇故事「写入 → 读回 → 就地修订 → 状态落定」，自检未通过前不更新进度

## 内容规范

- 每篇故事采用三段结构：故事背景 / 正文 / 备注
- 字数下限：总字数 ≥ 5000 字，其中正文 ≥ 3000 字
- 正文仅写中立、权威史实 + 必要「推断：」，禁分点/报告体/清单体
- 多维阐释、横向比较、辩证评论、后世接受史等全部落入备注
- 多势力并立时代按「分期 → 分势力分期专篇 → 里程碑事件篇」三层骨架组织，严禁「一势力讲完再讲下一势力」整块切片
- 优先使用权威史料（二十四史、《史记》、《资治通鉴》等），野史/笔记须备注标注体裁与出处
- 每篇故事独立存储为以故事 ID 命名的 Markdown 文件，带 YAML 元数据头
