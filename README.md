# 历史故事 Agent

系统讲述中国历代史的历史叙事项目，以「讲故事」的方式面向历史爱好者从三皇五帝讲到清朝。

## 项目简介

本项目围绕「政权及事实权力中心掌权阶段」建立连续时间轴，在每个阶段充分讲清该时代的重要人物、事件与社会结构。

## 目录结构

```
historical-stories/
├── AGENTS.md                          # Agent 提示词配置
├── README.md                          # 项目说明
└── logs/
    ├── progress.md                    # 进度跟踪
    ├── eras/                          # 时代故事图谱（每个朝代一个文件）
    │   ├── 00_sanhuang_wudi.md
    │   └── 01_xia.md
    └── contents/                      # 故事原文（按朝代分目录，每故事独立文件）
        ├── 00_sanhuang_wudi/
        │   ├── sanhuang_01.md
        │   ├── sanhuang_02.md
        │   └── ...
        └── 01_xia/
            ├── xia_01.md
            ├── xia_02.md
            └── ...
```

### 文件命名规则

- **时代图谱**：`eras/XX_name.md`（XX 为序号，如 `01_xia.md`）
- **故事文件**：`contents/XX_name/{era}_{number}.md`（如 `contents/01_xia/xia_14.md`）
- **进度文件**：`progress.md`

## 使用方式

1. 启动 Agent 后，按提示词执行流程操作
2. 每个新时代需先确认「时代谱系」和「故事列表」
3. 按顺序逐篇输出故事

## 内容规范

- 每篇故事采用三段结构：故事背景 / 正文 / 备注
- 正文使用叙事文自然段落，字数目标 3000 字以上
- 优先使用权威史料，争议内容在备注说明
- 每篇故事独立存储为以故事 ID 命名的 Markdown 文件
