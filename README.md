# 历史故事 Agent

以「讲故事」的方式面向历史爱好者，系统讲述中国历代史——从三皇五帝讲到清朝。

## 项目定位

围绕「政权及事实权力中心掌权阶段」建立连续时间轴，以耳熟能详的重要人物与事件为叙事主体，辅以权威史料与制度解说，通过考证、关联、对比三种学史方法帮助读者触类旁通地掌握通史脉络。

## 目录结构

```
historical-stories/
├── AGENTS.md              # Agent 主提示词（角色、流程路由、模块索引）
├── README.md              # 项目说明
├── .agents/               # 规则模块（叙事骨架 / 写作标准 / 文件规范）
└── logs/
    ├── progress.md        # 进度跟踪
    ├── eras/              # 时代故事图谱（每朝代一个文件）
    └── contents/          # 故事原文（按朝代分目录）
```

**命名约定**：
- 时代图谱：`eras/XX_name.md`（如 `01_xia.md`）
- 故事文件：`contents/XX_name/{era}_{number}.md`（如 `xia_14.md`）
- 记忆手卡：`contents/XX_name/{era}_{number}x.md`（不计入正式故事数）

## 提示词架构

采用模块化设计，`AGENTS.md` 为路由入口，按执行阶段按需加载对应模块：

| 模块 | 文件 | 职责 |
|------|------|------|
| 叙事骨架 | `.agents/narrative.md` | 时间轴结构、篇型体系、故事列表生成方法 |
| 写作标准 | `.agents/writing.md` | 写作与校对统一标准（含弹性 Checklist） |
| 文件规范 | `.agents/file-spec.md` | 文件路径、模板、元数据、命名 |

各模块自包含无交叉引用，所有跨模块路由仅通过 AGENTS.md 完成。

## 使用流程

1. 启动 Agent，先读 `logs/progress.md` 识别当前状态
2. 按 `AGENTS.md` 路由按需加载模块
3. 执行流程：新时代 → 确认时代谱系 → 确认故事列表 → 逐篇输出
4. 每篇故事须经「写入 → 审查校对 → 就地修订 → 状态落定」，校对未通过前不更新进度

## 内容规范

- 三段结构：故事背景 / 正文 / 备注
- 字数下限：总字数 ≥ 5000 字，正文 ≥ 3000 字
- 正文仅写中立、权威史实 + 必要「推断：」，禁分点/报告体/清单体
- 多维阐释、横向比较、辩证评论落入备注
- 优先使用权威史料（二十四史、《史记》、《资治通鉴》等），野史/笔记须在备注标注体裁与出处
