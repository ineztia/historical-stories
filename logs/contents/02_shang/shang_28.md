# 商代军事制度与战争形态

## 故事背景

前述诸篇从不同侧面触及了商代的战争：成汤灭夏的鸣条之战（#5、#6）是商族以武力夺取天下的起点，九世之乱时期方国叛离（#10、#11）是军事衰弱的外在表征，武丁征伐鬼方、土方、羌方（#14、#15）是商代军事力量的巅峰，帝乙帝辛征人方（#18、#19）是商朝最后的军事豪赌，而牧野之战（#20）则以商军的全面崩溃为殷商六百年画上句号。方国篇（#25）梳理了商与周边势力的战略关系，社会经济篇（#26）揭示了军事行动的经济基础，青铜器篇（#22）展示了铸铜技术如何武装了商朝的军队。然而，商代的军队究竟如何组织？武器装备有何特征？战车如何作战？兵员如何征召？这些问题尚未得到系统回答。

商代军事制度是中国古代军事制度的早期形态——从甲骨卜辞和考古发现来看，商代已形成了以"师"为核心编制、以战车为突击力量、以"登人"为征召方式的军事体系。这一体系支撑了商朝从部落联盟到王朝帝国的扩张，也暴露了"兵农合一"体制在面对突发危机时的脆弱性。本篇以"关联"为抓手，着重呈现军事制度与商朝政治、经济、宗教之间的结构性关联——军队组织与王权的关系、武器生产与铸铜工业的关系、战争形态与祭祀制度的关系。

## 故事正文

商代军队的最高编制单位是"师"。甲骨文中"师"字作"𠂤"，本义为聚落或驻屯地，后引申为军队编制单位。武丁时期的卜辞中已出现"中师"（《甲骨文合集》5807）和"右师"（《合集》5805）的记载，说明武丁时已有按右中左分师的军事组织雏形。武乙文丁时期的卜辞则明确记载了三师建制——"丁酉贞：王作三师，右、中、左"（据《甲骨文合集》33006）。右、中、左三师并列，可能分别由不同将领统率，商王居中节制。推断：三师制并非同时出征的固定编制，而是商王根据战争规模灵活调用的军事资源——小规模冲突出动一师，大规模征伐则三师并出。三师制的组织逻辑，与商代社会以"右—中—左"三分为基本结构的空间观念一致——祭祀卜辞中也有"右宗""中宗"等用语，说明"右中左"三分是商代制度思维的基本模式。

"师"之下还有"旅"和"行"两级编制。"旅"的规模较大——卜辞"登妇好三千，登旅万，呼伐[某方]"（据《甲骨文合集》5811）记载妇好直属兵力三千人，配属旅军一万人，说明"旅"的兵力可达数千至万人。"行"则是更低层级的战术分队，卜辞中有"令某行"的记载，即命令某人率行军出征。推断：商代军事编制的层级关系大致为"师—旅—行"，但这一体系可能尚未形成周代那样严格的固定员额——商代的"师""旅""行"更接近按任务需要灵活编组的作战单位，而非制度化的常备军。

商代兵员征召的主要方式是"登人"。"登"有征召、征集之意，"登人"即征召兵员。卜辞中"登人"的规模从三千到一万不等——"登人三千呼伐土方"（据《甲骨文合集》6057）、"登人五千呼伐[某方]"（据《合集》6168）、"登人万呼伐[某方]"（据《合集》6409）。征召规模的大小取决于战争的规模——对付土方的边境冲突征召三千人即可，征伐鬼方这样的大国则需要万人以上。除"登人"外，卜辞中还有"共人"（"共"通"供"，意为调集已有武装力量）的征召方式。"登人"侧重从民间征召新兵，"共人"侧重调集已编成的部队——两种方式配合使用，使商王能够在短时间内集结起大规模兵力。推断：商代的兵役制度是"兵农合一"——"众人"平时耕作（"呼众人协田"），战时被征召从军（"登人若干"）。这种制度的好处是养兵成本极低，坏处是缺乏训练有素的常备军——一旦遭遇突发入侵，临时征召的"众人"很难迅速形成战斗力。

军事指挥体系的层级同样清晰。最高级别是商王亲征——卜辞中"王征鬼方""王伐土方"的记载频繁出现，说明商王经常亲自统率大军出征。商王之下是将领代征——"令沚戛伐巴方""令望乘伐下危"，商王命令将领率军出征，将领对商王负责。再下一层是方国协同——"令攸侯伐某方"，商王命令服国出兵协同作战，以方制方。此外，王室成员亦可独立统兵——"令妇好伐巴方"是王后统军的著名案例（#15），显示了商代女性在特定条件下可以掌握军事指挥权。这种多层级指挥体系的好处是灵活——商王可以根据战争规模选择亲自出征或委托将领；坏处是高度依赖商王个人的军事才能和权威——当商王昏聩或年幼时，指挥体系就可能失灵。

商代军队的武器装备，以青铜器为核心。出土数量最多的青铜兵器是戈——殷墟出土铜戈数以千计，形制从早商的直内戈发展到晚商的曲内戈、銎内戈，装柄方式逐步改进。戈的用法为勾啄——以戈刃勾住敌人身体再拉回，或以戈尖向下啄击——是车战和步战中最重要的格斗兵器。矛是另一重要刺兵，殷墟侯家庄1004号大墓出土铜矛数百件，成束放置，显示矛的批量生产已具规模。矛在车战中是车右的主要武器，与戈配合使用——戈主勾啄，矛主刺击，长短互补。

钺在商代军事中具有特殊地位——它不仅是实战武器，更是军事统帅权的象征。妇好墓出土两件大铜钺，分别重8.5公斤和9公斤，铸有"妇好"铭文，器身饰虎纹和兽面纹，气势威严。推断：钺的功能类似于后世的"节钺"——商王将钺授予统兵将领，即授予其征伐之权；将领持钺出征，代表商王的权威。《尚书·牧誓》载武王在牧野之战中"王左杖黄钺，右秉白旄以麾"——左手持黄钺、右手持白旄旗指挥全军——说明钺作为军事权力象征的传统从商延续至周初。

远程武器以弓矢为主。甲骨文"射"字作张弓搭箭之形，卜辞中"射"既指田猎射箭，也指军事射击。殷墟出土大量铜镞，形制有双翼式、三棱式等，以双翼式最多。骨镞、石镞在普通士兵中仍有使用，青铜镞主要配给精锐部队和车左射手。防护装备方面，殷墟侯家庄1004号大墓出土了铜胄（头盔），以兽面纹为饰，工艺精湛。推断：青铜胄为高级贵族专用，普通士兵可能使用皮胄或无胄。盾以木、皮革为材质，表面蒙兽皮或髹漆，但有机质难以保存，考古发现极少。

商代战争形态最突出的特征是车战的兴起。殷墟已发掘车马坑数十座，是研究商代车战最直接的考古证据。典型商代马车为双轮、单辕（辀）、方形车舆，由两匹或四匹马牵引，轮径约1.2至1.4米，车舆长约1至1.3米，可容二至三人。郭家庄车马坑出土铜戈、铜镞等武器，证明此车为战车而非仪仗用车。

战车的基本编组为三人一车——车左持弓主射，可能为车长；车右持戈矛主格斗，负责近战；御者居中驾车。三人分工明确、各司其职，是商代车战的基本战术单元。《尚书·牧誓》载武王誓师时命令将士"称尔戈，比尔干，立尔矛"——举起戈、排列盾、竖起矛——反映的正是车战步兵协同的基本武器配置。推断：商代车战已形成"战车冲击+步卒跟进"的基本战术——战车先行冲破敌方阵型，步卒随后扩大战果。牧野之战中武王强调"不愆于六步、七步，乃止齐焉"（愆，超过）——步兵前进六七步就要停下来整队——说明步兵阵型纪律是车步协同的关键：步兵必须保持阵型以配合战车行动，一旦阵型散乱，战车就失去步兵掩护，陷入孤立。

商代战争的规模，可以从卜辞中"登人"的数字来估算。常规征伐动用三千至五千人，大规模征伐可达万人以上。武丁时期"登妇好三千，登旅万"的记载，意味着商军一次出征可动用一万三千人——这在当时已是一支相当庞大的军队。帝乙帝辛时期征人方的卜辞记录了详细的行军路线和日程，从殷都出发东南行经商丘、宿县直至淮河流域，全程历时数十日至数月——如此远距离的军事行动，必然需要完善的后勤保障体系。推断：商朝已具备组织远距离军事行动的后勤能力——粮秣供应依赖沿途方国的贡纳，武器补给依赖随军工匠的现场修理，交通则依赖太行山东麓和黄河两岸的南北向干线。

商代军事行动与祭祀制度深度绑定。每次出征前必占卜吉凶——"贞：王征鬼方，受又（佑）"是典型的战前占卜。卜辞中还有"告于大甲""告于祖乙"等战前向先王报告的祭祀，以及征伐胜利后向祖先献俘的仪式。征伐所获俘虏大量用于祭祀——"伐羌""用羌""卯羌"等记载极为频繁，羌人是商朝人祭制度中最大的牺牲群体（#24）。推断：商代战争与祭祀之间存在一种结构性循环——祭祀需要人牲，人牲来自战争俘虏，战争俘虏又需要发动新的征伐来获取。这种"战争—俘虏—祭祀—再战争"的循环，是商代军事制度区别于后世的重要特征：战争不仅服务于军事目的和经济目的，还服务于宗教目的——祭祀需求本身就是发动战争的动机之一。

帝辛将精锐部队投入东方战场征人方，西方防线空虚——当周武王率军突袭时，帝辛只能仓促征召奴隶和战俘充数（《史记》载"发兵七十万人"显系夸大，但临时拼凑军队应是事实）。这些临时征召的"众人"缺乏训练和士气，在周军战车冲击下一触即溃，"前徒倒戈"——前排士兵反戈攻击后排——商军阵型瞬间崩溃。

### 概念语境锁定

- **师/𠂤**：甲骨文中最高军事编制单位，"𠂤"本义为聚落或驻屯地，引申为军队编制；卜辞中"右师""中师""左师"为三师建制；本篇取义为商代军事编制单位，非周代"六军"之师，非后世"军队"泛称
- **旅**：甲骨文中军事编制单位，"登旅万"即征召旅军万人；本篇取义为商代师之下的作战单位，非周代"旅"（五百人），非后世"旅行"之义
- **行**：甲骨文中较低层级战术分队编制；本篇取义为商代旅之下的战术单位，非后世"行列"泛称
- **登人**：甲骨卜辞中征召兵员的制度性用语，"登"为征召、征集；本篇取义为商代兵员征召方式，非"攀登"之义
- **共人**：甲骨卜辞中调集已有武装力量的用语，"共"通"供"；本篇取义为商代兵员调集方式，非"共同"之义
- **戈**：商代最典型的勾啄类青铜近战武器，用法为勾啄；本篇取义为具体兵器类型，非后世"干戈"泛指武器之义
- **钺**：商代军事统帅权的象征器物，兼有实战功能；本篇取义为军事权力象征，非后世"斧钺"泛指刑具之义
- **乘**：战车计量单位，一乘即一车配马匹和甲士；"乘马"之"乘"为驾驭义，需辨析

### 正文推断出处与推理过程

1. **"三师制并非同时出征的固定编制，而是商王根据战争规模灵活调用的军事资源"**：推理过程——卜辞中"登人"的规模从三千到一万不等，说明商代出兵规模弹性很大；如果三师是固定编制且每次同时出动，则兵力应相对固定；三师更可能是按需要灵活组合的军事资源池，而非三支常备军
2. **"商代军事编制的层级关系大致为师—旅—行"**：推理过程——卜辞中"师""旅""行"三者均用于军事行动，从"登旅万"的规模来看旅小于师，"令某行"的行更小；三者构成从大到小的编制层级，但具体员额尚无定论
3. **"商代兵役制度是兵农合一"**：推理过程——卜辞中"众人"既用于"协田"（农业劳作）又被"登人"征召（军事行动），说明同一群体平时耕作、战时从军；商代未见常备军的明确记载，军事行动依赖临时征召
4. **"钺的功能类似于后世的节钺"**：推理过程——妇好墓出土大铜钺铸有"妇好"铭文，非普通士兵装备；《牧誓》"王左杖黄钺"说明钺与军事指挥权关联；后世文献中"假节钺"即授予征伐之权——三者指向钺为军事统帅权象征
5. **"商代车战已形成战车冲击+步卒跟进的基本战术"**：推理过程——殷墟车马坑出土战车配铜戈铜镞，证明战车用于实战；《牧誓》"不愆于六步、七步，乃止齐焉"强调步兵阵型纪律，说明步兵需配合战车行动；车步协同是当时最合理的战术——战车冲击力强但缺乏持久力，需要步兵跟进巩固战果
6. **"商朝已具备组织远距离军事行动的后勤能力"**：推理过程——帝乙帝辛征人方卜辞记录了从殷都到淮河流域的详细行军路线，历时数十日至数月；如此远距离的军事行动，必然需要粮秣供应、武器修理和交通保障——没有后勤体系支撑，远征不可能完成
7. **"战争—俘虏—祭祀—再战争的结构性循环"**：推理过程——卜辞中征羌与用羌人祭祀的记载高度重合；祭祀对羌人俘虏的需求是持续性的（周祭制度每年消耗大量人牲），构成征羌战争的持续性动力；单次征伐所获俘虏用于祭祀后，下一次祭祀又需新俘虏，形成循环

### 联系与比较视角

**纵向联系**：商代军事制度是中国古代军事制度的早期形态，与西周军事制度存在明显的承续关系。商代"三师"制可能是西周"六军"制的前身——周人在商代三师基础上扩展为六军，编制逻辑相同（以"右中左"三分扩展为"右中左"各分上下）。商代"登人"的征召方式延续至西周——西周的"籍田"制度和"大搜"礼，本质上仍是兵农合一的征召体制。商代车战的三人编制（车左、御者、车右）为周代所沿袭，直至春秋时期仍是战车的基本编组。然而，从商到周，军事制度也发生了重要变化——西周建立了更为制度化的"军制"（六军、师、旅、卒、两、伍的固定编制），比商代灵活编组的方式更为规范；西周还建立了"虎贲"等常备精锐部队，弥补了商代"兵农合一"缺乏常备军的缺陷。

**横向联系**：商代战车与同时期其他古文明的战车有可比之处。古埃及新王国时期的战车同样为双轮、单辕、由两匹马牵引，车上两人（驭手和射手）——与商代战车的三人编制略有不同，商代多了一个车右负责近战。赫梯帝国的战车为三人编制（驭手、射手、持盾者），与商代更为接近。推断：三人编制可能是古代战车的通行模式——驭手驾车、射手远程攻击、近战士兵保护战车——三人分工覆盖了远、中、近三种战斗距离。商代战车与埃及、赫梯战车的相似性，可能反映了战车技术从西亚向东传播的历史轨迹，也可能是在相似军事需求下的独立发明——这一问题尚无定论。

**母题归纳**：商代军事制度反复出现的一个母题是"兵农合一的弹性与脆弱"——平时不养常备军以降低成本，战时临时征召以应对危机；这种制度在和平时期效率极高，但在突发危机面前却缺乏弹性。牧野之战是这一母题的极端呈现——精锐远征在外，临时征召的民兵一触即溃。这一母题在中国历史上反复出现：秦末征发骊山刑徒拒敌、东汉末年临时征召黄巾降兵、明朝卫所制度崩坏后临时募兵——都是在常备军缺失或失效时，以临时手段应对危机，结果往往不堪一击。

### 阐释视角

**制度机理**：商代军事制度的运转依赖三重制度性支撑——占卜制度决定是否出征和何时出征，征召制度（"登人""共人"）提供兵员，方国贡纳制度保障后勤。三重支撑相互咬合：占卜赋予征伐以"天命"的正当性，征召提供执行天命的军事力量，方国贡纳维持远征的后勤供给。当商朝强盛时，三重支撑形成正反馈——占卜吉兆鼓舞士气，征召顺利集结大军，方国积极提供补给。当商朝衰弱时，三重支撑形成负反馈——占卜可能显示凶兆动摇军心，征召困难兵员不足，方国叛离后勤断绝。牧野之战就是负反馈循环的极端案例。

**长时段/多重动因**：商代军事制度的演变，是多重因素长期塑造的结果。地理因素——商朝核心区域地处平原，适合战车驰骋，因此车战成为主要作战方式；周边方国多在山地和高原，步兵和骑兵更占优势，因此商军在山地作战中往往力不从心。经济因素——青铜铸造需要大量铜锡，铜锡矿多在远方，保障矿料供应本身就是军事行动的重要动机。宗教因素——祭祀需要大量人牲，人牲来自战争俘虏，祭祀需求本身就是发动战争的动机之一。政治因素——征伐的胜利强化王权，王权的强化又为下一次征伐提供组织保障。多重因素交织，使商代军事制度呈现出"以战养战、以祭促战"的独特面貌。

**地理—经济—生态**：商代战争形态与地理生态密切相关。商朝核心区域（豫北—冀南）是黄河冲积平原，地势平坦开阔，适合战车作战——这是商代车战发达的地理基础。西北方的鬼方、土方活动于黄土高原和鄂尔多斯地区，地形起伏、沟壑纵横，战车难以展开——武丁伐鬼方"三年克之"，持续时间之长可能与此有关。东方的人方活动于山东丘陵和淮河流域，水系发达，战车同样受限——帝乙帝辛征人方的卜辞记录了商军沿水路行进，可能使用了舟船配合陆路作战。地理生态的差异，塑造了商朝在不同方向采取不同战术的基本格局——平原用车战，山地用步兵，水网地带车步协同甚至借助舟船。
