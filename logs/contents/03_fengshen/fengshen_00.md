# 封神演义人物战力图谱

> 本文件为并行叙事线《封神演义》的参考资料索引，非正式故事篇目。以明代百回本《封神演义》为唯一底本，按修为境界、法宝、实战战绩对书中重要人物进行战力分层。同档内不严格排序，人物简介、师承关系与排名理由均据原著情节整理。

---

## 战力分层总则

| 层级 | 定位 | 典型特征 |
|---|---|---|
| **T0** | 至高存在 | 封神世界天花板，无实战对手，可约束圣人 |
| **T0.5** | 天道级圣人/至高神 | 位格与圣人同级或更高，但正面斗法描写较少 |
| **T1** | 混元大罗金仙·教主级 | 三花聚顶、万劫不坏，一派之祖，法宝与阵法可改天换地 |
| **T2** | 准圣/顶级大罗金仙 | 圣人之下第一档，需圣人亲自出手方可镇压 |
| **T3** | 大罗金仙/金仙级 | 阐截两教中坚力量，有专属法宝或神通 |
| **T4** | 三代弟子/强力凡人/异术之士 | 有强力法宝或异术，可参与战局，但难敌金仙 |
| **T5** | 低阶法力/妖身/微末异术 | 有微末法力、妖身、异术或特殊体质，实战有限 |
| **T6** | 纯凡人/非战力角色 | 仅靠武艺或无战力，以剧情推动作用为主 |

## T1：混元大罗金仙·教主级

| 人物 | 身份关系 | 核心法宝/神通 | 排名原因 |
|---|---|---|---|
| **老子（太上老君）** | 人教圣人，三清之首；元始、通天之大兄 | 太极图、天地玄黄玲珑塔、乾坤图、风火蒲团；一气化三清 | 圣人中实战最强。诛仙阵中以一气化三清迷惑通天，扁拐连击；风火蒲团收多宝道人；单挑可压制通天教主。 |
| **通天教主** | 截教教主，三清之一；多宝、金灵、无当、龟灵等之师 | 诛仙四剑、诛仙阵图、六魂幡、青萍剑 | 阵法天下第一。诛仙阵需老子、元始、接引、准提四圣联手方破；万仙阵更倾截教全力。单挑略逊老子，但群战与阵法无出其右。 |
| **元始天尊** | 阐教教主，三清之一；十二金仙之师 | 盘古幡、三宝玉如意、万朵金莲护体辇车 | 独探诛仙阵安然无恙，联合三圣破阵。法力深不可测，综合实力稳居圣人前列。 |
| **接引道人** | 西方教教主 | 十二品莲台、青莲宝色旗、接引宝幢 | 四圣破诛仙阵之一，万仙阵中大量收截教门徒。防御与法力并重。 |
| **准提道人** | 西方教二教主 | 七宝妙树、十八手二十四首金身、六根清净竹 | 四圣破诛仙阵之一。战绩极多：收孔宣、败通天、拿乌云仙，是圣人中斗法最活跃者。 |

**T1 内部排序参考**：老子 ≥ 通天 ≈ 元始 > 接引 ≈ 准提。老子实战最稳；通天凭诛仙阵可越级群战；元始综合实力与通天相当；西方二圣略逊三清半筹。
