# 伶伦作乐与音乐文明

## 故事背景

黄帝统一华夏后，部落联盟的规模不断扩大，社会生活日益丰富。然而，当时还没有系统的音乐制度，人们只能通过简单的声音来表达情感，这种方式缺乏规范，难以满足社会生活的需求。随着社会的发展，人们对音乐的需求日益增长，迫切需要建立系统的音乐制度和规范的音乐表达方式。

伶伦作乐是中国音乐史上的重要事件，标志着中华音乐从自发阶段进入自觉阶段。音乐的发明和规范化不仅提高了人们的文化生活，也为礼仪制度和道德教化提供了重要基础。根据《吕氏春秋》、《史记》等文献记载，伶伦通过观察自然界的各种声音，创造了音乐，为中华音乐文明的发展奠定了基础。

伶伦作乐的过程反映了上古时期人类听察能力和艺术创造力的飞跃。通过观察自然界的各种声音和规律，伶伦发现了声音与情感之间的关系，并掌握了用声音表达情感的方法。音乐的发明不仅是技术进步，更是文化进步，它使人类能够用声音来表达情感，促进了文化传承和道德教化。

需要特别说明的是，黄帝时期虽然生产力水平相对低下，但音乐却得到了高度重视，这并非偶然，而是有着深刻的社会、政治和文化原因。首先，在上古社会，音乐是部落凝聚力和认同感的重要载体。通过共同的音乐活动，部落成员能够增强彼此之间的联系，形成共同的文化认同，这对于刚刚完成统一的部落联盟来说尤为重要。据《礼记·乐记》记载："乐者，天地之和也；礼者，天地之序也。"音乐被视为天地和谐的体现，能够促进社会和谐，增强部落凝聚力。

其次，音乐在当时具有重要的政治和礼仪功能。黄帝统一华夏后，需要建立一套完整的礼仪制度来规范社会秩序，而音乐是礼仪制度的重要组成部分。祭祀、庆典、朝会等重大活动都需要音乐来配合，音乐能够增强仪式的庄重感和神圣感，提高政治活动的权威性。据《周礼·春官》记载，周代设有专门的音乐官员，负责管理音乐活动，这说明音乐在政治和礼仪中的地位非常重要。虽然周代的音乐制度比黄帝时期更加完善，但其根源可以追溯到黄帝时期。

第三，音乐在当时具有重要的教育功能。上古社会没有文字，知识和文化的传承主要依靠口传心授，而音乐是口传心授的重要载体。通过音乐，人们可以传递历史、文化、道德等方面的知识，使后代能够了解和继承前人的智慧。据《礼记·乐记》记载："乐者，德之华也。"音乐被视为道德的外在表现，能够教化人心，培养人们的道德品质。

第四，音乐在当时具有重要的医疗和心理调节功能。上古社会医疗条件落后，人们面临各种疾病和心理压力，而音乐被认为能够调节情绪、缓解压力、治疗疾病。据《黄帝内经》记载，音乐可以调节人体的阴阳平衡，促进身心健康。虽然黄帝内经成书于战国至汉代，但其理论基础可以追溯到黄帝时期。

第五，音乐在当时具有重要的劳动组织功能。上古社会的劳动主要依靠人力，需要协调劳动者的动作和节奏，而音乐能够起到协调作用，提高劳动效率。据《吕氏春秋·古乐》记载，古代劳动时常常配合音乐，使劳动者能够协调一致地完成工作。

尽管黄帝时期生产力水平相对低下，但音乐的重要性使得人们愿意投入大量的人力和物力来发展音乐。这不仅反映了上古先民对精神文化生活的追求，也反映了他们对音乐价值的深刻认识。音乐在当时不仅是娱乐活动，更是政治、教育、医疗、劳动等多个领域的重要组成部分，对部落联盟的稳定和发展起到了重要作用。

## 正文

黄帝统一华夏后，部落联盟的规模不断扩大，社会生活日益丰富。黄帝每天都要处理大量的政务，同时也要关心部落成员的文化生活。他发现，随着部落联盟的不断扩大，人们对音乐的需求日益增长。然而，当时的音乐主要依靠经验传承，缺乏系统的理论指导，音乐表达缺乏规范。黄帝深知，如果不能建立系统的音乐制度和规范的音乐表达方式，人们的文化生活将难以提高。

黄帝开始思考如何创造音乐。他首先观察了自然界中的各种声音，如鸟类的鸣叫、兽类的吼叫、风声、雨声、雷声等，试图从中找到创造音乐的灵感。他发现，不同的声音有不同的特点，这些特点可以用来表达不同的情感。如果能够创造一套声音系统，就可以用声音来表达各种情感。据《吕氏春秋·古乐》记载，伶伦"听凤凰之鸣"，这表明伶伦通过观察自然，找到了创造音乐的灵感。

黄帝任命伶伦负责音乐的创造工作。伶伦是黄帝时期的乐官，负责部落联盟的音乐活动。伶伦深知音乐的重要性，他接受了黄帝的委托，开始了音乐的创造工作。伶伦首先研究了自然界中的各种声音，分析了其特点和规律。他发现，不同的声音有不同的音高、音色和节奏，这些特点可以用来表达不同的情感。据《吕氏春秋·古乐》记载，伶伦"制十二筒，以听凤凰之鸣，其雄鸣为六，雌鸣亦六"，这表明伶伦通过观察自然，发现了声音的规律。

伶伦开始尝试创造音乐。他首先从最简单的声音开始，如单音、双音、和弦等，这些声音可以用来表达基本的情感。经过反复试验，伶伦掌握了创造声音的技术，能够创造出各种声音。然而，伶伦很快发现，如果只是创造一些孤立的声音，这些声音之间没有联系，难以形成一个完整的音乐系统。伶伦认为，音乐必须是一个完整的系统，各个声音之间必须有联系，才能有效地表达情感。

伶伦开始尝试创造系统的音乐。他观察了自然界中的各种声音，如鸟类的鸣叫、兽类的吼叫、风声、雨声、雷声等，试图从中找到创造音乐的规律。他发现，不同的声音有不同的音高，这些音高可以形成一个音阶。同时，不同的声音之间也有和谐的关系，这些关系可以用来创造和谐的音乐。据《吕氏春秋·古乐》记载，伶伦"制十二筒，以听凤凰之鸣，其雄鸣为六，雌鸣亦六，以比黄钟之宫，皆可以生之"，这表明伶伦通过观察自然，发现了音阶的规律。

在创造音乐的过程中，伶伦遇到了很多困难。首先，如何创造能够表达不同情感的音阶是一个难题。伶伦经过反复思考，认为可以用不同的音高来表示不同的情感。例如，用高音来表示欢快的情感，用低音来表示悲伤的情感。据《吕氏春秋·古乐》记载，伶伦"制十二筒，以听凤凰之鸣，其雄鸣为六，雌鸣亦六"，这表明伶伦通过观察自然，创造了十二律音阶。其次，如何创造能够表达复杂情感的旋律也是一个难题。伶伦经过反复思考，认为可以用不同的音高组合来表示复杂的情感。例如，用上升的旋律来表示希望，用下降的旋律来表示绝望。

伶伦开始尝试创造更加复杂的音乐。他发现，可以用节奏来增强音乐的表现力。节奏是音乐的重要组成部分，可以用来表达不同的情感和意境。例如，用快速的节奏来表示兴奋，用缓慢的节奏来表示平静。据《吕氏春秋·古乐》记载，伶伦"以比黄钟之宫，皆可以生之"，这表明伶伦通过创造节奏，增强了音乐的表现力。同时，伶伦还发现，可以用和声来丰富音乐的表现力。和声是多个声音的组合，可以创造出更加丰富的音乐效果。

伶伦创造音乐的消息很快传遍了整个部落联盟。黄帝立即下令在部落联盟中推广使用这套音乐系统。黄帝还任命专门的乐官，负责教授部落成员使用音乐。据《史记·乐书》记载，黄帝"作咸池之乐"，这表明黄帝非常重视音乐的推广和应用。

音乐的推广使用，给部落联盟带来了巨大的变化。首先，音乐提高了人们的文化生活。有了音乐，人们可以用声音来表达各种情感，如欢乐、悲伤、愤怒、恐惧等，提高了人们的文化生活。其次，音乐促进了礼仪制度和道德教化。有了音乐，人们可以用音乐来配合礼仪活动，如祭祀、庆典、婚礼、葬礼等，促进了礼仪制度和道德教化。据《礼记·乐记》记载，"乐者，天地之和也；礼者，天地之序也"，这表明音乐的发明为礼仪制度和道德教化奠定了基础。

## 备注

**史料来源与可靠性说明**：

1. **《吕氏春秋·古乐》**：关于伶伦作乐的记载最为详细。原文："昔黄帝令伶伦作为律。伶伦自大夏之西，乃之阮隃之阴，取竹于嶰溪之谷，以生空窍厚钧者，断两节间，其长三寸九分，而吹之，以为黄钟之宫，吹曰舍少。次制十二筒，以之阮隃之下，听凤凰之鸣，以别十二律。其雄鸣为六，雌鸣亦六，以比黄钟之宫，皆可以生之。故曰黄钟之宫，律吕之本。"《吕氏春秋》是先秦时期的文献，记载了上古音乐的发展，具有较高的史料价值。

2. **《史记·乐书》**：记载了黄帝的音乐创作。原文："黄帝作咸池之乐，尧作大章之乐，舜作大韶之乐，禹作大夏之乐，汤作大护之乐，武王作大武之乐。"《史记》是汉代正史，记载了上古音乐的发展，具有较高的可靠性。

3. **《礼记·乐记》**：记载了音乐的作用。原文："乐者，天地之和也；礼者，天地之序也。和，故百物皆化；序，故群物皆别。乐由天作，礼以地制。过制则乱，过作则暴。明于天地，然后能兴礼乐也。"《礼记》是先秦时期的礼制文献，记载了音乐的作用，具有较高的史料价值。

4. **《周礼·春官》**：记载了音乐制度。原文："大司乐掌成均之法，以治建国之学政，而合国之子弟焉。凡有道者、有德者，使教焉，死则以为乐祖，祭于瞽宗。以乐德教国子，中、和、祗、庸、孝、友；以乐语教国子，兴、道、讽、诵、言、语；以乐舞教国子，舞云门、大卷、大咸、大韶、大夏、大护、大武。"《周礼》是先秦时期的礼制文献，记载了音乐制度，具有较高的史料价值。

**史实争议说明**：

1. **伶伦作乐的真实性**：关于伶伦是否真的发明了音乐，存在争议。现代学者普遍认为，音乐的发明是一个长期的过程，不可能由一人完成。伶伦可能是音乐整理和推广的推动者，而不是音乐的唯一发明者。

2. **音乐的发明时间**：关于音乐的发明时间，存在不同观点。传统观点认为音乐发明于黄帝时期；现代考古发现表明，音乐的起源可能更早，但成熟音乐的形成确实在黄帝时期。

3. **伶伦的身份**：关于伶伦是否为真实的历史人物，存在争议。一些学者认为伶伦是黄帝的乐官，是真实的历史人物；另一些学者则认为伶伦是音乐发明者的代称，可能不是具体的历史人物。

4. **十二律音阶的发明**：关于十二律音阶是否由伶伦发明，存在争议。一些学者认为十二律音阶是后世发明的，被附会到伶伦身上；另一些学者则认为十二律音阶的原理在黄帝时期可能已经存在。

**十二律音阶的具体内容及其流传情况**：

十二律音阶是中国古代音乐理论的核心组成部分，由伶伦根据凤凰的鸣声创造而成。根据《吕氏春秋·古乐》记载，伶伦"制十二筒，以听凤凰之鸣，以别十二律。其雄鸣为六，雌鸣亦六，以比黄钟之宫，皆可以生之"。十二律分为六律（阳律）和六吕（阴吕），共十二个音律，构成了完整的音阶体系。

**六律（阳律）**：
1. **黄钟** - 十二律之本，为宫音，是音阶的基准音。据《吕氏春秋·古乐》记载，伶伦"取竹于嶰溪之谷，以生空窍厚钧者，断两节间，其长三寸九分，而吹之，以为黄钟之宫，吹曰舍少"。
2. **太簇** - 商音，音高较黄钟高。
3. **姑洗** - 角音，音高较太簇高。
4. **蕤宾** - 变徵音，音高较姑洗高。
5. **夷则** - 徵音，音高较蕤宾高。
6. **无射** - 羽音，音高较夷则高。

**六吕（阴吕）**：
1. **大吕** - 变宫音，音高介于黄钟和太簇之间。
2. **夹钟** - 商音，音高介于太簇和姑洗之间。
3. **仲吕** - 角音，音高介于姑洗和蕤宾之间。
4. **林钟** - 变徵音，音高介于蕤宾和夷则之间。
5. **南吕** - 徵音，音高介于夷则和无射之间。
6. **应钟** - 羽音，音高介于无射和黄钟之间。

十二律音阶的发明，标志着中国古代音乐理论的形成。音阶的建立，使音乐创作和演奏有了规范和标准，为后世音乐的发展奠定了基础。十二律音阶不仅用于音乐创作，还用于历法、度量衡等领域，体现了中国古代"天人合一"的思想。

十二律音阶在后世得到了广泛流传和发展。据《史记·律书》记载，汉代已经形成了完整的律吕体系，用于宫廷音乐和民间音乐。到了唐代，十二律音阶与外来音乐融合，形成了更加丰富的音乐体系。宋代以后，十二律音阶的理论不断完善，出现了《律吕新书》等专门著作。明清时期，十二律音阶的理论与实践相结合，形成了中国传统音乐的完整体系。

现代研究表明，十二律音阶与现代音乐的十二平均律有一定的相似性，但并不完全相同。十二律音阶是基于三分损益法计算的，而十二平均律是基于数学比例计算的。尽管如此，十二律音阶作为中国古代音乐理论的核心，对中华音乐文明的发展产生了深远的影响。

**黄帝时期使用的乐器**：

根据史料记载和考古发现，黄帝时期使用的乐器主要包括以下几类：

**1. 打击乐器**：
- **钟** - 青铜钟，用于宫廷音乐。虽然青铜钟在商周时期才发展成熟，但其雏形可能在黄帝时期就已经存在。
- **磬** - 石制打击乐器，通过敲击石片发出声音。据《尚书·益稷》记载，"戛击鸣球、搏拊琴瑟以咏"，其中"鸣球"可能指的就是磬。
- **鼓** - 皮制打击乐器，通过敲击兽皮蒙在木框上发出声音。鼓是最古老的乐器之一，在上古社会广泛使用。
- **柷** - 木制打击乐器，形状像斗，用于音乐开始。据《周礼·春官》记载，柷用于"以止乐"。
- **敔** - 木制打击乐器，形状像伏虎，用于音乐结束。据《周礼·春官》记载，敔用于"以止乐"。

**2. 吹奏乐器**：
- **埙** - 陶制吹奏乐器，形状像鹅蛋，通过吹气发出声音。埙是中国最古老的吹奏乐器之一，考古发现表明，埙在新石器时代就已经存在。
- **籥** - 竹制吹奏乐器，形状像笛子，通过吹气发出声音。据《吕氏春秋·古乐》记载，伶伦"制十二筒"，可能指的就是籥。
- **箫** - 竹制吹奏乐器，形状像笛子，通过吹气发出声音。箫在黄帝时期可能已经存在，但其具体形制可能与后世不同。
- **箎** - 竹制吹奏乐器，形状像笛子，通过吹气发出声音。据《诗经·小雅·何人斯》记载，"伯氏吹埙，仲氏吹箎"，说明箎在古代广泛使用。
- **笙** - 簧片吹奏乐器，通过吹气使簧片振动发出声音。笙在黄帝时期可能已经存在，但其具体形制可能与后世不同。

**3. 弹拨乐器**：
- **琴** - 七弦琴，通过拨动琴弦发出声音。琴是中国最古老的弹拨乐器之一，据《史记》记载，琴在黄帝时期就已经存在。
- **瑟** - 二十五弦瑟，通过拨动琴弦发出声音。瑟是中国最古老的弹拨乐器之一，据《诗经》记载，瑟在古代广泛使用。

需要说明的是，黄帝时期的乐器主要是陶制、竹制、木制乐器，金属乐器如青铜钟等可能在商周时期才发展成熟。琴瑟等弹拨乐器的发展需要更长的历史过程，其在黄帝时期的具体形制可能与后世不同。

**流传至今的音乐作品和史料**：

根据史料记载，黄帝时期及后世流传下来的古代乐舞主要有：

**1. 黄帝时期**：

**3. 夏商周时期**：
- **《大夏》** - 禹创作的乐舞，歌颂禹治水的功德。据《史记·乐书》记载，"禹作大夏之乐"。《大夏》是夏代的重要乐舞，用于祭祀和庆典活动。

**4. 颛顼时期**：
- **《承云》** - 颛顼创作的乐舞，模仿八风之音。据《吕氏春秋·古乐》记载，"帝颛顼令飞龙作乐，效八风之音，命之曰《承云》"。《承云》是颛顼时期的重要乐舞，体现了古代对自然声音的模仿和利用。

### 联系与比较视角

**纵向联系**：上承原始祭祀鼓乐—骨笛吹奏传统，下启夏商「乐舞—祀典」一体化与周代「礼乐」制度；伶伦制律是中国音律史的起点性叙事。

**横向联系**：与古希腊毕达哥拉斯的弦长比率律、印度《娑摩吠陀》的祭祀音乐、两河流域竖琴—里拉音阶体系属于人类早期音律独立探索的平行线索。

**辩证视角**：伶伦截竹定律的传说含有理想化成分，但贾湖骨笛（距今 8000—9000 年）已可吹奏七声音阶，说明上古中国音律实践远早于伶伦所处时代。

**母题归纳**：属「圣王—乐官—定律」母题，与希腊「缪斯—阿波罗—竖琴」、印度「梵天—娑摩—吠陀」结构同型，均以音乐为宇宙秩序的听觉表达。

### 多维阐释视角

**制度机理**：乐律制度承担节气、祭祀、军事、礼仪四项功能；「十二律」思维将时间（月）、空间（方位）、音高三者对应，为后世律历合一、音义相通的宇宙观奠基。

**长时段动因**：黄河流域竹材（大宛竹）与标准化手工技术的发展，为乐律定量化创造条件；而等级化社会对仪式音乐的需求推动「官方音律」的产生。

**地理—经济—生态**：伶伦传说提到取竹于昆仑阮隃，反映上古乐律材料「远求名山」的神圣化需求；同时也暗示了早期长距离原材料网络。

**跨文明同期**：公元前 2500—前 2000 年，苏美尔乌尔王陵出土竖琴与定调器、古埃及第五—第六王朝有成体系的乐师群体，乐律知识正作为王权仪典的核心。

**概念史**：「律」本义为「法度、刻度」，由音乐度量引申为「法律」；「吕」与「律」分属阴阳，构成十二律吕的双轨结构，体现阴阳互补的宇宙观。
