# 文王访贤与渭水聘子牙——飞熊入梦与西岐立基

## 故事背景

《封神演义》第十九回"伯邑考进贡赎罪"至第二十四回"渭水文王聘子牙"，是"西岐兴起"叙事段中承上启下的枢纽篇章。上一篇（#5）以姜子牙的视角写他从昆仑下山、朝歌试道到磻溪垂钓的完整弧线；本篇则将镜头切回西岐——以文王姬昌的视角，写他从羑里脱困、归国吐子、造灵台梦飞熊，最终在渭水之畔亲访姜子牙、拜为国师的全过程。

从叙事结构看，本篇覆盖六回正文（第十九至二十四回），但叙事主线高度集中：**文王姬昌从"囚徒"到"明主"的蜕变**。这一蜕变由四个相互咬合的叙事段落构成：其一是"羑里之痛"——长子伯邑考赴朝歌进贡赎罪，被妲己陷害、纣王剁为肉酱，文王在羑里明知子肉而含泪吞食，以隐忍保全性命；其二是"脱困归国"——散宜生以重金贿赂费仲、尤浑，二奸臣在纣王面前力保姬昌，纣王下旨赦免并加封文王，文王借"夸官"之机夤（yín，深夜）夜逃出朝歌，雷震子奉云中子之命下山救父、背父飞出五关；其三是"飞熊入梦"——文王归国后造灵台、泽枯骨，夜梦白额猛虎胁生双翼扑入帐中，散宜生解为"飞熊入梦"之大吉兆，预示西岐将得栋梁之臣；其四是"渭水聘贤"——文王率文武出南郊访贤，经武吉引路，在磻溪之畔见到直钩垂钓的姜子牙，以大礼聘为国师，西岐从此有了灭纣兴周的总设计师。

在原著与正史的对照上，本篇涉及多处"史影与文学的交错"：其一，伯邑考——正史《史记·管蔡世家》仅记"文王长子伯邑考"，未载其死因；《帝王世纪》始有"纣烹伯邑考为羹赐文王"之说，《封神演义》在此基础上加入了妲己引诱、白面猿猴行刺、剁为肉酱等文学细节。其二，文王食子——正史《帝王世纪》记"文王食之"，是文王忍辱负重的史影；《封神演义》第二十回将这一情节演绎为"明知子肉而含泪吞食"，并加入"吐子"（文王归国后吐出三只兔子）的民间传说。其三，文王脱困——正史《史记·周本纪》记"闳夭之徒患之，乃求有莘氏美女、骊戎之文马、有熊九驷、他奇怪物，因殷嬖臣费仲而献之纣，纣大说，曰：'此一物足以释西伯，况其多乎！'乃赦西伯"，是文王获释的史实骨架；《封神演义》将"闳夭"改为"散宜生"，并增加了雷震子救父、背父飞出五关的神魔情节。其四，飞熊入梦——正史《史记·齐太公世家》"西伯将出猎，卜之，曰：'所获非龙非彲，非虎非罴，所获霸王之辅'"是"非熊"（即飞熊）的原型；《封神演义》第二十三回将"出猎卜卦"改为"灵台夜梦"，并借散宜生之口将"非熊"解为"飞熊"。

本篇以《封神演义》第十九至二十四回为主叙事底本，忠实原著情节，以"关联"为抓手——把原著"文王脱困—归国—梦兆—访贤"的叙事链，与正史"文王获释—渭水遇太公"的史影相互勾连，揭示同一历史事件在史书与神魔小说中的不同面貌。

## 故事正文

磻溪的直钩还悬在水面三尺之上，姜子牙还在等他的"愿者"。而远在朝歌的羑（yǒu）里城中，那位他等的"愿者"——西伯侯姬昌——已经整整被囚了七年。

七年。七年前，姬昌因同情被炮烙的忠臣、在朝堂上叹息了一声，被崇侯虎告发，纣王一道旨意将他押入羑里。七年里，朝歌城外的世界天翻地覆：妲己入宫、炮烙虿（chài，蝎子）盆、比干剖心、哪吒闹海、姜子牙下山——但姬昌一概不知。他在羑里城中每日做的事只有两件：一是闭门待罪，二是将伏羲八卦演为六十四卦、三百八十四爻，按阴阳消息之机、周天划度之妙，推演出一部《周易》。

西岐那边，姬昌的长子伯邑考坐不住了。父亲被囚七年，做儿子的怎能安寝？他对上大夫散宜生说："我要去朝歌，以进贡为名，代父赎罪。"散宜生力劝不可，但伯邑考心意已决。他进宫辞别母亲太姬，将西岐内事托付二弟姬发、外事托付散宜生、军务托付大将军南宫适（kuò），然后收拾了祖传的三件镇国之宝——七香车、醒酒毡、白面猿猴——外加美女十名，择日上路。

这三件宝贝各有来历。七香车是轩辕黄帝破蚩尤于北海时传下来的，人坐其上不用推引，欲东则东、欲西则西。醒酒毡能解千杯之醉，人若酩酊大醉卧于毡上，不消片刻即醒。白面猿猴虽是畜类，却善知三千小曲、八百大曲，能讴筵前之歌、善为掌上之舞。伯邑考带着这些宝物，扬鞭纵马，过汜（sì）水关、渡黄河、入朝歌城。

伯邑考在午门外素缟抱本，等了整整五天，才遇到亚相比干。比干见他为父陈冤、言辞恳切，便将进贡本章转呈纣王。纣王在摘星楼上见了伯邑考，见他"丰姿都雅、目秀眉清、唇红齿白、言语温柔"，心中已有几分好感。但妲己在内帘后偷看伯邑考，见他年轻俊美，便起了邪念。

妲己传旨卷起珠帘，对纣王说："妾闻西岐伯邑考善能鼓琴，真世上无双、人间绝少。陛下可着邑考抚弹一曲，便知深浅。"纣王准奏。伯邑考盘膝坐定，将琴置于膝上，十指拨动，弹了一曲《风入松》。原书写道："音韵幽扬，真如戛玉鸣珠，万壑松涛，清婉欲绝，令人尘襟顿爽，恍如身在瑶池凤阙。"一曲终了，纣王听得入神，妲己更是心旌摇荡。

妲己对纣王说："陛下可赦邑考之罪，令其在此教妾抚琴，待妾学精之后，早晚侍奉陛下。"纣王准奏。妲己便借学琴之名，深夜将伯邑考召入内宫，以言语挑逗。伯邑考正气凛然，以"君臣之礼、母子之分"严词拒绝。妲己恼羞成怒，次日便在纣王面前哭诉伯邑考"以琴挑之"。纣王大怒，命人将伯邑考拿下。

伯邑考见事已至此，取过琴来，隔席向妲己猛力打去——这一击虽未打中，却将盘碟打得纷飞。纣王怒不可遏："匹夫！猿猴行刺被你巧言说过，今又以琴击皇后，分明弑逆！"喝令左右将伯邑考拿下摘星楼。妲己命人取四根长钉，将伯邑考手足钉住，用刀碎剁。原书写伯邑考临死骂不绝口："贱人！你将成汤锦绣江山化为乌有。我死不足惜，忠名常在，孝节永存！"不一时，伯邑考被剁成肉酱。

妲己又生毒计，对纣王说："妾闻姬昌号为圣人，能明祸福、善识阴阳。圣人当不食子肉。今将邑考之肉做成肉饼，赐与姬昌。若昌竟食，此人妄诞虚名；如果不食，当速斩姬昌，恐遗后患。"纣王准奏，命厨役将伯邑考之肉做成肉饼，差官送往羑里。

羑里城中，姬昌正在抚瑶琴。猛然琴中大弦发出杀声，姬昌大惊："此杀声主何怪事？"忙取金钱占了一课，不觉泪流满面："我儿不听父言，遭此碎身之祸！今日如不食子肉，难逃杀身之殃；如食子肉，其心何忍？"正悲痛间，使命官到。姬昌缟素接旨，使命官将龙凤膳盒摆在面前，说："主上见贤侯在羑里久羁，圣心不忍。昨日圣驾幸猎，打得鹿獐之物，做成肉饼，特赐贤侯。"

姬昌跪在案前，揭开膳盒——明知里面是自己长子的肉。他含悲忍泪，连食三饼，将盒盖了，叩头谢恩："圣上受鞍马之劳，反赐犯臣鹿饼之享，愿陛下万岁！"使命官暗暗叹道："人言姬昌能知先天神数、善晓吉凶，今日见子肉而不知，连食而甘美——所谓阴阳吉凶，皆是虚语！"使命官回朝复命，纣王听了大笑："姬昌素有重名，今观自己子肉食而不知，人言可尽信哉！"

但费仲却起了疑心。他对纣王说："昌数无差，定知子肉。恐欲不食又遭屠戮，只得勉强忍食，以为脱身之计。陛下不可不察。"纣王听罢犹豫，便暂不赦姬昌。

消息传到西岐，伯邑考的随从星夜逃回，向二公子姬发哭报："公子往朝歌进贡，被纣王醢（hǎi，剁为肉酱）为肉酱！"姬发大哭于殿廷，几乎气绝。大将军南宫适大叫："公子无辜而受屠戮，君臣之义已绝！何不统倾国之兵，先取五关，杀上朝歌，剿戮昏君，再立明主！"两边武将齐声响应。

散宜生急忙阻止："主公以仁义闻于天下，今日若兴兵伐纣，天下必以西岐为叛逆。不如先救主公归国为上。"散宜生定下一计——以重金贿赂纣王的两个宠臣费仲、尤浑。他备了两份厚礼：白璧、黄金、彩缎、玉带，派太颠送费仲、闳夭（hóng yāo）送尤浑，二人扮作商贾，星夜潜入朝歌。

费仲、尤浑各收了礼物，在纣王面前一唱一和。费仲先说："臣暗使心腹探听虚实，羑里军民俱言姬昌实有忠义，每月逢朔望焚香祈求陛下国祚安康。囚昌七载，并无一怨言。姬昌真乃忠臣。"尤浑又奏："姬昌数年困苦，训羑里万民，万民感德，称姬昌为圣人。陛下若赦姬昌归国，再加一王封，假以白旄（máo）黄钺（yuè）、得专征伐，使东南两路知之，不战自退。"纣王大喜，即降赦条，单赦姬昌速离羑里，并加封为"文王"，赐白旄黄钺，专征伐之权。

姬昌接了赦旨，不敢久留。武成王黄飞虎暗中相助，给了他铜符令箭以便出关。文王连夜离了朝歌，过孟津、渡黄河，过渑（miǎn）池，往临潼关方向疾行。但纣王随后便得了费仲、尤浑的密报——二人怕担责任，又反过来告发文王"夸官二日不谢圣恩、暗自逃归"。纣王大怒，命神武大将军殷破败、雷开点三千飞骑追赶。

文王行至临潼关前，回头望见后面尘土荡起、人马喊杀之声渐近，惊得魂飞魄散。他仰天叹道："武成王虽是为我，我一时失于打点，夤（yín）夜逃归。此一拿回，再无生理！"正危急间——

终南山玉柱洞中，云中子正在碧游床运其元神，猛的心血来潮，掐指一算："呀！原来西伯灾厄已满，目下逢危。今日正当他父子重逢！"便叫金霞童子去桃园请雷震子。

雷震子见了云中子下拜。云中子曰："徒弟，汝父有难，你可前去救拔。"雷震子问："弟子父是何人？"云中子曰："汝父乃是西伯侯姬昌，有难在临潼关。你可往虎儿崖下寻一兵器来，待吾秘授你些兵法。"

雷震子来到虎儿崖下，东瞧西看寻不到兵器。正欲转身回洞，忽然闻到一阵异香扑鼻。循香望去，只见绿叶之下有两枚红杏。雷震子心中欢喜，攀藤附葛摘了下来。他吃了一枚，觉得馨香甘美，忍不住把另一枚也吃了。刚吃完，左胁下"嘭"的一声响，长出一只翅膀来，翅尖拖到了地上。雷震子大惊，伸手去拔——不防右胁下又"嘭"的一声，又冒出一只翅膀。他吓得坐在地上，双手一摸脸：鼻子高了，像鹰嘴一样勾着；眼睛凸了出来；牙齿横生，探到了唇外。跑到水边一照——面如蓝靛，发似朱砂，完全变了一副模样。

雷震子拖着两只翅膀，像斗败了的鸡一样回到洞中。云中子见了哈哈大笑："雷震子，你变身了！"雷震子哭丧着脸问："师父，我这是怎么回事？"云中子说："你吃了两枚仙杏，已脱了凡胎。来，为师传你棍法。"云中子取出一条金棍，传授雷震子棍法。那金棍上下飞腾，盘旋如风雨之声，进退有龙蛇之势。云中子又在雷震子翅上各写一道符印——左翅"风"字，右翅"雷"字——雷震子将双翅一振，飞腾于半空之中，风雷之声大作。

云中子叮嘱："你速往临潼关救你父亲，送他出五关便回，不许伤纣王军将，也不许同你父往西岐。功完速回终南，再传你道术。"

雷震子展翅飞到临潼关上空，正见殷破败、雷开率三千飞骑追到文王身后。雷震子落将下来，拦在路中。殷破败厉声喝问："汝是何人，敢拦去路？"雷震子答："吾乃西伯文王第百子雷震子是也。吾父王乃仁人君子，无故被囚七载，今既放归，为何又来追袭？你二人好好回去，不必言勇！"

殷破败大笑："好丑匹夫！焉敢口出大言！"纵马舞刀来取。雷震子将金棍架住，说："我师父吩咐不可伤人间众生，故教汝速退。但你要定个雌雄——我且试与你看。"他将胁下双翅一振，飞上半空，有风雷之声。脚登天、头望下，看见西边有一山嘴往外扑着，雷震子说："待我把这山嘴打一棍你看。"一声响亮，金棍落下，山嘴滚下一半。雷震子转身落下来，对二将说："你的头可有这山结实？"

殷破败、雷开见此凶恶，魂不附体，只得拨马而回。

雷震子回到山上见文王。文王已被刚才的景象吓得呆了。雷震子说："父王，追兵已退。如今事急，恐后面又有兵来。待孩儿背父王飞出五关。"文王看着自己那匹随他患难七年的马，心中不忍："此马随我七年，今日一旦弃他，我心何忍？"雷震子劝道："事已到此，君子弃小而全大。"文王上前以手拍马，叹道："马！非昌不仁，舍你出关。奈恐追兵复至，我命难逃。我今别你，任凭你去罢，另择良主。"说罢洒泪别马。

文王伏在雷震子背上，紧闭二目，只听得耳边风声呼啸。不过一刻，雷震子已飞出五关，落在金鸡岭上。文王睁开眼，已知是西岐本土，大喜道："今日复见我故乡之地，皆赖孩儿之力！"雷震子叩头道："父王前途保重，孩儿就此告归。奉师父之命，止救父王出关即归山洞。孩儿学全道术，不久下山再拜尊颜。"父子洒泪而别。

文王独自一人，步行一日，年高跋涉艰难。傍晚投店歇宿，次日起身囊中无钱，被店小儿拦住索要饭钱。店主人申杰出来，见文王虽年迈但精神相貌不凡，问明来历。文王说："我非别人，乃西伯侯是也。因囚羑里七年，蒙圣恩赦宥归国。幸逢吾儿雷震子救我出五关，因此囊内空虚。"申杰大惊，慌忙倒身下拜，献上壶浆，又将自己家中磨面的驴儿收拾鞍辔，亲自送文王归国。

文王骑着驴，过了金鸡岭、首阳山，一路上晓行夜住。这日行至西岐山，转过迢遥径路，故国在望。文王不觉心中凄惨："昔日朝商之时遭此大难，不意今日回归又是七载。青山依旧，人面已非。"

正嗟叹间，只见两杆红旗招展，大炮一声，簇拥一队人马。左有大将军南宫适、右有上大夫散宜生，引了四贤八俊、三十六杰伏于道旁。次子姬发近前拜伏驴前："父王羁縻异国，时月累更，为人子不能分忧代患，诚天地间之罪人！今日复睹慈颜，不胜欣慰。"

文王见众文武、世子多人，不觉泪下："孤想今日不胜凄惨。孤已无家而有家，无国而有国，无臣而有臣，无子而有子。陷身七载，羁囚羑里，自甘老死。今幸见天日，与尔等复能完聚，睹此反觉凄惨耳。"

散宜生劝道："昔成汤王亦囚于夏台，一日还国而有事于天下。今主公归国，更修德政、育养民生，俟时而动——安知今日之羑里，非昔之夏台乎？"

文王换了王服，乘辇入城。西岐万民牵羊担酒、户户焚香，一路上欢声拥道、乐奏笙簧。众民大呼："七年远隔，未睹天颜。今大王归国，万民瞻仰！今日西岐有主矣！"文王出小龙山口，见两边文武、九十八子相随，独不见长子伯邑考——想起他被醢尸之苦、自己在羑里吞食子肉之痛，不觉心中大痛，泪如雨下。文王以衣掩面，作歌道：

> 尽臣节兮奉旨朝商，直谏君兮欲正纲常。谗臣陷兮困于羑里，不敢怨兮天降其殃。食子肉兮痛伤骨髓，感圣恩兮位至文王。夸官逃难兮路逢雷震，命不绝兮幸济吾疆。今归西土兮团圆母子，独不见邑考兮碎裂肝肠！

歌罢，文王大叫一声："痛杀我也！"跌下马来。左右慌忙扶起。只见文王连吐三口——每口吐出一块肉羹，那肉羹落地便化为三只白兔，蹦跳而去。这便是后世"文王吐子"的传说——"吐子"即"兔子"，以谐音寄哀思。

文王归国之后，修德政、育民生，西岐日益强盛。一日，文王对散宜生说："孤思西岐城南，欲造一台，名曰'灵台'，以占风候、看验民灾。但恐土木之工劳伤百姓。"散宜生奏道："大王造灵台为西土之民而设，非为游观之乐，何为劳民？"文王便出告示：愿做工者每日给工银一钱，不愿者不强逼。西岐军民见了告示，齐声欢呼："大王恩德如天！我等虽肝脑涂地，亦所甘心，如何反领大王工银？"众人情愿出力，不领工钱。

灵台不出一月便告完工。文王率文武登台观看，雕梁画栋，台砌巍峨。文王默然不语。散宜生问："灵台工完，大王为何不悦？"文王说："此台虽好，台下欠一池沼以应'水火既济、配合阴阳'之意。孤欲再开池沼，又恐劳伤民力。"话音未落，众民大呼："小小池沼，有何难成！"众人挥锹便挖。挖着挖着，土中翻出一付枯骨，众人随手抛掷。文王在台上看见，急传旨："将枯骨取来，用匣盛之，埋于高阜之地。岂有因孤开沼而暴露此骸骨？实孤之罪也。"众人听了大呼："圣德之君，泽及枯骨！何况我等人民！"

天色渐晚，回驾不及。文王与文武在灵台上设宴，君臣共乐。席罢，文武在台下安歇，文王在台上设绣榻而寝。时至三更，文王正在梦中——忽见东南方向一只白额猛虎，胁生双翼，向帐中扑来。文王急叫左右，只听台后一声响亮，火光冲霄。文王惊醒，吓了一身香汗。

次日一早，文王召散宜生解梦。散宜生躬身贺道："此梦乃大王之大吉兆！主大王得栋梁之臣、大贤之士，真不让风后、伊尹之右。"文王问："何以见得？"散宜生说："昔商高宗曾有飞熊入梦，得傅说于版筑之间。今主上梦虎生双翼者，乃熊也；又见台后火光，乃火锻物之象。今西方属金，金见火必锻，锻炼寒金必成大器。此乃兴周之大兆！"

文王大喜，便传旨出南郊访贤。南宫适领五百家将出南郊布置围场，众武士披坚执锐，带着黄鹰猎犬。文王到了南郊，见围场罗网密布，大惊道："上大夫，这里怎么设了围场？"散宜生欠身说："南宫将军设围场，等主公前来游猎，畅快心胸。"文王正色道："大夫此言差矣！如今初春时节，正是万物生育之时，如何残杀生灵？古人体现天地好生之仁，不忍剪除树木枝丫。快叫南宫把围场拆了！"南宫适慌忙撤了围场。

文王一行沿渭水而行，一路寻访。先遇一伙渔人，在渭水边唱歌而行。文王听那歌词清奇，便命人请渔人近前询问。渔人说："这歌不是我们编的——离此三十五里，磻溪边上有一位老道长，天天在那里垂钓，这歌是他教我们唱的。"文王又问："那老道长姓甚名谁？"渔人说："姓姜，名尚，字子牙，道号飞熊。"

"飞熊！"文王心中一震——正应了灵台之梦。

文王继续前行，又遇一伙樵夫挑柴而来，唱的也是清奇之歌。文王问樵夫歌从何来，樵夫也说是磻溪边那位老道长教的。文王又问："那老道长如何垂钓？"樵夫笑道："说也奇怪——他的钓钩是直的，离水三尺，不挂鱼饵。他还说：'宁在直中取，不向曲中求。不为锦鳞设，只钓王与侯。'"

文王听了，心中愈发笃定。正行间，只见一人挑着一担柴唱歌而来：

> 春水悠悠春草奇，金鱼未遇隐磻溪。世人不识高贤志，只作溪边老钓矶。

文王听这歌声，嗟叹道："附近必定有大贤！"命人将樵夫请来。这樵夫不是别人，正是武吉——当初在南门误伤门军王相，被文王画地为牢判了死罪，后经散宜生奏请放回家安置老母。姜子牙收他为徒，以厌星之术替他掩过灾厄。散宜生一见武吉，大惊道："你不是跳万丈深潭死了吗？"武吉跪地，将姜子牙收他为徒、替他厌星之事一一禀明。

文王叹道："原来如此。武吉，你带孤去见你师父。"

磻溪之畔，姜子牙依旧端坐青石之上。直钩，无饵，离水三尺。远处烟尘大起——文王姬昌，来了。

文王远远望见溪边一位白发老叟，鹤发银须，目光深邃，仿佛与这天地融为一体。他翻身下了逍遥马，命散宜生、南宫适等人在远处等候，自己只带数名随从，步行来到溪边。

文王整了整衣冠，近前拱手行礼："老先生，晚辈姬昌，久仰大名。"

姜子牙缓缓抬头，看了文王一眼，微微一笑。那笑容里没有惊讶，没有谦卑，只有一种历经沧桑后的通透与淡然。

文王在溪边青石上坐下，开口便问："老先生，你这鱼钩离水三尺，钩直无饵——如何能钓得鱼？"

姜子牙声音清朗："老夫钓鱼，与众不同。宁在直中取，不向曲中求。不为锦鳞设，只钓王与侯。"

文王心中一凛。不为锦鳞，只钓王侯——天底下敢说这话的人，若非狂徒，必是奇士。而这老者气宇轩昂、谈吐不凡，显然是后者。

文王郑重地躬身一拜："姬昌敢问先生——方今天下，纣王无道，生灵涂炭。西岐虽小，愿为天下开太平。先生可有以教我？"

姜子牙放下钓竿，目光灼灼地看着文王。他没有推辞，也没有客套，开口便纵论天下大势——从三皇五帝说到夏桀商纣，从天文星象说到山川形胜，从用兵阵法说到治国之道。他说：纣王之所以失天下，不在兵甲不利、不在府库不充，而在失人心。炮烙忠良、虿盆宫女、剖比干之心、醢伯邑考之肉——每一桩暴行，都是在为西岐积攒天命。天命不在祭坛之上，而在万民之心。

他又说：西岐之所以能兴，不在城池之固、不在甲兵之众，而在仁义。仁义不是空谈——灵台给工钱是仁义，泽及枯骨是仁义，撤围场不杀生是仁义。这些事看似细小，但天下人看在眼里，民心便向西岐汇聚。得民心者得天下，失民心者失天下——这便是天道。

一席话罢，文王已是汗颜。他自认勤政爱民、贤名远播，可与眼前这位老者相比，方知自己的见识不过是井底之蛙。什么是真正的治国之道，什么是帝王之学，今日才算真正领教。

文王起身，再次深深鞠躬："先生，请随我回西岐。姬昌愿拜先生为国师，一切军国大事，皆听先生裁决。"

姜子牙却拂袖而起，摇了摇头："老臣年逾七旬，垂垂老矣，只怕不堪驱驰，误了大王大事。"

文王哪里肯依，再三恳请。散宜生在旁，命人摆开聘礼——白璧、黄金、锦缎，列于溪边。姜子牙看了，命童子收了。

散宜生又推来王车，请姜子牙上车。姜子牙跪地道："老臣蒙大王厚恩，以礼相聘，怎敢乘坐王车？乱了名分，断然不敢！"文王再三相请，姜子牙终不敢坐。最后散宜生建议：让姜子牙骑文王的逍遥马，文王仍坐王车。姜子牙这才应允。

于是，文王乘车，子牙乘马，一路往西岐城而去。磻溪的风吹过渭水，吹过那根直钩——它已经完成了使命。

回到西岐城中，文王在金殿之上，当着满朝文武的面，拜姜子牙为右灵台丞相。文王说："自今以后，西岐军国大事，皆由丞相裁决。孤之见，亦须丞相点头方可施行。"满朝文武齐声贺道："恭喜大王得贤臣，恭喜丞相遇明主！"

原书此处有证诗一首：

> 渭水溪头一钓竿，几年卧在碧波间。忽然风起云相送，平地飞腾上九天。

姜子牙这位"昆仑山四十年学道之士"，从此由一个磻溪边直钩垂钓的怪老道，跃升为西岐丞相。他将辅佐文王修德政、强甲兵，为日后的武王伐纣奠定全部根基。西岐，从此有了灭纣兴周的总设计师。

而这一切的起点——是文王灵台上的那一梦，是磻溪边那一根直钩，是君臣相遇时那一声"愿者上钩"。

### 史源原文（关键段落）

**《封神演义》第十九回"伯邑考被醢"原文**：

> "妲己命左右取钉四根，将邑考手足钉了，用刀碎剁。可怜一声拿下，钉了手足。邑考大叫，骂不绝口：'贱人！你将成汤锦绣江山，化为乌有。我死不足惜，忠名常在，孝节永存。'……不一时将邑考剁成肉酱。"

**《封神演义》第二十回"文王食子肉"原文**：

> "姬昌跪在案前，揭开膳盒，言曰：'圣上受鞍马之劳，反赐犯臣鹿饼之享，愿陛下万岁！'谢恩毕，连食三饼，将盒盖了。使命见姬昌食了子肉，暗暗叹曰：'人言姬伯能知先天神数，善晓吉凶，今日见子肉而不知，快餐而甘美，所谓阴阳吉凶，皆是虚语！'"

**《封神演义》第二十回"费仲尤浑受贿保姬昌"原文**：

> "费仲乘机奏曰：'臣闻姬昌素有叛逆不臣之心……臣于前数日着心腹往羑里探听虚实。羑里军民俱言姬昌实有忠义，每月逢朔望之辰，焚香祈求陛下国祚安康……据臣意，看姬昌真乃忠臣。'"

**《封神演义》第二十一回"雷震子救父"原文**：

> "雷震子将胁下翅一声响飞起空中，有风雷之声，脚登山，头望下，看见西边有一山嘴，往外扑看，雷震子说：'待我把这山嘴打一棍你看。'一声响亮，山嘴滚下一半。雷震子转身落下来，对二将言曰：'你的头可有这山结实？'"

**《封神演义》第二十二回"文王吐子"原文**：

> "文王作歌曰：'尽臣节兮奉旨朝商……食子肉兮痛伤骨髓……独不见邑考兮碎裂肝肠！'歌罢，文王大叫一声：'痛杀我也！'跌下马来。……只见文王连吐三口——每口吐出一块肉羹，那肉羹落地便化为三只白兔。"

**《封神演义》第二十三回"灵台夜梦飞熊"原文**：

> "时至三更，正值梦中，忽见东南一只白额猛虎，胁生双翼，望帐中扑来。文王急叫左右，只听台后一声响亮，火光冲霄，文王惊醒，吓了一身香汗。"

**《封神演义》第二十三回"散宜生解梦"原文**：

> "散宜生躬身贺曰：'此梦乃大王之大吉兆，主大王得栋梁之臣，大贤之客，真不让风后、伊尹之右。……昔商高宗曾有飞熊入梦，得傅说于版筑之间；今主公梦虎生双翼者，乃熊也；又见台后火光，乃火锻物之象。今西方属金，金见火必锻；锻炼寒金，必成大器。此乃兴周之大兆。'"

**《封神演义》第二十四回"文王聘子牙"原文**：

> "宜生将銮舆推过，请子牙登舆。子牙跪而告曰：'老臣荷蒙洪恩，以礼相聘，尚已感激非浅，怎敢乘坐銮舆，越名僭分？这个断然不敢！'文王曰：'孤预先相设，特迓先生，必然乘坐，不负素心。'子牙再三不敢，推阻数次，决不敢坐。……宜生曰：'……大王乘舆，贤士乘马，不识尊意如何？'子牙方才允诺。于是，文王乘车，子牙乘马。"

**《史记·周本纪》"文王获释"原文**：

> "闳夭之徒患之，乃求有莘氏美女、骊戎之文马、有熊九驷、他奇怪物，因殷嬖臣费仲而献之纣。纣大说，曰：'此一物足以释西伯，况其多乎！'乃赦西伯，赐之弓矢斧钺，使西伯得征伐。"

**《史记·齐太公世家》"非熊"原文**：

> "西伯将出猎，卜之，曰：'所获非龙非彲，非虎非罴，所获霸王之辅。'于是周西伯猎，果遇太公于渭之阳。"

**《帝王世纪》"纣烹伯邑考"原文**：

> "囚文王，文王长子曰伯邑考，质于殷，为纣御，纣烹为羹，赐文王，曰：'圣人当不食子羹。'文王食之。纣曰：'谁为西伯圣者？食其子尚不知。'"

### 概念语境锁定

- **伯邑考**：本篇取义为《封神演义》中周文王长子，携三宝赴朝歌代父赎罪，被妲己陷害、纣王剁为肉酱。正史《史记·管蔡世家》仅记"文王长子曰伯邑考"，未载其死因；《帝王世纪》始有被烹之说
- **七香车**：本篇取义为《封神演义》中西岐祖传三宝之一——轩辕黄帝破蚩尤于北海所遗，人坐其上不用推引、欲东则东欲西则西。纯文学虚构
- **醒酒毡**：本篇取义为《封神演义》中西岐祖传三宝之一——人若醉卧毡上，不消片刻即醒。纯文学虚构
- **白面猿猴**：本篇取义为《封神演义》中西岐祖传三宝之一——善知三千小曲、八百大曲，能讴歌善舞。纯文学虚构
- **羑里**：本篇取义为《封神演义》中文王被囚之地，即今河南汤阴县。正史《史记·周本纪》"囚西伯于羑里"为本回所本
- **文王食子**：本篇取义为《封神演义》第二十回——文王明知子肉而含泪吞食，以隐忍保全性命。正史《帝王世纪》有"纣烹为羹，赐文王"之说
- **吐子**：本篇取义为《封神演义》第二十二回——文王归国后吐出三只白兔，"吐子"谐音"兔子"。纯民间传说，非正史
- **费仲、尤浑**：本篇取义为《封神演义》中纣王的两个宠臣/奸臣。正史《史记·周本纪》"因殷嬖臣费仲而献之纣"为本回所本（尤浑为文学虚构人物）
- **散宜生**：本篇取义为《封神演义》中西岐上大夫，以重金贿赂费仲、尤浑救出文王。正史《史记·周本纪》记"闳夭之徒"行贿救文王，散宜生为文王重臣之一
- **雷震子**：本篇取义为《封神演义》中文王第一百子——燕山收的义子，云中子之徒，食仙杏而生双翅，面如蓝靛、发似朱砂，使黄金棍。纯文学虚构
- **云中子**：本篇取义为《封神演义》中终南山玉柱洞的阐教仙人，雷震子之师。纯文学虚构
- **临潼关**：本篇取义为《封神演义》中朝歌通往西岐的五关之一，雷震子救父之处
- **金鸡岭**：本篇取义为《封神演义》中西岐地界，雷震子背文王飞出五关后降落之处
- **灵台**：本篇取义为《封神演义》中文王归国后所造之台，以占风候、看验民灾。正史《诗经·大雅·灵台》"经始灵台，经之营之"为本回所本
- **飞熊入梦**：本篇取义为《封神演义》第二十三回——文王灵台夜梦白额猛虎胁生双翼扑入帐中，散宜生解为"飞熊入梦"之兆。正史《史记·齐太公世家》"非虎非罴"（非熊）为本回原型
- **武吉**：本篇取义为《封神演义》中西岐樵夫，误伤人命被判死罪，姜子牙收其为徒并以厌星之术救之，后为文王引路访贤。纯文学虚构
- **画地为牢**：本篇取义为《封神演义》中西岐的刑罚方式——在地上画一圈即为牢狱，竖一木即为狱吏，犯人不得擅出。文学演绎（体现西岐"仁义之邦"）
- **文王聘子牙**：本篇取义为《封神演义》第二十四回——文王亲至磻溪，以大礼拜姜子牙为右灵台丞相。正史《史记·齐太公世家》"文王遇太公于渭之阳"为本回所本

### 学史方法

- **关联（主）**：本篇以"关联"为主抓手——把《封神演义》"文王脱困—归国—梦兆—访贤"的叙事链，与正史"文王获释—渭水遇太公"的史影相互勾连，揭示同一历史事件在史书与神魔小说中的不同面貌。具体为四层关联：
  1. **文王获释的层累**：从《史记·周本纪》"闳夭之徒……因殷嬖臣费仲而献之纣，纣大说……乃赦西伯"的史实骨架，到《封神演义》"散宜生贿赂费仲尤浑—二奸臣保奏—纣王加封文王"的文学演绎——"闳夭"变为"散宜生"，"献美女宝马"变为"送白璧黄金"，"费仲一人"变为"费仲尤浑二人"
  2. **伯邑考之死的层累**：从《史记·管蔡世家》仅记"文王长子曰伯邑考"（未载死因），到《帝王世纪》"纣烹为羹，赐文王"，到《封神演义》加入妲己引诱、白面猿猴行刺、剁为肉酱等完整情节——同一事件经过"正史—杂史—神魔小说"三种文体的层累建构
  3. **飞熊入梦的层累**：从《史记·齐太公世家》"西伯将出猎，卜之，曰：'所获非龙非彲，非虎非罴，所获霸王之辅'"的"出猎卜卦"，到《封神演义》"灵台夜梦白额猛虎胁生双翼"的"夜梦飞熊"——同一母题从"清醒卜卦"变为"梦境预兆"，"非熊"变为"飞熊"
  4. **文王聘贤的层累**：从《史记·齐太公世家》"文王遇太公于渭之阳"的简略记载，到《封神演义》"渔樵引路—武吉证道—磻溪亲访—大礼拜相"的完整叙事——同一事件从"偶遇"变为"天命寻访"
- **对比（辅）**：辅以"史影与文学的对比"——以本篇为切片，对比正史"文王获释—渭水遇太公"的史影范式，与《封神演义》"伯邑考进贡—文王食子—散宜生行贿—雷震子救父—灵台梦兆—磻溪聘贤"的文学范式

### 延伸思考（文学图谱专项）

#### 1. 叙事结构：六回合一之"文王蜕变弧线"

本篇以第十九至二十四回为底本，回目跨度极大（19 → 20 → 21 → 22 → 23 → 24），但叙事主线高度集中——"文王姬昌从囚徒到明主的蜕变"。四个叙事段落构成"逐级递进"：

- **段落一"羑里之痛"（第十九至二十回）**：伯邑考进贡 → 妲己陷害 → 剁为肉酱 → 文王含泪食子 → 隐忍保全
- **段落二"脱困归国"（第二十至二十二回）**：散宜生行贿 → 费尤保奏 → 纣王加封 → 夸官逃关 → 雷震子救父 → 吐子归国
- **段落三"飞熊入梦"（第二十三回）**：造灵台 → 泽枯骨 → 夜梦飞熊 → 散宜生解梦 → 出郊访贤
- **段落四"渭水聘贤"（第二十四回）**：渔樵引路 → 武吉证道 → 磻溪亲访 → 大礼拜相

四段落环环相扣：痛定 → 脱困 → 梦兆 → 得贤。每一段落都"更进一步"——从被动受难到主动求贤，从"囚徒"到"明主"。

#### 2. 文学母题："飞熊入梦"的叙事功能

"飞熊入梦"是《封神演义》全书"天命叙事"的关键节点。其叙事功能有三：其一，**预兆功能**——在文王尚未见到姜子牙之前，便以梦境预兆"将得栋梁之臣"，使后续的"磻溪访贤"不再是偶然相遇，而是天命注定；其二，**悬念功能**——"飞熊"究竟是谁？文王出郊访贤的过程因此充满了寻找与发现的悬念；其三，**合法性功能**——以"天命梦兆"为西岐的兴起赋予神圣合法性，这是中国古代"君权神授"叙事传统的典型体现。

#### 3. "文王食子"的悲剧张力

"文王食子"是《封神演义》全书最具悲剧张力的段落之一。文王明知膳盒中是自己长子的肉，却必须含泪吞食——因为不食则暴露自己"能知先天神数"，必遭杀身之祸。这一情节的深层结构是"知"与"忍"的悖论：文王的智慧（能算出子肉）恰恰成为他的枷锁（必须假装不知而食之）。使命官那句"人言姬伯能知先天神数，善晓吉凶，今日见子肉而不知，快餐而甘美，所谓阴阳吉凶，皆是虚语"——是全书最辛辣的反讽之一。

#### 4. "吐子"传说的民间文学渊源

"文王吐子"（吐出三只白兔）不见于正史，是典型的民间传说融入神魔小说。"吐子"谐音"兔子"，以谐音寄哀思——这是中国民间文学中常见的"谐音叙事"手法。三只兔子象征伯邑考的三魂，也暗示文王将悲愤化为力量，继续兴周大业。这一情节在民间影响极大，至今河南汤阴羑里城仍有"吐儿冢"遗迹。

#### 5. 雷震子：神魔小说中的"救父"母题

雷震子食仙杏而生双翅、面如蓝靛发似朱砂，是中国神魔小说中"变形—获能—救父"母题的典型体现。这一母题可追溯至中国古代的"孝感"叙事传统——子女因孝心感动天地而获得超自然力量。雷震子背父飞出五关的情节，既是神魔小说的奇幻想象，也是儒家"孝道"的文学化表达。

#### 6. "画地为牢"与西岐的仁义形象

《封神演义》第二十三回写西岐"画地为牢、竖木为吏"——在地上画一个圈就是牢狱，竖一根木头就是狱吏，犯人不得擅出。这一细节虽为文学虚构，但用意极深：它塑造了西岐"仁义之邦"的形象——连刑罚都不需要真正的监狱，因为百姓自觉守法。这与朝歌的炮烙、虿盆形成鲜明对比，是全书"商周对比"叙事策略的重要组成部分。

### 正史线并行故事

正史线无对应"伯邑考进贡三宝—妲己陷害—雷震子救父—飞熊入梦—文王聘子牙"的完整故事——本篇所述大部分情节为《封神演义》的文学虚构/神魔演绎。正史中可考的相关内容仅有：

1. **文王被囚与获释**——见《史记·周本纪》——"囚西伯于羑里""闳夭之徒……因殷嬖臣费仲而献之纣……乃赦西伯"
2. **伯邑考**——见《史记·管蔡世家》《帝王世纪》——"文王长子曰伯邑考""纣烹为羹，赐文王"
3. **文王遇太公**——见《史记·齐太公世家》——"西伯将出猎，卜之……果遇太公于渭之阳"
4. **灵台**——见《诗经·大雅·灵台》——"经始灵台，经之营之"

如欲对照"文王兴周"与"武王伐纣"的正史视角，详见 [`03_xizhou.md`](./03_xizhou.md) 中相关各篇。
